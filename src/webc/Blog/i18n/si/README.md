# බ්ලොග් පෝස්ට් සංරචකය

- **ස්වයංක්‍රීය වසර සමූහගත කිරීම**: ලිපි දිනය අනුව ස්වයංක්‍රීයව වසර වර්ගීකරණය කර ඒවා වසරින් ප්‍රතිලෝම අනුපිළිවෙලට සකසන්න
- **සරල කළ දින ආකෘතිය**: සංදර්ශන කිරීමේදී වසර උපසර්ගය ස්වයංක්‍රීයව ඉවත් කර මාසය සහ දිනය පමණක් සංදර්ශනය කරන්න
- **Markdown සාරාංශය සහ පෙළ**: බිල්ට්-ඉන් ලැයිස්තු සාරාංශ පෙරදසුන සහ තනි ලිපිය සම්පූර්ණ පෙළ විදැහුම්කරණය
- **ශ්‍රේණියේ ත්‍රිමාන මාතෘකාව**: සිරස්තල සහ මුදා හැරීමේ දිනය පෙන්වීමට `H1Txt` ඒකාබද්ධ කරන්න

## Demo භාවිතා කරන්න

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/ප්‍රකාශනය": ["මාතෘකාව", "සාරාංශය", "2026-07-27"]
};

// නිශ්චිත ලිපි අන්තර්ගතය පූරණය කිරීමට මාරු වන්න (නැවත ලැයිස්තුවට මාරු වීමට හිස් තන්තුවක් පසු කරන්න)
blog.load("2026/publish");
</script>
```

## අතුරුමුහුණත් පරාමිතීන්

### ගුණාංග සහ ක්රම

- `blog.prefix`: ලිපි සබැඳි උපසර්ගය ලබා ගන්න හෝ සකසන්න (`"/blog/"` වැනි)
- `blog.mdUrl`: Markdown ලිපි ලිපින උත්පාදන කාර්යය `(key, lang) => url` ලබා ගන්න හෝ සකසන්න
- `blog._`: ලිපි ලැයිස්තු පාරදත්ත ශබ්දකෝෂය `{ [key]: [title, summary, date] }` ලබා ගන්න හෝ සකසන්න
- `blog.load(key)`: නිශ්චිත යතුරේ ලිපි අන්තර්ගතය පූරණය කිරීමට මාරු වන්න, බ්ලොග් ලැයිස්තුවට ආපසු මාරු වීමට හිස් තන්තුවක් `""` පසු කරන්න
