# جزء پست وبلاگ

- **گروه بندی خودکار سال**: به طور خودکار سال ها را بر اساس تاریخ مقاله طبقه بندی کنید و آنها را به ترتیب معکوس بر اساس سال مرتب کنید.
- **فرمت ساده شده تاریخ**: به طور خودکار پیشوند سال را هنگام نمایش حذف کنید و فقط ماه و روز را نمایش دهید
- **خلاصه علامت گذاری و متن**: پیش نمایش خلاصه فهرست داخلی و ارائه متن کامل تک مقاله
- **عنوان سه بعدی گرادیان**: `H1Txt` را برای نمایش عنوان و تاریخ انتشار ادغام کنید

## از دمو استفاده کنید

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/انتشار": ["عنوان"، "چکیده"، "2026-07-27"]
};

// برای بارگیری بدنه مقاله مشخص شده تغییر دهید (یک رشته خالی را برای بازگشت به لیست ارسال کنید)
blog.load("2026/publish");
</script>
```

## پارامترهای رابط

### خواص و روش ها

- `blog.prefix`: دریافت یا تنظیم پیشوند پیوند مقاله (مانند `"/blog/"`)
- `blog.mdUrl`: تابع تولید آدرس مقاله Markdown را دریافت یا تنظیم کنید `(key, lang) => url`
- `blog._`: فرهنگ لغت فراداده فهرست مقاله را دریافت یا تنظیم کنید `{ [key]: [title, summary, date] }`
- `blog.load(key)`: برای بارگیری محتوای مقاله کلید مشخص شده تغییر دهید، یک رشته خالی `""` را برای بازگشت به لیست وبلاگ ارسال کنید
