# Компонент публикации в блоге

- **Автоматическая группировка по годам**: автоматически классифицируйте годы по дате статьи и располагайте их в обратном порядке по годам.
- **Упрощенный формат даты**: автоматически удаляет префикс года при отображении и отображает только месяц и день.
- **Сводка и текст уценки**: встроенный предварительный просмотр сводки списка и рендеринг полного текста отдельной статьи.
- **Трёхмерный заголовок с градиентом**: интегрируйте `H1Txt` для отображения заголовка и даты выпуска.

## Используйте демо-версию

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/опубликовать": ["название", "аннотация", "27.07.2026"]
};

// Переключаемся на загрузку указанного текста статьи (передаем пустую строку, чтобы вернуться к списку)
blog.load("2026/publish");
</script>
```

## Параметры интерфейса

### Свойства и методы

- `blog.prefix`: получение или установка префикса ссылки на статью (например, `"/blog/"`).
- `blog.mdUrl`: получите или установите функцию генерации адреса статьи Markdown `(key, lang) => url`
- `blog._`: получение или установка словаря метаданных списка статей `{ [key]: [title, summary, date] }`
- `blog.load(key)`: переключитесь на загрузку содержимого статьи по указанному ключу, передайте пустую строку `""`, чтобы вернуться к списку блогов.
