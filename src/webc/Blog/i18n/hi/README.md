# ब्लॉग पोस्ट घटक

- **स्वचालित वर्ष समूहन**: लेख तिथि के अनुसार वर्षों को स्वचालित रूप से वर्गीकृत करें, और उन्हें वर्ष के अनुसार उल्टे क्रम में व्यवस्थित करें
- **सरलीकृत दिनांक प्रारूप**: प्रदर्शित करते समय वर्ष उपसर्ग को स्वचालित रूप से हटा दें, और केवल माह और दिन प्रदर्शित करें
- **मार्कडाउन सारांश और पाठ**: अंतर्निहित सूची सारांश पूर्वावलोकन और एकल लेख संपूर्ण पाठ प्रतिपादन
- **ग्रेडियंट त्रि-आयामी शीर्षक**: शीर्षक और रिलीज़ दिनांक प्रदर्शित करने के लिए `H1Txt` को एकीकृत करें

## डेमो का प्रयोग करें

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/प्रकाशित करें": ["शीर्षक", "सार", "2026-07-27"]
};

// निर्दिष्ट आलेख पाठ को लोड करने के लिए स्विच करें (सूची पर वापस जाने के लिए एक खाली स्ट्रिंग पास करें)
blog.load("2026/publish");
</script>
```

## इंटरफ़ेस पैरामीटर

### गुण और विधियाँ

- `blog.prefix`: आलेख लिंक उपसर्ग प्राप्त करें या सेट करें (जैसे कि `"/blog/"`)
- `blog.mdUrl`: मार्कडाउन आलेख पता जनरेशन फ़ंक्शन `(key, lang) => url` प्राप्त करें या सेट करें
- `blog._`: आलेख सूची मेटाडेटा शब्दकोश `{ [key]: [title, summary, date] }` प्राप्त करें या सेट करें
- `blog.load(key)`: निर्दिष्ट कुंजी के लेख सामग्री को लोड करने के लिए स्विच करें, ब्लॉग सूची पर वापस जाने के लिए एक खाली स्ट्रिंग `""` पास करें
