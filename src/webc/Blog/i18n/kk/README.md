# Блог жазбасының құрамдас бөлігі

- **Жылдарды автоматты түрде топтау**: Жылдарды мақала күніне қарай автоматты түрде жіктеп, оларды жыл бойынша кері ретпен реттеңіз
- **Жеңілдетілген күн пішімі**: көрсету кезінде жыл префиксін автоматты түрде алып тастаңыз және тек айды және күнді көрсетіңіз
- **Белгіленген қорытынды және мәтін**: кірістірілген тізімнің жиынтықты алдын ала қарауы және бір мақаланың толық мәтінін көрсету
- **Градиенттік үш өлшемді тақырып**: тақырыпты және шығарылым күнін көрсету үшін `H1Txt` біріктіріңіз

## Демонстрацияны пайдаланыңыз

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/publish": ["атауы", "реферат", "2026-07-27"]
};

// Көрсетілген мақала мәтінін жүктеуге ауысу (тізімге қайта ауысу үшін бос жолды өткізіңіз)
blog.load("2026/publish");
</script>
```

## Интерфейс параметрлері

### Қасиеттер мен әдістер

- `blog.prefix`: мақала сілтемесінің префиксін алу немесе орнату (мысалы, `"/blog/"`)
- `blog.mdUrl`: Markdown мақала мекенжайын құру функциясын `(key, lang) => url` алыңыз немесе орнатыңыз
- `blog._`: `{ [key]: [title, summary, date] }` мақалалар тізімінің метадеректер сөздігін алу немесе орнату
- `blog.load(key)`: Көрсетілген кілттің мақала мазмұнын жүктеуге ауысыңыз, блог тізіміне қайта ауысу үшін бос жолды `""` өткізіңіз
