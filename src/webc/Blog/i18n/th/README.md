# ส่วนประกอบโพสต์บล็อก

- **การจัดกลุ่มปีอัตโนมัติ**: จำแนกปีตามวันที่ในบทความโดยอัตโนมัติ และจัดเรียงปีตามลำดับย้อนกลับ
- **รูปแบบวันที่แบบง่าย**: ลบคำนำหน้าปีโดยอัตโนมัติเมื่อแสดง และแสดงเฉพาะเดือนและวันเท่านั้น
- **สรุปมาร์กดาวน์และข้อความ**: การแสดงตัวอย่างสรุปรายการในตัวและการแสดงข้อความฉบับสมบูรณ์ของบทความเดี่ยว
- **ชื่อสามมิติแบบไล่ระดับสี**: รวม `H1Txt` เพื่อแสดงพาดหัวและวันที่เผยแพร่

## ใช้การสาธิต

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/เผยแพร่": ["หัวข้อ", "นามธรรม", "27-07-2569"]
};

// สลับเพื่อโหลดเนื้อหาบทความที่ระบุ (ส่งสตริงว่างเพื่อสลับกลับไปยังรายการ)
blog.load("2026/publish");
</script>
```

## พารามิเตอร์อินเทอร์เฟซ

### คุณสมบัติและวิธีการ

- `blog.prefix`: รับหรือตั้งค่าคำนำหน้าลิงก์บทความ (เช่น `"/blog/"`)
- `blog.mdUrl`: รับหรือตั้งค่าฟังก์ชันการสร้างที่อยู่บทความ Markdown `(key, lang) => url`
- `blog._`: รับหรือตั้งค่าพจนานุกรมข้อมูลเมตาของรายการบทความ `{ [key]: [title, summary, date] }`
- `blog.load(key)`: สลับเพื่อโหลดเนื้อหาบทความของคีย์ที่ระบุ ส่งสตริงว่าง `""` เพื่อเปลี่ยนกลับไปยังรายการบล็อก
