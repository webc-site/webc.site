# ອົງປະກອບຕອບ blog

- ** ການ​ຈັດ​ກຸ່ມ​ປີ​ອັດ​ຕະ​ໂນ​ມັດ **​: ຈັດ​ປະ​ເພດ​ປີ​ອັດ​ຕະ​ໂນ​ມັດ​ຕາມ​ວັນ​ທີ​ບົດ​ຄວາມ​, ແລະ​ຈັດ​ໃຫ້​ເຂົາ​ເຈົ້າ​ໃນ​ລໍາ​ດັບ​ປີ​ກັບ​ຄືນ​ໄປ​ບ່ອນ
- **ຮູບແບບວັນທີແບບງ່າຍ**: ເອົາຄຳນຳໜ້າປີອອກໂດຍອັດຕະໂນມັດເມື່ອສະແດງ, ແລະສະແດງສະເພາະເດືອນ ແລະມື້ເທົ່ານັ້ນ.
- **ສະຫຼຸບຫຍໍ້ ແລະຂໍ້ຄວາມ**: ເບິ່ງຕົວຢ່າງສະຫຼຸບລາຍຊື່ໃນຕົວ ແລະສະແດງຂໍ້ຄວາມໃຫ້ເຕັມບົດຄວາມດຽວ.
- **ຊື່ຫົວຂໍ້ສາມມິຕິລະດັບສີ**: ປະສົມປະສານ `H1Txt`ເພື່ອສະແດງຫົວຂໍ້ຂ່າວ ແລະວັນທີເປີດຕົວ

## ໃຊ້ຕົວຢ່າງ

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/publish": ["title", "abstract", "2026-07-27"]
};

// ສະຫຼັບເພື່ອໂຫຼດເນື້ອໃນບົດຄວາມທີ່ລະບຸໄວ້ (ຜ່ານສະຕຣິງຫວ່າງເປົ່າເພື່ອສະຫຼັບກັບໄປຫາລາຍການ)
blog.load("2026/publish");
</script>
```

## ຕົວກໍານົດການໃນການໂຕ້ຕອບ

### ຄຸນສົມບັດແລະວິທີການ

- `blog.prefix`: ເອົາ ຫຼືຕັ້ງຄຳນຳໜ້າລິ້ງບົດຄວາມ (ເຊັ່ນ: `"/blog/"`)
- `blog.mdUrl`: ໄດ້​ຮັບ​ຫຼື​ຕັ້ງ​ຫນ້າ​ການ​ຜະ​ລິດ​ທີ່​ຢູ່​ບົດ​ຄວາມ Markdown `(key, lang) => url`
- `blog._`: ເອົາ ຫຼືຕັ້ງລາຍການບົດຄວາມ metadata ວັດຈະນານຸກົມ `{ [key]: [title, summary, date] }`
- `blog.load(key)`: ສະຫຼັບເພື່ອໂຫຼດເນື້ອໃນບົດຄວາມຂອງລະຫັດທີ່ລະບຸໄວ້, ຜ່ານສະຕຣິງຫວ່າງເປົ່າ `""`ເພື່ອສະຫຼັບກັບໄປຫາລາຍການບລັອກ
