# Компонент публікації в блозі

- **Автоматичне групування за роками**: автоматично класифікуйте роки відповідно до дати статті та розташуйте їх у зворотному порядку за роками
- **Спрощений формат дати**: автоматично видаляти префікс року під час відображення та відображати лише місяць і день
- **Підсумок розцінки та текст**: вбудований попередній перегляд підсумкового списку та рендеринг повного тексту однієї статті
- **Градієнтний тривимірний заголовок**: інтегруйте `H1Txt` для відображення заголовка та дати випуску

## Використовуйте демо

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/publish": ["title", "abstract", "2026-07-27"]
};

// Перемикання для завантаження зазначеного тіла статті (передайте порожній рядок, щоб повернутися до списку)
blog.load("2026/publish");
</script>
```

## Параметри інтерфейсу

### Властивості та методи

- `blog.prefix`: отримати або встановити префікс посилання на статтю (наприклад, `"/blog/"`)
- `blog.mdUrl`: отримати або встановити функцію генерації адреси статті Markdown `(key, lang) => url`
- `blog._`: отримати або встановити словник метаданих списку статей `{ [key]: [title, summary, date] }`
- `blog.load(key)`: перемикання для завантаження вмісту статті з указаним ключем, передача порожнього рядка `""` для перемикання назад до списку блогів
