# بلاگ پوسٽ جو حصو

- **خودڪار سال گروپنگ**: آرٽيڪل جي تاريخ جي مطابق پاڻمرادو سالن جي درجه بندي ڪريو، ۽ انھن کي سال جي حساب سان ريورس آرڊر ۾ ترتيب ڏيو
- **آسان ٿيل تاريخ فارميٽ**: پاڻمرادو ختم ڪريو سال اڳياڙي جڏهن ڏيکاريندي، ۽ صرف ڏيکاريو مهينو ۽ ڏينهن
- **مارڪ ڊائون خلاصو ۽ ٽيڪسٽ**: بلٽ ان لسٽ جو خلاصو ڏيک ۽ اڪيلو مضمون مڪمل ٽيڪسٽ رينڊرنگ
- **گراڊيئيٽ ٽي-dimensional عنوان**: ضم ڪريو `H1Txt` عنوان ۽ ڇڏڻ جي تاريخ ڏيکارڻ لاءِ

## ڊيمو استعمال ڪريو

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/publish": ["عنوان"، "خلاصه"، "2026-07-27"]
};

// مخصوص آرٽيڪل باڊي کي لوڊ ڪرڻ لاءِ سوئچ ڪريو (فهرست ڏانھن واپس وڃڻ لاءِ خالي اسٽرنگ پاس ڪريو)
blog.load("2026/publish");
</script>
```

## انٽرفيس پيٽرول

### خاصيتون ۽ طريقا

- `blog.prefix`: حاصل ڪريو يا آرٽيڪل لنڪ اڳياڙي مقرر ڪريو (جهڙوڪ `"/blog/"`)
- `blog.mdUrl`: حاصل ڪريو يا سيٽ ڪريو مارڪ ڊائون آرٽيڪل ايڊريس جنريشن فنڪشن `(key, lang) => url`
- `blog._`: حاصل ڪريو يا سيٽ ڪريو آرٽيڪل لسٽ ميٽا ڊيٽا ڊڪشنري `{ [key]: [title, summary, date] }`
- `blog.load(key)`: مخصوص ڪيل ڪي جي آرٽيڪل مواد لوڊ ڪرڻ لاءِ سوئچ ڪريو، خالي اسٽرنگ پاس ڪريو `""` بلاگ لسٽ ڏانھن واپس وڃڻ لاءِ
