# مكون مشاركة المدونة

- **تجميع السنوات تلقائيًا**: تصنيف السنوات تلقائيًا وفقًا لتاريخ المقالة، وترتيبها بترتيب عكسي حسب السنة
- **تنسيق التاريخ المبسط**: إزالة بادئة السنة تلقائيًا عند العرض، وعرض الشهر واليوم فقط
- **ملخص تخفيض السعر والنص**: معاينة ملخص القائمة المضمنة وعرض النص الكامل لمقال واحد
- **عنوان متدرج ثلاثي الأبعاد**: قم بدمج `H1Txt` لعرض العنوان الرئيسي وتاريخ الإصدار

## استخدم العرض التوضيحي

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/نشر": ["عنوان"، "ملخص"، "27-07-2026"]
};

// قم بالتبديل لتحميل نص المقالة المحدد (قم بتمرير سلسلة فارغة للتبديل مرة أخرى إلى القائمة)
blog.load("2026/publish");
</script>
```

## معلمات الواجهة

### الخصائص والأساليب

- `blog.prefix`: الحصول على بادئة رابط المقالة أو تعيينها (مثل `"/blog/"`)
- `blog.mdUrl`: احصل على وظيفة إنشاء عنوان مقالة Markdown أو قم بتعيينها `(key, lang) => url`
- `blog._`: احصل على أو قم بتعيين قاموس البيانات الوصفية لقائمة المقالات `{ [key]: [title, summary, date] }`
- `blog.load(key)`: قم بالتبديل لتحميل محتوى المقالة للمفتاح المحدد، وقم بتمرير سلسلة فارغة `""` للتبديل مرة أخرى إلى قائمة المدونات
