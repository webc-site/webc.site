# ブログ投稿コンポーネント

- **年の自動グループ化**: 記事の日付に従って年を自動的に分類し、年の逆順に並べます。
- **簡易日付形式**: 表示時に年の接頭辞が自動的に削除され、月と日のみが表示されます。
- **マークダウンの概要とテキスト**: 組み込みのリスト概要プレビューと単一記事の完全なテキストのレンダリング
- **グラデーション立体タイトル**: 見出しと発売日を`H1Txt`統合して表示します

## デモを使用する

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/出版": ["タイトル", "要約", "2026-07-27"]
};

// 指定された記事本文のロードに切り替えます (リストに戻るには空の文字列を渡します)
blog.load("2026/publish");
</script>
```

## インターフェースパラメータ

### プロパティとメソッド

- `blog.prefix`: 記事リンクのプレフィックス (`"/blog/"` など) を取得または設定します。
- `blog.mdUrl`: Markdown 記事のアドレス生成関数を取得または設定します `(key, lang) => url`
- `blog._`: 記事リストのメタデータ辞書を取得または設定します `{ [key]: [title, summary, date] }`
- `blog.load(key)`: 指定されたキーの記事コンテンツをロードするように切り替えます。ブログ リストに戻るには、空の文字列 `""` を渡します。
