# بلاگ پوسٹ کا جزو

- **خودکار سال کی گروپ بندی**: خودکار طور پر سال کو آرٹیکل کی تاریخ کے مطابق درجہ بندی کریں، اور انہیں سال کے لحاظ سے الٹی ترتیب میں ترتیب دیں
- **آسان تاریخ کی شکل**: ڈسپلے کرتے وقت خودکار طور پر سال کا سابقہ ​​ہٹا دیں، اور صرف مہینہ اور دن دکھائیں
- **مارک ڈاؤن خلاصہ اور متن**: بلٹ ان لسٹ سمری کا پیش نظارہ اور ایک مضمون مکمل ٹیکسٹ رینڈرنگ
- **گریڈینٹ تین جہتی عنوان**: سرخی اور ریلیز کی تاریخ کو ظاہر کرنے کے لیے `H1Txt` کو مربوط کریں

## ڈیمو استعمال کریں۔

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/publish": ["عنوان"، "خلاصہ"، "2026-07-27"]
};

// مخصوص آرٹیکل باڈی کو لوڈ کرنے کے لیے سوئچ کریں (فہرست پر واپس جانے کے لیے ایک خالی سٹرنگ پاس کریں)
blog.load("2026/publish");
</script>
```

## انٹرفیس کے پیرامیٹرز

### خصوصیات اور طریقے

- `blog.prefix`: آرٹیکل لنک کا سابقہ ​​حاصل کریں یا سیٹ کریں (جیسے `"/blog/"`)
- `blog.mdUrl`: مارک ڈاؤن آرٹیکل ایڈریس جنریشن فنکشن حاصل کریں یا سیٹ کریں `(key, lang) => url`
- `blog._`: آرٹیکل لسٹ میٹا ڈیٹا ڈکشنری حاصل کریں یا سیٹ کریں `{ [key]: [title, summary, date] }`
- `blog.load(key)`: مخصوص کلید کے مضمون کے مواد کو لوڈ کرنے کے لیے سوئچ کریں، بلاگ کی فہرست پر واپس جانے کے لیے ایک خالی سٹرنگ `""` پاس کریں۔
