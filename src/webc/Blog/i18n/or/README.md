# ବ୍ଲଗ୍ ପୋଷ୍ଟ ଉପାଦାନ |

- ** ସ୍ୱୟଂଚାଳିତ ବର୍ଷ ଗ୍ରୁପିଂ **: ଆର୍ଟିକିଲ୍ ତାରିଖ ଅନୁଯାୟୀ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ବର୍ଷଗୁଡ଼ିକୁ ଶ୍ରେଣୀଭୁକ୍ତ କର, ଏବଂ ବର୍ଷକୁ ଓଲଟା କ୍ରମରେ ସଜାନ୍ତୁ |
- ** ସରଳୀକୃତ ତାରିଖ ଫର୍ମାଟ୍ **: ପ୍ରଦର୍ଶନ କରିବା ସମୟରେ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ବର୍ଷର ଉପସର୍ଗକୁ ଅପସାରଣ କରନ୍ତୁ, ଏବଂ କେବଳ ମାସ ଏବଂ ଦିନ ପ୍ରଦର୍ଶନ କରନ୍ତୁ |
- ** ମାର୍କଡାଉନ୍ ସାରାଂଶ ଏବଂ ପାଠ୍ୟ **: ବିଲ୍ଟ-ଇନ୍ ତାଲିକା ସାରାଂଶ ପୂର୍ବାବଲୋକନ ଏବଂ ଏକକ ପ୍ରବନ୍ଧ ସଂପୂର୍ଣ୍ଣ ପାଠ୍ୟ ଉପସ୍ଥାପନା |
- ** ଗ୍ରେଡିଏଣ୍ଟ୍ ତିନି-ଡାଇମେନ୍ସନାଲ୍ ଟାଇଟଲ୍ **: ହେଡଲାଇନ୍ ଏବଂ ରିଲିଜ୍ ତାରିଖ ପ୍ରଦର୍ଶନ କରିବାକୁ `H1Txt` ଏକତ୍ର କର |

## ଡେମୋ ବ୍ୟବହାର କରନ୍ତୁ |

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026 / ପ୍ରକାଶନ": ["ଆଖ୍ୟା", "ବିସ୍ତୃତ", "2026-07-27"]
};

// ନିର୍ଦ୍ଦିଷ୍ଟ ଆର୍ଟିକିଲ୍ ବଡି ଲୋଡ୍ କରିବାକୁ ସୁଇଚ୍ କରନ୍ତୁ (ତାଲିକାକୁ ଫେରିବା ପାଇଁ ଏକ ଖାଲି ଷ୍ଟ୍ରିଙ୍ଗ୍ ପାସ୍ କରନ୍ତୁ) |
blog.load("2026/publish");
</script>
```

## ଇଣ୍ଟରଫେସ୍ ପାରାମିଟରଗୁଡିକ

### ଗୁଣ ଏବଂ ପଦ୍ଧତି |

- `blog.prefix`: ଆର୍ଟିକିଲ୍ ଲିଙ୍କ୍ ଉପସର୍ଗ ପ୍ରାପ୍ତ କରନ୍ତୁ କିମ୍ବା ସେଟ୍ କରନ୍ତୁ (ଯେପରିକି `"/blog/"`)
- `blog.mdUrl`: ମାର୍କଡାଉନ୍ ଆର୍ଟିକିଲ୍ ଠିକଣା ଉତ୍ପାଦନ କାର୍ଯ୍ୟ `(key, lang) => url` ପାଆନ୍ତୁ କିମ୍ବା ସେଟ୍ କରନ୍ତୁ |
- `blog._`: ପ୍ରବନ୍ଧ ତାଲିକା ମେଟାଡାଟା ଅଭିଧାନ `{ [key]: [title, summary, date] }` ପ୍ରାପ୍ତ କିମ୍ବା ସେଟ୍ କରନ୍ତୁ |
- `blog.load(key)`: ନିର୍ଦ୍ଦିଷ୍ଟ ଚାବିର ଆର୍ଟିକିଲ୍ ବିଷୟବସ୍ତୁ ଲୋଡ୍ କରିବାକୁ ସୁଇଚ୍ କରନ୍ତୁ, ବ୍ଲଗ୍ ତାଲିକାକୁ ଫେରିବା ପାଇଁ ଏକ ଖାଲି ଷ୍ଟ୍ରିଙ୍ଗ୍ `""` ପାସ୍ କରନ୍ତୁ |
