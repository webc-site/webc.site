# Компонента за блог пост

- **Автоматско групирање години**: Автоматски класифицирајте ги годините според датумот на статијата и распоредете ги во обратен редослед по година
- **Поедноставен формат на датум**: Автоматски отстранете го префиксот на годината при прикажување и прикажувајте ги само месецот и денот
- **Резиме и текст за обележување**: Вграден преглед на резимето на списокот и прикажување на целосен текст за една статија
- **Градиент тродимензионален наслов**: Интегрирајте `H1Txt` за прикажување на насловот и датумот на објавување

## Користете го демо

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  „2026/објавување“: [„наслов“, „апстракт“, „2026-07-27“]
};

// Префрли за да се вчита наведеното тело на статијата (помине празна низа за да се вратиш назад на списокот)
blog.load("2026/publish");
</script>
```

## Параметри на интерфејсот

### Својства и методи

- `blog.prefix`: Земете или поставете го префиксот за врската на статијата (како што е `"/blog/"`)
- `blog.mdUrl`: Земете или поставете ја функцијата за генерирање адреса на статијата Markdown `(key, lang) => url`
- `blog._`: Земете или поставете го речникот на метаподатоци од списокот на статии `{ [key]: [title, summary, date] }`
- `blog.load(key)`: префрлете се за да ја вчитате содржината на статијата на наведениот клуч, поминете празна низа `""` за да се вратите на списокот со блогови
