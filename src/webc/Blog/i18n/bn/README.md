# ব্লগ পোস্ট উপাদান

- **স্বয়ংক্রিয় বছরের গ্রুপিং**: নিবন্ধের তারিখ অনুসারে স্বয়ংক্রিয়ভাবে বছরগুলিকে শ্রেণীবদ্ধ করুন এবং বছর অনুসারে তাদের বিপরীত ক্রমে সাজান
- **সরলীকৃত তারিখ বিন্যাস**: প্রদর্শন করার সময় স্বয়ংক্রিয়ভাবে বছরের উপসর্গটি সরিয়ে দিন এবং শুধুমাত্র মাস এবং দিন প্রদর্শন করুন
- **মার্কডাউন সারাংশ এবং পাঠ্য**: অন্তর্নির্মিত তালিকার সারাংশের পূর্বরূপ এবং একক নিবন্ধ সম্পূর্ণ পাঠ্য রেন্ডারিং
- **গ্রেডিয়েন্ট ত্রিমাত্রিক শিরোনাম**: শিরোনাম এবং প্রকাশের তারিখ প্রদর্শন করতে `H1Txt` একীভূত করুন

## ডেমো ব্যবহার করুন

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/প্রকাশ": ["শিরোনাম", "বিমূর্ত", "2026-07-27"]
};

// নির্দিষ্ট নিবন্ধের অংশ লোড করতে স্যুইচ করুন (তালিকায় ফিরে যেতে একটি খালি স্ট্রিং পাস করুন)
blog.load("2026/publish");
</script>
```

## ইন্টারফেস পরামিতি

### বৈশিষ্ট্য এবং পদ্ধতি

- `blog.prefix`: নিবন্ধের লিঙ্ক প্রিফিক্স পান বা সেট করুন (যেমন `"/blog/"`)
- `blog.mdUrl`: মার্কডাউন নিবন্ধ ঠিকানা তৈরি ফাংশন পান বা সেট করুন `(key, lang) => url`৷
- `blog._`: নিবন্ধের তালিকা মেটাডেটা অভিধান `{ [key]: [title, summary, date] }` পান বা সেট করুন৷
- `blog.load(key)`: নির্দিষ্ট কী এর নিবন্ধ সামগ্রী লোড করতে স্যুইচ করুন, ব্লগ তালিকায় ফিরে যেতে একটি খালি স্ট্রিং `""` পাস করুন
