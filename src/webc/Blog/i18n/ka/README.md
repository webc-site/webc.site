# ბლოგის პოსტის კომპონენტი

- **წლების ავტომატური დაჯგუფება**: ავტომატურად დაალაგეთ წლები სტატიის თარიღის მიხედვით და დაალაგეთ ისინი საპირისპირო თანმიმდევრობით წლის მიხედვით
- ** გამარტივებული თარიღის ფორმატი **: ავტომატურად წაშალეთ წელიწადის პრეფიქსი ჩვენებისას და აჩვენეთ მხოლოდ თვე და დღე
- ** მარკდაუნის შეჯამება და ტექსტი **: ჩაშენებული სიის შეჯამების გადახედვა და ერთი სტატიის სრული ტექსტის გადმოცემა
- **გრადიენტური სამგანზომილებიანი სათაური**: ინტეგრირება `H1Txt` სათაურის და გამოშვების თარიღის საჩვენებლად

## გამოიყენეთ დემო ვერსია

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/გამოქვეყნება": ["სათაური", "რეზიუმე", "2026-07-27"]
};

// გადართეთ მითითებული სტატიის ტექსტის ჩატვირთვაზე (გაატარეთ ცარიელი სტრიქონი სიაზე დასაბრუნებლად)
blog.load("2026/publish");
</script>
```

## ინტერფეისის პარამეტრები

### თვისებები და მეთოდები

- `blog.prefix`: მიიღეთ ან დააყენეთ სტატიის ბმულის პრეფიქსი (როგორიცაა `"/blog/"`)
- `blog.mdUrl`: მიიღეთ ან დააყენეთ Markdown სტატიის მისამართის გენერირების ფუნქცია `(key, lang) => url`
- `blog._`: მიიღეთ ან დააყენეთ სტატიების სიის მეტამონაცემების ლექსიკონი `{ [key]: [title, summary, date] }`
- `blog.load(key)`: გადართეთ მითითებული გასაღების სტატიის შინაარსის ჩატვირთვაზე, გადასვით ცარიელი სტრიქონი `""` ბლოგების სიაზე დასაბრუნებლად
