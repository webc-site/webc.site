# Στοιχείο ανάρτησης ιστολογίου

- **Αυτόματη ομαδοποίηση ετών**: Αυτόματη ταξινόμηση ετών σύμφωνα με την ημερομηνία του άρθρου και τακτοποίηση με αντίστροφη σειρά ανά έτος
- **Απλοποιημένη μορφή ημερομηνίας**: Καταργήστε αυτόματα το πρόθεμα έτους κατά την εμφάνιση και εμφανίστε μόνο τον μήνα και την ημέρα
- **Σύνοψη και κείμενο Markdown**: Ενσωματωμένη προεπισκόπηση σύνοψης λίστας και πλήρης απόδοση κειμένου μεμονωμένου άρθρου
- **Gradient τρισδιάστατος τίτλος**: Ενσωματώστε το `H1Txt` για να εμφανίσετε την επικεφαλίδα και την ημερομηνία κυκλοφορίας

## Χρησιμοποιήστε το demo

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/δημοσίευση": ["τίτλος", "περίληψη", "2026-07-27"]
};

// Εναλλαγή για φόρτωση του καθορισμένου σώματος άρθρου (πέρασε μια κενή συμβολοσειρά για να επιστρέψεις στη λίστα)
blog.load("2026/publish");
</script>
```

## Παράμετροι διεπαφής

### Ιδιότητες και μέθοδοι

- `blog.prefix`: Αποκτήστε ή ορίστε το πρόθεμα συνδέσμου άρθρου (όπως `"/blog/"`)
- `blog.mdUrl`: Αποκτήστε ή ορίστε τη συνάρτηση δημιουργίας διεύθυνσης άρθρου Markdown `(key, lang) => url`
- `blog._`: Λήψη ή ρύθμιση του λεξικού μεταδεδομένων της λίστας άρθρων `{ [key]: [title, summary, date] }`
- `blog.load(key)`: Εναλλαγή για να φορτώσετε το περιεχόμενο του άρθρου του καθορισμένου κλειδιού, περάστε μια κενή συμβολοσειρά `""` για να επιστρέψετε στη λίστα ιστολογίων
