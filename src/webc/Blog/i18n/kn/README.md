# ಬ್ಲಾಗ್ ಪೋಸ್ಟ್ ಘಟಕ

- **ಸ್ವಯಂಚಾಲಿತ ವರ್ಷದ ಗುಂಪು**: ಲೇಖನದ ದಿನಾಂಕದ ಪ್ರಕಾರ ವರ್ಷಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ವರ್ಗೀಕರಿಸಿ ಮತ್ತು ಅವುಗಳನ್ನು ವರ್ಷದಿಂದ ಹಿಮ್ಮುಖ ಕ್ರಮದಲ್ಲಿ ಜೋಡಿಸಿ
- **ಸರಳೀಕೃತ ದಿನಾಂಕ ಸ್ವರೂಪ**: ಪ್ರದರ್ಶಿಸುವಾಗ ವರ್ಷದ ಪೂರ್ವಪ್ರತ್ಯಯವನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ತೆಗೆದುಹಾಕಿ ಮತ್ತು ತಿಂಗಳು ಮತ್ತು ದಿನವನ್ನು ಮಾತ್ರ ಪ್ರದರ್ಶಿಸಿ
- **ಮಾರ್ಕ್‌ಡೌನ್ ಸಾರಾಂಶ ಮತ್ತು ಪಠ್ಯ**: ಅಂತರ್ನಿರ್ಮಿತ ಪಟ್ಟಿ ಸಾರಾಂಶ ಪೂರ್ವವೀಕ್ಷಣೆ ಮತ್ತು ಏಕ ಲೇಖನ ಸಂಪೂರ್ಣ ಪಠ್ಯ ರೆಂಡರಿಂಗ್
- **ಗ್ರೇಡಿಯಂಟ್ ಮೂರು ಆಯಾಮದ ಶೀರ್ಷಿಕೆ**: ಶೀರ್ಷಿಕೆ ಮತ್ತು ಬಿಡುಗಡೆ ದಿನಾಂಕವನ್ನು ಪ್ರದರ್ಶಿಸಲು `H1Txt` ಅನ್ನು ಸಂಯೋಜಿಸಿ

## ಡೆಮೊ ಬಳಸಿ

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/ಪ್ರಕಟಿಸು": ["ಶೀರ್ಷಿಕೆ", "ಅಮೂರ್ತ", "2026-07-27"]
};

// ನಿರ್ದಿಷ್ಟಪಡಿಸಿದ ಲೇಖನದ ದೇಹವನ್ನು ಲೋಡ್ ಮಾಡಲು ಬದಲಿಸಿ (ಪಟ್ಟಿಗೆ ಹಿಂತಿರುಗಲು ಖಾಲಿ ಸ್ಟ್ರಿಂಗ್ ಅನ್ನು ಪಾಸ್ ಮಾಡಿ)
blog.load("2026/publish");
</script>
```

## ಇಂಟರ್ಫೇಸ್ ನಿಯತಾಂಕಗಳು

### ಗುಣಲಕ್ಷಣಗಳು ಮತ್ತು ವಿಧಾನಗಳು

- `blog.prefix`: ಲೇಖನ ಲಿಂಕ್ ಪೂರ್ವಪ್ರತ್ಯಯವನ್ನು ಪಡೆಯಿರಿ ಅಥವಾ ಹೊಂದಿಸಿ (ಉದಾಹರಣೆಗೆ `"/blog/"`)
- `blog.mdUrl`: ಮಾರ್ಕ್‌ಡೌನ್ ಲೇಖನದ ವಿಳಾಸ ರಚನೆ ಕಾರ್ಯವನ್ನು ಪಡೆಯಿರಿ ಅಥವಾ ಹೊಂದಿಸಿ `(key, lang) => url`
- `blog._`: ಲೇಖನ ಪಟ್ಟಿ ಮೆಟಾಡೇಟಾ ನಿಘಂಟನ್ನು `{ [key]: [title, summary, date] }` ಪಡೆಯಿರಿ ಅಥವಾ ಹೊಂದಿಸಿ
- `blog.load(key)`: ನಿರ್ದಿಷ್ಟಪಡಿಸಿದ ಕೀಲಿಯ ಲೇಖನದ ವಿಷಯವನ್ನು ಲೋಡ್ ಮಾಡಲು ಬದಲಿಸಿ, ಬ್ಲಾಗ್ ಪಟ್ಟಿಗೆ ಹಿಂತಿರುಗಲು ಖಾಲಿ ಸ್ಟ್ರಿಂಗ್ ಅನ್ನು ಪಾಸ್ ಮಾಡಿ `""`
