# ब्लग पोस्ट घटक

- **स्वचालित वर्ष समूहीकरण**: स्वचालित रूपमा लेख मिति अनुसार वर्ष वर्गीकरण गर्नुहोस्, र तिनीहरूलाई वर्ष अनुसार उल्टो क्रममा व्यवस्थित गर्नुहोस्।
- **सरलीकृत मिति ढाँचा**: प्रदर्शन गर्दा स्वचालित रूपमा वर्ष उपसर्ग हटाउनुहोस्, र केवल महिना र दिन प्रदर्शन गर्नुहोस्।
- **मार्कडाउन सारांश र पाठ**: बिल्ट-इन सूची सारांश पूर्वावलोकन र एकल लेख पूर्ण पाठ रेन्डरिङ
- **ग्रेडियन्ट त्रि-आयामी शीर्षक**: हेडलाइन र रिलीज मिति प्रदर्शन गर्न `H1Txt` एकीकृत गर्नुहोस्

## डेमो प्रयोग गर्नुहोस्

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "२०२६/प्रकाशन": ["शीर्षक", "संक्षेप", "२०२६-०७-२७"]
};

// निर्दिष्ट लेख मुख्य भाग लोड गर्न स्विच गर्नुहोस् (सूचीमा फिर्ता स्विच गर्न खाली स्ट्रिङ पास गर्नुहोस्)
blog.load("2026/publish");
</script>
```

## इन्टरफेस प्यारामिटरहरू

### गुण र विधिहरू

- `blog.prefix`: लेख लिङ्क उपसर्ग प्राप्त गर्नुहोस् वा सेट गर्नुहोस् (जस्तै `"/blog/"`)
- `blog.mdUrl`: मार्कडाउन लेख ठेगाना उत्पादन प्रकार्य प्राप्त वा सेट गर्नुहोस् `(key, lang) => url`
- `blog._`: प्राप्त गर्नुहोस् वा लेख सूची मेटाडेटा शब्दकोश `{ [key]: [title, summary, date] }` सेट गर्नुहोस्
- `blog.load(key)`: निर्दिष्ट कुञ्जीको लेख सामग्री लोड गर्न स्विच गर्नुहोस्, ब्लग सूचीमा फर्कन खाली स्ट्रिङ `""` पास गर्नुहोस्
