# ব্লগ পোষ্টৰ উপাদান

- **স্বয়ংক্ৰিয় বছৰৰ গোট**: প্ৰবন্ধৰ তাৰিখ অনুসৰি বছৰবোৰ স্বয়ংক্ৰিয়ভাৱে শ্ৰেণীভুক্ত কৰক, আৰু বছৰ অনুসৰি ওলোটা ক্ৰমত সজাওক
- **সৰলীকৃত তাৰিখ বিন্যাস**: প্ৰদৰ্শন কৰাৰ সময়ত বছৰৰ উপসৰ্গটো স্বয়ংক্ৰিয়ভাৱে আঁতৰাওক, আৰু কেৱল মাহ আৰু দিন প্ৰদৰ্শন কৰক
- **মাৰ্কডাউন সাৰাংশ আৰু লিখনী**: বিল্ট-ইন তালিকা সাৰাংশ পূৰ্বদৰ্শন আৰু একক প্ৰবন্ধ সম্পূৰ্ণ লিখনী ৰেণ্ডাৰ
- **গ্ৰেডিয়েন্ট ত্ৰিমাত্ৰিক শিৰোনাম**: শিৰোনাম আৰু মুক্তিৰ তাৰিখ প্ৰদৰ্শন কৰিবলৈ `H1Txt` সংহতি কৰক

## ডেমো ব্যৱহাৰ কৰক

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "২০২৬/প্ৰকাশ": ["শিৰোনাম", "বিমূৰ্ত", "২০২৬-০৭-২৭"]
};

// ধাৰ্য্য কৰা প্ৰবন্ধৰ মূখ্য অংশ লোড কৰিবলে সলনি কৰক (তালিকালৈ ঘূৰি যাবলৈ এটা খালী স্ট্ৰিং পাছ কৰক)
blog.load("2026/publish");
</script>
```

## আন্তঃপৃষ্ঠ প্ৰাচলসমূহ

### ধৰ্ম আৰু পদ্ধতি

- `blog.prefix`: প্ৰবন্ধৰ সংযোগ উপসৰ্গ (যেনে `"/blog/"`) লাভ কৰক বা নিৰ্ধাৰণ কৰক
- `blog.mdUrl`: মাৰ্কডাউন প্ৰবন্ধ ঠিকনা সৃষ্টি ফলন `(key, lang) => url` পাওক বা সংহতি কৰক
- `blog._`: প্ৰবন্ধ তালিকা মেটাডাটা অভিধান `{ [key]: [title, summary, date] }` পাওক বা সংহতি কৰক
- `blog.load(key)`: ধাৰ্য্য কৰা কি'ৰ প্ৰবন্ধৰ বিষয়বস্তু লোড কৰিবলৈ সলনি কৰক, ব্লগ তালিকালৈ ঘূৰি যাবলৈ এটা খালী ষ্ট্ৰিং `""` পাছ কৰক
