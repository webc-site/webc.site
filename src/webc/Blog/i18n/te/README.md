# బ్లాగ్ పోస్ట్ భాగం

- **ఆటోమేటిక్ ఇయర్ గ్రూపింగ్**: ఆర్టికల్ తేదీ ప్రకారం సంవత్సరాలను స్వయంచాలకంగా వర్గీకరించండి మరియు వాటిని సంవత్సరానికి రివర్స్ ఆర్డర్‌లో అమర్చండి
- **సరళీకృత తేదీ ఆకృతి**: ప్రదర్శించేటప్పుడు స్వయంచాలకంగా సంవత్సరం ఉపసర్గను తీసివేసి, నెల మరియు రోజును మాత్రమే ప్రదర్శించండి
- **మార్క్‌డౌన్ సారాంశం మరియు వచనం**: అంతర్నిర్మిత జాబితా సారాంశం ప్రివ్యూ మరియు సింగిల్ ఆర్టికల్ పూర్తి టెక్స్ట్ రెండరింగ్
- **గ్రేడియంట్ త్రీ-డైమెన్షనల్ టైటిల్**: హెడ్‌లైన్ మరియు విడుదల తేదీని ప్రదర్శించడానికి `H1Txt`ని ఇంటిగ్రేట్ చేయండి

## డెమో ఉపయోగించండి

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/ప్రచురించండి": ["శీర్షిక", "అబ్‌స్ట్రాక్ట్", "2026-07-27"]
};

// పేర్కొన్న ఆర్టికల్ బాడీని లోడ్ చేయడానికి మారండి (జాబితాకు తిరిగి మారడానికి ఖాళీ స్ట్రింగ్‌ను పాస్ చేయండి)
blog.load("2026/publish");
</script>
```

## ఇంటర్ఫేస్ పారామితులు

### లక్షణాలు మరియు పద్ధతులు

- `blog.prefix`: కథనం లింక్ ప్రిఫిక్స్ (`"/blog/"` వంటివి) పొందండి లేదా సెట్ చేయండి
- `blog.mdUrl`: మార్క్‌డౌన్ ఆర్టికల్ అడ్రస్ జనరేషన్ ఫంక్షన్ `(key, lang) => url`ని పొందండి లేదా సెట్ చేయండి
- `blog._`: కథనం జాబితా మెటాడేటా నిఘంటువు `{ [key]: [title, summary, date] }`ని పొందండి లేదా సెట్ చేయండి
- `blog.load(key)`: పేర్కొన్న కీలోని కథన కంటెంట్‌ను లోడ్ చేయడానికి మారండి, బ్లాగ్ జాబితాకు తిరిగి మారడానికి ఖాళీ స్ట్రింగ్‌ను `""` పాస్ చేయండి
