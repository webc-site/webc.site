# Компонент за публикация в блог

- **Автоматично групиране на годините**: Автоматично класифициране на годините според датата на статията и подреждането им в обратен ред по години
- **Опростен формат на датата**: Автоматично премахване на префикса на годината при показване и показване само на месеца и деня
- **Резюме и текст на Markdown**: Вграден преглед на резюме на списъка и изобразяване на пълен текст на една статия
- **Градиентно триизмерно заглавие**: Интегрирайте `H1Txt` за показване на заглавието и датата на пускане

## Използвайте демонстрацията

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/публикувай": ["заглавие", "резюме", "27.07.2026"]
};

// Превключете за зареждане на указаното тяло на статия (подайте празен низ, за ​​да превключите обратно към списъка)
blog.load("2026/publish");
</script>
```

## Параметри на интерфейса

### Свойства и методи

- `blog.prefix`: Вземете или задайте префикса на връзката към статия (като `"/blog/"`)
- `blog.mdUrl`: Вземете или задайте функцията за генериране на адрес на статия в Markdown `(key, lang) => url`
- `blog._`: Вземете или задайте речника с метаданни на списъка със статии `{ [key]: [title, summary, date] }`
- `blog.load(key)`: Превключете, за да заредите съдържанието на статията на посочения ключ, подайте празен низ `""`, за да превключите обратно към списъка с блогове
