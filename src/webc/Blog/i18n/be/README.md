# Кампанент паведамлення ў блогу

- **Аўтаматычная групаванне па гадах**: аўтаматычна класіфікаваць гады ў адпаведнасці з датай артыкула і размясціць іх у зваротным парадку па гадах
- **Спрошчаны фармат даты**: аўтаматычна выдаляць прэфікс года пры адлюстраванні і адлюстроўваць толькі месяц і дзень
- **Зводка ўцэнкі і тэкст**: убудаваны папярэдні прагляд зводкі спісу і поўны тэкст аднаго артыкула
- **Градыентны трохмерны загаловак**: інтэгруйце `H1Txt` для адлюстравання загалоўка і даты выпуску

## Выкарыстоўвайце дэма

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/апублікаваць": ["назва", "анатацыя", "2026-07-27"]
};

// Пераключэнне для загрузкі азначанага цела артыкула (перадайце пусты радок, каб пераключыцца назад у спіс)
blog.load("2026/publish");
</script>
```

## Параметры інтэрфейсу

### Уласцівасці і метады

- `blog.prefix`: атрымаць або ўсталяваць прэфікс спасылкі на артыкул (напрыклад, `"/blog/"`)
- `blog.mdUrl`: атрымаць або ўсталяваць функцыю генерацыі адрасоў артыкула Markdown `(key, lang) => url`
- `blog._`: атрымаць або ўсталяваць слоўнік метаданых спісу артыкулаў `{ [key]: [title, summary, date] }`
- `blog.load(key)`: пераключыцца, каб загрузіць змесціва артыкула з указаным ключом, перадайце пусты радок `""`, каб пераключыцца назад у спіс блогаў
