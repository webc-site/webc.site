# ဘလော့ပို့စ် အစိတ်အပိုင်း

- **အလိုအလျောက်နှစ်ကို အုပ်စုဖွဲ့ခြင်း**- ဆောင်းပါးရက်စွဲအရ နှစ်များကို အလိုအလျောက် အမျိုးအစားခွဲကာ ၎င်းတို့ကို နှစ်အလိုက် ပြောင်းပြန်အစီအစဥ်ဖြင့် စီစဉ်ပါ။
- **ရိုးရှင်းသောရက်စွဲပုံစံ**- ပြသသောအခါတွင် နှစ်ရှေ့ဆက်ကို အလိုအလျောက်ဖယ်ရှားပြီး လနှင့်နေ့ကိုသာ ပြသသည်
- **Markdown အကျဉ်းချုပ်နှင့် စာသား**- ထည့်သွင်းထားသော စာရင်းအကျဉ်းချုပ် အစမ်းကြည့်ရှုခြင်းနှင့် ဆောင်းပါးတစ်ပုဒ်တည်းကို ပြီးပြည့်စုံသော စာသားပြန်ဆိုခြင်း
- ** Gradient သုံးဖက်မြင် ခေါင်းစဉ်**- ခေါင်းစီးနှင့် ထွက်ရှိမည့်ရက်စွဲကို ပြသရန် `H1Txt` ပေါင်းစပ်ပါ

## ဒီမိုကိုသုံးပါ။

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/ထုတ်ဝေခြင်း"- ["ခေါင်းစဉ်", "စိတ္တဇ", "2026-07-27"]
};

// သတ်မှတ်ထားသော ဆောင်းပါးကိုယ်ထည်ကို တင်ရန် ပြောင်းပါ (စာရင်းသို့ ပြန်ပြောင်းရန် ဗလာစာကြောင်းတစ်ခုကို ဖြတ်သန်းပါ)
blog.load("2026/publish");
</script>
```

## မျက်နှာပြင်ဘောင်များ

### ဂုဏ်သတ္တိများနှင့်နည်းလမ်းများ

- `blog.prefix`- ဆောင်းပါးလင့်ခ်ရှေ့ဆက်ကို ရယူပါ သို့မဟုတ် သတ်မှတ်ပါ (ဥပမာ `"/blog/"`)
- `blog.mdUrl`- Markdown ဆောင်းပါး လိပ်စာ ဖန်တီးမှု လုပ်ဆောင်ချက် `(key, lang) => url`ကို ရယူပါ သို့မဟုတ် သတ်မှတ်ပါ။
- `blog._`- ဆောင်းပါးစာရင်း မက်တာဒေတာအဘိဓာန် `{ [key]: [title, summary, date] }`ကို ရယူပါ သို့မဟုတ် သတ်မှတ်ပါ။
- `blog.load(key)`- သတ်မှတ်ထားသော သော့၏ ဆောင်းပါးအကြောင်းအရာကို တင်ရန် ပြောင်းပါ၊ ဘလော့ဂ်စာရင်းသို့ ပြန်ပြောင်းရန် ဗလာစာကြောင်းတစ်ခု `""`ကို ဖြတ်သန်းပါ။
