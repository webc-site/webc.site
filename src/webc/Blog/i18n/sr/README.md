# Компонента поста на блогу

- **Аутоматско груписање година**: Аутоматски класификујте године према датуму чланка и поређајте их обрнутим редоследом по годинама
- **Поједностављени формат датума**: Аутоматски уклоните префикс године приликом приказивања и прикажите само месец и дан
- **Резиме и текст за означавање**: Уграђени преглед резимеа листе и комплетно приказивање текста једног чланка
- **Градијентни тродимензионални наслов**: Интегришите <б ид="1"> да бисте приказали наслов и датум објављивања

## Користите демо

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/објави": ["наслов", "сажетак", "2026-07-27"]
};

// Пребаците се да бисте учитали наведено тело чланка (проследите празан стринг да бисте се вратили на листу)
blog.load("2026/publish");
</script>
```

## Параметри интерфејса

### Особине и методе

- <б ид="1">: Преузмите или подесите префикс везе до чланка (као што је <б ид="2">)
- <б ид="1">: Преузмите или подесите функцију генерисања адресе чланка Маркдовн <б ид="2">
- <б ид="1">: Преузмите или подесите речник метаподатака листе чланака <б ид="2">
- <б ид="1">: Пребаците се да бисте учитали садржај чланка наведеног кључа, проследите празан стринг <б ид="2"> да бисте се вратили на листу блогова
