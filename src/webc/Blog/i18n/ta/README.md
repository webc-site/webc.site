# வலைப்பதிவு இடுகை கூறு

- **தானியங்கி ஆண்டுக் குழுவாக்கம்**: கட்டுரைத் தேதியின்படி ஆண்டுகளைத் தானாக வகைப்படுத்தி, ஆண்டு வாரியாக அவற்றைத் தலைகீழ் வரிசையில் வரிசைப்படுத்துங்கள்
- **எளிமைப்படுத்தப்பட்ட தேதி வடிவம்**: காண்பிக்கும் போது ஆண்டு முன்னொட்டை தானாக அகற்றி, மாதம் மற்றும் நாளை மட்டும் காட்டவும்
- **மார்க்டவுன் சுருக்கம் மற்றும் உரை**: உள்ளமைக்கப்பட்ட பட்டியல் சுருக்க முன்னோட்டம் மற்றும் ஒற்றை கட்டுரை முழுமையான உரை ரெண்டரிங்
- **கிரேடியன்ட் முப்பரிமாண தலைப்பு**: தலைப்பு மற்றும் வெளியீட்டு தேதியைக் காட்ட `H1Txt`ஐ ஒருங்கிணைக்கவும்

## டெமோவைப் பயன்படுத்தவும்

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/வெளியிடு": ["தலைப்பு", "சுருக்கம்", "2026-07-27"]
};

// குறிப்பிட்ட கட்டுரையின் உள்ளடக்கத்தை ஏற்றுவதற்கு மாறவும் (பட்டியலுக்கு மீண்டும் மாற ஒரு வெற்று சரத்தை அனுப்பவும்)
blog.load("2026/publish");
</script>
```

## இடைமுக அளவுருக்கள்

### பண்புகள் மற்றும் முறைகள்

- `blog.prefix`: கட்டுரை இணைப்பு முன்னொட்டைப் பெறவும் அல்லது அமைக்கவும் (`"/blog/"` போன்றவை)
- `blog.mdUrl`: மார்க் டவுன் கட்டுரை முகவரி உருவாக்க செயல்பாட்டைப் பெறவும் அல்லது அமைக்கவும் `(key, lang) => url`
- `blog._`: கட்டுரை பட்டியல் மெட்டாடேட்டா அகராதியை `{ [key]: [title, summary, date] }` பெறவும் அல்லது அமைக்கவும்
- `blog.load(key)`: குறிப்பிட்ட விசையின் கட்டுரை உள்ளடக்கத்தை ஏற்றுவதற்கு மாறவும், வலைப்பதிவு பட்டியலுக்கு மாற, `""` என்ற வெற்று சரத்தை அனுப்பவும்
