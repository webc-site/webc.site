# ब्लॉग पोस्ट घटक

- **स्वयंचलित वर्ष गटबद्धता**: लेखाच्या तारखेनुसार वर्षांचे स्वयंचलितपणे वर्गीकरण करा आणि वर्षानुसार उलट क्रमाने त्यांची व्यवस्था करा
- **सरलीकृत तारीख स्वरूप**: प्रदर्शित करताना स्वयंचलितपणे वर्ष उपसर्ग काढून टाका आणि फक्त महिना आणि दिवस प्रदर्शित करा
- **मार्कडाउन सारांश आणि मजकूर**: अंगभूत सूची सारांश पूर्वावलोकन आणि एकल लेख पूर्ण मजकूर प्रस्तुतीकरण
- **ग्रेडियंट त्रि-आयामी शीर्षक**: शीर्षक आणि प्रकाशन तारीख प्रदर्शित करण्यासाठी `H1Txt` समाकलित करा

## डेमो वापरा

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/प्रकाशित": ["शीर्षक", "अमूर्त", "2026-07-27"]
};

// निर्दिष्ट लेखाचा मुख्य भाग लोड करण्यासाठी स्विच करा (सूचीवर परत जाण्यासाठी रिक्त स्ट्रिंग पास करा)
blog.load("2026/publish");
</script>
```

## इंटरफेस पॅरामीटर्स

### गुणधर्म आणि पद्धती

- `blog.prefix`: लेख लिंक उपसर्ग मिळवा किंवा सेट करा (जसे की `"/blog/"`)
- `blog.mdUrl`: मार्कडाउन लेख ॲड्रेस जनरेशन फंक्शन मिळवा किंवा सेट करा `(key, lang) => url`
- `blog._`: लेख सूची मेटाडेटा शब्दकोश मिळवा किंवा सेट करा `{ [key]: [title, summary, date] }`
- `blog.load(key)`: निर्दिष्ट कीची लेख सामग्री लोड करण्यासाठी स्विच करा, ब्लॉग सूचीवर परत जाण्यासाठी रिक्त स्ट्रिंग `""` पास करा
