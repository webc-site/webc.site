# Բլոգի գրառման բաղադրիչ

- **Տարվա ավտոմատ խմբավորում**. ավտոմատ կերպով դասակարգել տարիները ըստ հոդվածի ամսաթվի և դասավորել դրանք հակառակ հերթականությամբ ըստ տարիների
- **Ամսաթվի պարզեցված ձևաչափ**. ցուցադրելիս ինքնաբերաբար հեռացրեք տարվա նախածանցը և ցուցադրեք միայն ամիսն ու օրը
- **Նշման ամփոփում և տեքստ**. Ներկառուցված ցուցակի ամփոփման նախադիտում և մեկ հոդվածի ամբողջական տեքստի մատուցում
- **Գրադիենտ եռաչափ վերնագիր**. Ինտեգրել `H1Txt` վերնագիրը և թողարկման ամսաթիվը ցուցադրելու համար

## Օգտագործեք ցուցադրությունը

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  «2026/հրատարակել»՝ [«վերնագիր», «վերացական», «2026-07-27»]
};

// Անցնել՝ նշված հոդվածի մարմինը բեռնելու համար (անցեք դատարկ տող՝ ցուցակին վերադառնալու համար)
blog.load("2026/publish");
</script>
```

## Ինտերֆեյսի պարամետրեր

### Հատկություններ և մեթոդներ

- `blog.prefix`. Ստացեք կամ սահմանեք հոդվածի հղման նախածանցը (օրինակ՝ `"/blog/"`)
- `blog.mdUrl`. Ստացեք կամ սահմանեք Markdown հոդվածի հասցեի ստեղծման գործառույթը `(key, lang) => url`
- `blog._`. Ստացեք կամ սահմանեք հոդվածների ցանկի մետատվյալների բառարանը `{ [key]: [title, summary, date] }`
- `blog.load(key)`. փոխարկեք նշված բանալիով հոդվածի բովանդակությունը բեռնելու համար, անցեք դատարկ տող `""`՝ բլոգերի ցուցակին վերադառնալու համար:
