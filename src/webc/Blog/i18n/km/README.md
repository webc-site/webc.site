# សមាសធាតុប្រកាសប្លុក

- **ការដាក់ជាក្រុមឆ្នាំដោយស្វ័យប្រវត្តិ**៖ បែងចែកឆ្នាំដោយស្វ័យប្រវត្តិទៅតាមកាលបរិច្ឆេទអត្ថបទ ហើយរៀបចំពួកវាតាមលំដាប់បញ្ច្រាសតាមឆ្នាំ។
- **ទម្រង់កាលបរិច្ឆេទសាមញ្ញ**៖ យកបុព្វបទឆ្នាំចេញដោយស្វ័យប្រវត្តិនៅពេលបង្ហាញ ហើយបង្ហាញតែខែ និងថ្ងៃប៉ុណ្ណោះ។
- **សេចក្តីសង្ខេប និងអត្ថបទកំណត់សម្គាល់**៖ ការមើលសង្ខេបបញ្ជីដែលភ្ជាប់មកជាមួយ និងបង្ហាញអត្ថបទពេញលេញ
- **ចំណងជើងបីវិមាត្រពណ៌ជម្រាល**៖ រួមបញ្ចូល `H1Txt` ដើម្បីបង្ហាញចំណងជើង និងកាលបរិច្ឆេទចេញផ្សាយ

## ប្រើការបង្ហាញ

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/publish": ["title", "abstract", "2026-07-27"]
};

// ប្ដូរ​ទៅ​ផ្ទុក​អត្ថបទ​ដែល​បាន​បញ្ជាក់ (ឆ្លង​ខ្សែ​អក្សរ​ទទេ​ដើម្បី​ប្ដូរ​ទៅ​បញ្ជី​វិញ)
blog.load("2026/publish");
</script>
```

## ប៉ារ៉ាម៉ែត្រចំណុចប្រទាក់

### លក្ខណៈសម្បត្តិនិងវិធីសាស្រ្ត

- `blog.prefix`៖ ទទួល ឬកំណត់បុព្វបទតំណអត្ថបទ (ដូចជា `"/blog/"`)
- `blog.mdUrl`៖ ទទួល ឬកំណត់មុខងារបង្កើតអាសយដ្ឋានអត្ថបទ Markdown `(key, lang) => url`
- `blog._`៖ ទទួល ឬកំណត់បញ្ជីអត្ថបទ វចនានុក្រមទិន្នន័យមេតា `{ [key]: [title, summary, date] }`
- `blog.load(key)`៖ ប្ដូរ​ទៅ​ផ្ទុក​ខ្លឹមសារ​អត្ថបទ​នៃ​សោ​ដែល​បាន​បញ្ជាក់ ឆ្លង​ខ្សែ​អក្សរ​ទទេ `""` ដើម្បី​ប្ដូរ​ទៅ​បញ្ជី​ប្លក់​វិញ
