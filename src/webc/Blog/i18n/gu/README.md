# બ્લોગ પોસ્ટ ઘટક

- **આપમેળે વર્ષનું જૂથીકરણ**: લેખની તારીખ પ્રમાણે વર્ષોનું આપમેળે વર્ગીકરણ કરો અને વર્ષ પ્રમાણે તેને વિપરીત ક્રમમાં ગોઠવો
- **સરળ તારીખ ફોર્મેટ**: પ્રદર્શિત કરતી વખતે વર્ષનો ઉપસર્ગ આપમેળે દૂર કરો અને માત્ર મહિનો અને દિવસ દર્શાવો
- **માર્કડાઉન સારાંશ અને ટેક્સ્ટ**: બિલ્ટ-ઇન સૂચિ સારાંશ પૂર્વાવલોકન અને એક લેખ સંપૂર્ણ ટેક્સ્ટ રેન્ડરિંગ
- **ગ્રેડિયન્ટ ત્રિ-પરિમાણીય શીર્ષક**: હેડલાઇન અને પ્રકાશન તારીખ દર્શાવવા માટે `H1Txt` એકીકૃત કરો

## ડેમોનો ઉપયોગ કરો

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/પ્રકાશિત": ["શીર્ષક", "અમૂર્ત", "2026-07-27"]
};

// ઉલ્લેખિત લેખના મુખ્ય ભાગને લોડ કરવા માટે સ્વિચ કરો (સૂચિ પર પાછા સ્વિચ કરવા માટે ખાલી સ્ટ્રિંગ પસાર કરો)
blog.load("2026/publish");
</script>
```

## ઇન્ટરફેસ પરિમાણો

### ગુણધર્મો અને પદ્ધતિઓ

- `blog.prefix`: લેખની લિંક ઉપસર્ગ મેળવો અથવા સેટ કરો (જેમ કે `"/blog/"`)
- `blog.mdUrl`: માર્કડાઉન લેખ એડ્રેસ જનરેશન ફંક્શન મેળવો અથવા સેટ કરો `(key, lang) => url`
- `blog._`: લેખ સૂચિ મેટાડેટા શબ્દકોશ મેળવો અથવા સેટ કરો `{ [key]: [title, summary, date] }`
- `blog.load(key)`: ઉલ્લેખિત કીની લેખ સામગ્રી લોડ કરવા માટે સ્વિચ કરો, બ્લોગ સૂચિ પર પાછા સ્વિચ કરવા માટે ખાલી સ્ટ્રિંગ `""` પસાર કરો
