# רכיב פוסט בבלוג

- **קיבוץ שנה אוטומטי**: סיווג שנים אוטומטית לפי תאריך המאמר, וסדר אותן בסדר הפוך לפי שנה
- **פורמט תאריך פשוט**: הסר אוטומטית את קידומת השנה בעת הצגתו, והצג רק את החודש והיום
- **סיכום סימון וטקסט**: תצוגה מקדימה מובנית של סיכום רשימה ועיבוד טקסט מלא של מאמר בודד
- **כותרת תלת מימדית שיפוע**: שלב את `H1Txt` כדי להציג את הכותרת ותאריך השחרור

## השתמש בהדגמה

```html
<c-blog></c-blog>

<script type="module">
import "webc.site/Blog.js";

const blog = document.querySelector("c-blog");
blog.prefix = "/blog/";
blog.mdUrl = (key, lang) => "/doc/" + lang + "/blog/" + key + ".md";
blog._ = {
  "2026/פרסם": ["כותרת", "תקציר", "2026-07-27"]
};

// עבור לטעינת גוף המאמר שצוין (עבר מחרוזת ריקה כדי לחזור לרשימה)
blog.load("2026/publish");
</script>
```

## פרמטרים של ממשק

### מאפיינים ושיטות

- `blog.prefix`: קבל או הגדר את קידומת הקישור למאמר (כגון `"/blog/"`)
- `blog.mdUrl`: קבל או הגדר את פונקציית יצירת כתובת מאמר Markdown `(key, lang) => url`
- `blog._`: קבל או הגדר את מילון המטא נתונים של רשימת המאמרים `{ [key]: [title, summary, date] }`
- `blog.load(key)`: עבור לטעינת תוכן המאמר של המפתח שצוין, העבר מחרוזת ריקה `""` כדי לחזור לרשימת הבלוגים
