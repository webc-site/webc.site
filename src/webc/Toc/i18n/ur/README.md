# ڈائرکٹری نیویگیشن جزو

- **ریسپانسیو دراز**: چوڑی اسکرین میں سائڈبار ڈسپلے کریں، خود بخود تنگ اسکرین میں سمٹ جائیں اور `c-side` دراز اور ٹائٹل ٹرگر بٹن کے ساتھ تعاون کریں
- **ملٹی لینگویج ڈرائیور**: آبجیکٹ لغت یا کثیر زبان کے افعال کو سپورٹ کرتا ہے، خود بخود زبان کی تبدیلی کا جواب دیتا ہے
- **خودکار ذیلی ڈائرکٹری**: ثانوی ڈائرکٹری بنانے اور ہیش ویو پورٹ سکرولنگ ہائی لائٹ کو مانیٹر کرنے کے لیے ٹارگٹ کنٹینر میں `h1`~`h6` عنوانات کو خودکار طور پر پارس کریں۔
- **غیر مطابقت پذیر لوڈنگ**: ڈائرکٹری آئٹم پر کلک کریں تاکہ مارک ڈاون متن کو غیر مطابقت پذیر طریقے سے حاصل کیا جا سکے اور اسے مواد کے علاقے میں داخل کریں، `Ing` لوڈنگ اینیمیشن ڈسپلے کرتے ہوئے

## ڈیمو استعمال کریں۔

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "استعمال": "اجزاء استعمال کریں"
});
</script>
```

## انٹرفیس کے پیرامیٹرز

### خصوصیات اور طریقے

- `toc.prefix`: روٹنگ پریفکس سٹرنگ حاصل کریں یا سیٹ کریں (جیسے `"doc"`، ٹریلنگ سلیش اختیاری ہے)، `README` کلید خود بخود خالی راستے پر نقش ہو جائے گی (یعنی سابقہ ​​ہی)
- `toc.li`: ڈائرکٹری ملٹی لینگویج جنریشن فنکشن `(lang) => ({ key: title })` حاصل کریں یا سیٹ کریں۔
- `toc.mdUrl`: مارک ڈاؤن URL جنریشن فنکشن حاصل کریں یا سیٹ کریں `(key, lang) => url`
- `toc.target`: متعلقہ ٹارگٹ رینڈرنگ نوڈ (جیسے `c-md`) حاصل کریں یا سیٹ کریں۔ اگر متعین نہیں کیا گیا ہے، تو یہ خود بخود `c-md` / `main` / `article` تلاش کر لے گا۔
- `toc.load(key)`: کلید کے مطابق دستاویز کی لوڈنگ اور ڈائریکٹری کی توسیع کو دستی طور پر متحرک کریں
- `toc.sync()`: موجودہ ٹارگٹ نوڈ میں ٹائٹل کو دستی طور پر دوبارہ پارس کریں، سیکنڈری ڈائرکٹری کو سنکرونائز کریں اور اسٹیٹس کو ہائی لائٹ کریں۔
