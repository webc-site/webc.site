# ডাইৰেকটৰি নেভিগেচন উপাদান

- **প্ৰতিক্ৰিয়াশীল ড্ৰয়াৰ**: বহল পৰ্দাত চাইডবাৰ প্ৰদৰ্শন কৰক, সংকীৰ্ণ পৰ্দাত স্বয়ংক্ৰিয়ভাৱে ভাঙি যাওক আৰু `c-side` ড্ৰয়াৰ আৰু শিৰোনাম ট্ৰিগাৰ বুটামৰ সৈতে সহযোগ কৰক
- **বহু-ভাষা ড্ৰাইভাৰ**: বস্তু অভিধান বা বহু-ভাষা ফলনসমূহ সমৰ্থন কৰে, স্বয়ংক্ৰিয়ভাৱে ভাষা সলনিৰ প্ৰতি সঁহাৰি জনায়
- **স্বয়ংক্ৰিয় উপডাইৰেকটৰি**: এটা গৌণ পঞ্জিকা সৃষ্টি কৰিবলে আৰু হেচ দৰ্শনপৰ্ট স্ক্ৰলিং হাইলাইট নিৰীক্ষণ কৰিবলে লক্ষ্য ধাৰকত `h1`~`h6` শিৰোনামসমূহ স্বয়ংক্ৰিয়ভাৱে বিশ্লেষণ কৰক।
- **এচিংক্ৰ'নাছ লোডিং**: এটা ডাইৰেকটৰি বস্তুত ক্লিক কৰক স্বয়ংক্ৰিয়ভাৱে মাৰ্কডাউন লিখনী এচিনক্ৰ'নাছভাৱে লাভ কৰিবলৈ আৰু ইয়াক বিষয়বস্তু অঞ্চলত ইনজেকচন কৰিবলৈ, `Ing` লোডিং এনিমেচন প্ৰদৰ্শন কৰি

## ডেমো ব্যৱহাৰ কৰক

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "ব্যৱহাৰ": "উপাদান ব্যৱহাৰ"
});
</script>
```

## আন্তঃপৃষ্ঠ প্ৰাচলসমূহ

### ধৰ্ম আৰু পদ্ধতি

- `toc.prefix`: ৰাউটিং উপসৰ্গ ষ্ট্ৰিং লওক বা সংহতি কৰক (যেনে `"doc"`, পিছৰ স্লেচ বৈকল্পিক), `README` কি' স্বয়ংক্ৰিয়ভাৱে এটা খালী পথলৈ মেপ কৰা হ'ব (অৰ্থাৎ উপসৰ্গটো নিজেই)
- `toc.li`: পঞ্জিকা বহু-ভাষা সৃষ্টি ফলন `(lang) => ({ key: title })` পাওক বা সংহতি কৰক
- `toc.mdUrl`: মাৰ্কডাউন URL সৃষ্টি ফলন `(key, lang) => url` পাওক বা সংহতি কৰক
- `toc.target`: সংশ্লিষ্ট লক্ষ্য ৰেণ্ডাৰ ন'ড (যেনে `c-md`) লওক বা সংহতি কৰক। যদি ধাৰ্য্য কৰা হোৱা নাই, ই স্বয়ংক্ৰিয়ভাৱে `c-md` / `main` / `article` বিচাৰি পাব
- `toc.load(key)`: চাবিৰ সৈতে সংগতি ৰাখি দস্তাবেজ লোডিং আৰু পঞ্জিকা সম্প্ৰসাৰণ হস্তচালিতভাৱে ট্ৰিগাৰ কৰক
- `toc.sync()`: বৰ্তমান লক্ষ্য ন'ডত শিৰোনামক হস্তচালিতভাৱে পুনৰ বিশ্লেষণ কৰক, গৌণ পঞ্জিকা সমন্বয় কৰক আৰু অৱস্থা হাইলাইট কৰক
