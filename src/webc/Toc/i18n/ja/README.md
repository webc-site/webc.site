# ディレクトリナビゲーションコンポーネント

- **レスポンシブドロワー**: ワイドスクリーンではサイドバーを表示し、狭いスクリーンでは自動的に折りたたみ、`c-side`ドロワーとタイトルトリガーボタンと連携します。
- **多言語ドライバー**: オブジェクト辞書または多言語機能をサポートし、言語の切り替えに自動的に対応します。
- **自動サブディレクトリ**: ターゲット コンテナ内の `h1`~`h6` タイトルを自動的に解析して 2 番目のディレクトリを生成し、ハッシュ ビューポートのスクロール ハイライトを監視します。
- **非同期読み込み**: ディレクトリ項目をクリックすると、マークダウン テキストが非同期で自動的に取得され、コンテンツ領域に挿入され、`Ing`読み込みアニメーションが表示されます。

## デモを使用する

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "コンポーネントを使用"
});
</script>
```

## インターフェースパラメータ

### プロパティとメソッド

- `toc.prefix`: ルーティング プレフィックス文字列 (`"doc"` など、末尾のスラッシュはオプション) を取得または設定します。`README` キーは空のパス (つまり、プレフィックス自体) に自動的にマッピングされます。
- `toc.li`: ディレクトリの多言語生成関数を取得または設定します `(lang) => ({ key: title })`
- `toc.mdUrl`: Markdown URL 生成関数を取得または設定します `(key, lang) => url`
- `toc.target`: 関連付けられたターゲット レンダリング ノード (`c-md` など) を取得または設定します。指定しない場合は、`c-md` / `main` / `article` が自動的に検索されます。
- `toc.load(key)`: キーに対応するドキュメントの読み込みとディレクトリ展開を手動でトリガーします
- `toc.sync()`: 現在のターゲット ノードのタイトルを手動で再解析し、セカンダリ ディレクトリを同期してステータスを強調表示します。
