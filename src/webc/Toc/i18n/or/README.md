# ଡିରେକ୍ଟୋରୀ ନାଭିଗେସନ୍ ଉପାଦାନ |

- ** ପ୍ରତିକ୍ରିୟାଶୀଳ ଡ୍ରୟର **: ପ୍ରଶସ୍ତ ପରଦାରେ ପାର୍ଶ୍ୱ ଦଣ୍ଡିକା ପ୍ରଦର୍ଶନ କରନ୍ତୁ, ସଂକୀର୍ଣ୍ଣ ପରଦାରେ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଭୁଶୁଡ଼ି ପଡ଼ନ୍ତୁ ଏବଂ `c-side` ଡ୍ରୟର ଏବଂ ଟାଇଟଲ୍ ଟ୍ରିଗର ବଟନ୍ ସହିତ ସହଯୋଗ କରନ୍ତୁ |
- ** ମଲ୍ଟି ଲାଙ୍ଗୁଏଜ୍ ଡ୍ରାଇଭର **: ଅବଜେକ୍ଟ ଅଭିଧାନ କିମ୍ବା ମଲ୍ଟି ଲାଙ୍ଗୁଏଜ୍ ଫଙ୍କସନ୍ସକୁ ସମର୍ଥନ କରେ, ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଭାଷା ସୁଇଚିଂକୁ ପ୍ରତିକ୍ରିୟା କରେ |
- ** ସ୍ୱୟଂଚାଳିତ ଉପଡିରେକ୍ଟୋରୀ **: ଏକ ଦ୍ secondary ିତୀୟ ଡିରେକ୍ଟୋରୀ ସୃଷ୍ଟି କରିବା ଏବଂ ହ୍ୟାସ୍ ଭ୍ୟୁପୋର୍ଟ ସ୍କ୍ରୋଲିଂ ହାଇଲାଇଟ୍ ଉପରେ ନଜର ରଖିବା ପାଇଁ ଲକ୍ଷ୍ୟ ପାତ୍ରରେ ଥିବା `h1` ~ `h6` ଟାଇଟଲ୍ଗୁଡ଼ିକୁ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ପାର୍ସ କରନ୍ତୁ |
- ** ଅସନ୍ତୁଳିତ ଲୋଡିଂ **: ସ୍ୱୟଂଚାଳିତ ଭାବରେ ମାର୍କଡାଉନ୍ ପାଠ୍ୟକୁ ଅସନ୍ତୁଳିତ ଭାବରେ ପାଇବା ପାଇଁ ଏକ ଡିରେକ୍ଟୋରୀ ଆଇଟମ୍ ଉପରେ କ୍ଲିକ୍ କରନ୍ତୁ ଏବଂ ଏହାକୁ `Ing` ଲୋଡିଂ ଆନିମେସନ୍ ପ୍ରଦର୍ଶନ କରି ବିଷୟବସ୍ତୁ କ୍ଷେତ୍ରରେ ଇଞ୍ଜେକ୍ସନ ଦିଅନ୍ତୁ |

## ଡେମୋ ବ୍ୟବହାର କରନ୍ତୁ |

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "ବ୍ୟବହାର": "ଉପାଦାନ ବ୍ୟବହାର"
});
</script>
```

## ଇଣ୍ଟରଫେସ୍ ପାରାମିଟରଗୁଡିକ

### ଗୁଣ ଏବଂ ପଦ୍ଧତି |

- `toc.prefix`: ରାଉଟିଙ୍ଗ୍ ଉପସର୍ଗ ଷ୍ଟ୍ରିଙ୍ଗ୍ ପ୍ରାପ୍ତ କରନ୍ତୁ କିମ୍ବା ସେଟ୍ କରନ୍ତୁ (ଯେପରିକି `"doc"`, ଟ୍ରେଲିଂ ସ୍ଲାସ୍ ଇଚ୍ଛାଧୀନ), `README` ଚାବି ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଏକ ଖାଲି ପଥରେ ମ୍ୟାପ୍ ହେବ (ଯଥା ଉପସର୍ଗ ନିଜେ) |
- `toc.li`: ମଲ୍ଟି ଭାଷା ଉତ୍ପାଦନ ଫଙ୍କସନ୍ `(lang) => ({ key: title })` ଡିରେକ୍ଟୋରୀକୁ ପ୍ରାପ୍ତ କରନ୍ତୁ କିମ୍ବା ସେଟ୍ କରନ୍ତୁ |
- `toc.mdUrl`: ମାର୍କଡାଉନ୍ URL ଉତ୍ପାଦନ କାର୍ଯ୍ୟ `(key, lang) => url` ପାଆନ୍ତୁ କିମ୍ବା ସେଟ୍ କରନ୍ତୁ |
- `toc.target`: ସଂପୃକ୍ତ ଟାର୍ଗେଟ୍ ରେଣ୍ଡରିଂ ନୋଡ୍ ପ୍ରାପ୍ତ କରନ୍ତୁ କିମ୍ବା ସେଟ୍ କରନ୍ତୁ (ଯେପରିକି `c-md`) | ଯଦି ନିର୍ଦ୍ଦିଷ୍ଟ କରାଯାଇ ନାହିଁ, ଏହା ସ୍ୱୟଂଚାଳିତ ଭାବରେ `c-md` / `main` / `article` ପାଇବ |
- `toc.load(key)`: ଚାବି ସହିତ ଡକ୍ୟୁମେଣ୍ଟ୍ ଲୋଡିଂ ଏବଂ ଡିରେକ୍ଟୋରୀ ବିସ୍ତାରକୁ ମାନୁଆଲ୍ ଟ୍ରିଗର କରନ୍ତୁ |
- `toc.sync()`: ସାମ୍ପ୍ରତିକ ଟାର୍ଗେଟ୍ ନୋଡରେ ଟାଇଟଲ୍ କୁ ମାନୁଆଲୀ ପୁନ - ପାର୍ସ କରନ୍ତୁ, ସେକେଣ୍ଡାରୀ ଡିରେକ୍ଟୋରୀକୁ ସିଙ୍କ୍ରୋନାଇଜ୍ କରନ୍ତୁ ଏବଂ ସ୍ଥିତିକୁ ହାଇଲାଇଟ୍ କରନ୍ତୁ |
