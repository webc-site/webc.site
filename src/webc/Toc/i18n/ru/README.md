# Компонент навигации по каталогу

- **Адаптивный ящик**: боковая панель отображается на широком экране, автоматически сворачивается на узком экране и взаимодействует с ящиком `c-side` и кнопкой запуска заголовка.
- **Многоязычный драйвер**: поддерживает словарь объектов или многоязычные функции, автоматически реагирует на переключение языка.
- **Автоматический подкаталог**: автоматически анализируйте заголовки `h1`~`h6` в целевом контейнере, чтобы создать дополнительный каталог и отслеживать выделение прокрутки области просмотра Hash.
- **Асинхронная загрузка**: нажмите на элемент каталога, чтобы автоматически асинхронно получить текст Markdown и вставить его в область содержимого, отображая `Ing` анимацию загрузки.

## Используйте демо-версию

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "использовать компонент"
});
</script>
```

## Параметры интерфейса

### Свойства и методы

- `toc.prefix`: получите или установите строку префикса маршрутизации (например, `"doc"`, косая черта в конце необязательна), ключ `README` будет автоматически сопоставлен с пустым путем (т. е. с самим префиксом).
- `toc.li`: получите или установите функцию создания многоязычного каталога `(lang) => ({ key: title })`
- `toc.mdUrl`: получите или установите функцию создания URL-адреса Markdown `(key, lang) => url`
- `toc.target`: получите или установите связанный целевой узел рендеринга (например, `c-md`). Если не указано, он автоматически найдет `c-md` / `main` / `article`
- `toc.load(key)`: вручную инициировать загрузку документа и расширение каталога, соответствующего ключу.
- `toc.sync()`: вручную повторно проанализировать заголовок в текущем целевом узле, синхронизировать дополнительный каталог и выделить статус.
