# လမ်းညွှန်လမ်းညွှန်ချက် အစိတ်အပိုင်း

- **တုံ့ပြန်မှုရှိသောအံဆွဲ**- မျက်နှာပြင်ကျယ်တွင် ဘေးဘားကိုပြသပါ၊ ကျဉ်းမြောင်းသောစခရင်တွင် အလိုအလျောက်ပြိုကျကာ `c-side`အံဆွဲနှင့် ခေါင်းစဉ်အစပျိုးခလုတ်တို့နှင့် ပူးပေါင်းလုပ်ဆောင်ပါ။
- ** ဘာသာစကားပေါင်းစုံ ဒရိုက်ဗာ**- အရာဝတ္ထုအဘိဓာန် သို့မဟုတ် ဘာသာစကားပေါင်းစုံ လုပ်ဆောင်ချက်များကို ပံ့ပိုးပေးသည်၊ ဘာသာစကားပြောင်းခြင်းကို အလိုအလျောက်တုံ့ပြန်သည်
- **အလိုအလျောက်လမ်းညွှန်ချက်ခွဲ**- အလယ်တန်းလမ်းညွှန်တစ်ခုထုတ်လုပ်ရန်နှင့် Hash ရှုထောင့်မှလှိမ့်ကြည့်မီးမောင်းထိုးပြရန် ပစ်မှတ်ကွန်တိန်နာရှိ `h1`~`h6`ခေါင်းစဉ်များကို အလိုအလျောက်ခွဲခြမ်းစိတ်ဖြာပါ။
- **Asynchronous loading**- Markdown စာသားကို အလိုအလျောက်ရရှိရန် လမ်းညွှန်အကြောင်းအရာတစ်ခုကို နှိပ်ပြီး `Ing` ကာတွန်းတင်ခြင်းကို ပြသနေသည့် အကြောင်းအရာ ဧရိယာထဲသို့ ထိုးသွင်းပါ။

## ဒီမိုကိုသုံးပါ။

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "အစိတ်အပိုင်းကို အသုံးပြုရန်"
});
</script>
```

## မျက်နှာပြင်ဘောင်များ

### ဂုဏ်သတ္တိများနှင့်နည်းလမ်းများ

- `toc.prefix`- လမ်းကြောင်းရှေ့ဆက်စာကြောင်းကို ရယူပါ သို့မဟုတ် သတ်မှတ်ပါ (ဥပမာ `"doc"`၊ နောက်လိုက်မျဉ်းစောင်းသည် ချန်လှပ်ထားနိုင်သည်)၊ `README`သော့သည် အချည်းနှီးသောလမ်းကြောင်းတစ်ခုသို့ အလိုအလျောက် ပုံဖော်သွားပါမည် (ဥပမာ ရှေ့ဆက်ကိုယ်တိုင်)
- `toc.li`- လမ်းညွှန်ကို ရယူပါ သို့မဟုတ် သတ်မှတ်ရန် ဘာသာစကားပေါင်းစုံ မျိုးဆက်လုပ်ဆောင်ချက် `(lang) => ({ key: title })`
- `toc.mdUrl`- Markdown URL မျိုးဆက်လုပ်ဆောင်ချက် `(key, lang) => url`ကို ရယူပါ သို့မဟုတ် သတ်မှတ်ပါ။
- `toc.target`-- ဆက်စပ်ပစ်မှတ်ကို တင်ဆက်ခြင်း node (ဥပမာ `c-md`) ကို ရယူပါ သို့မဟုတ် သတ်မှတ်ပါ။ မသတ်မှတ်ထားပါက၊ ၎င်းသည် `c-md` / `main` / `article` အလိုအလျောက် တွေ့ရလိမ့်မည်၊
- `toc.load(key)`- သော့နှင့်သက်ဆိုင်သော စာရွက်စာတမ်းဖွင့်ခြင်းနှင့် လမ်းညွှန်ချဲ့ထွင်မှုကို ကိုယ်တိုင်လုပ်ဆောင်ပါ။
- `toc.sync()`- လက်ရှိပစ်မှတ်အမှတ်အသားတွင် ခေါင်းစဉ်ကို ကိုယ်တိုင်ပြန်လည်ခွဲခြမ်းစိတ်ဖြာပြီး အလယ်တန်းလမ်းညွှန်ကို တစ်ပြိုင်တည်းလုပ်ဆောင်ပြီး အခြေအနေကို မီးမောင်းထိုးပြပါ
