# निर्देशिका नेव्हिगेशन घटक

- **रिस्पॉन्सिव्ह ड्रॉवर**: रुंद स्क्रीनमध्ये साइडबार प्रदर्शित करा, अरुंद स्क्रीनमध्ये स्वयंचलितपणे कोलॅप्स करा आणि `c-side` ड्रॉवर आणि शीर्षक ट्रिगर बटणासह सहकार्य करा
- **मल्टी-लँग्वेज ड्रायव्हर**: ऑब्जेक्ट डिक्शनरी किंवा मल्टी-लँग्वेज फंक्शनला सपोर्ट करते, भाषा स्विचिंगला आपोआप प्रतिसाद देते
- **स्वयंचलित उपनिर्देशिका**: दुय्यम निर्देशिका व्युत्पन्न करण्यासाठी आणि हॅश व्ह्यूपोर्ट स्क्रोलिंग हायलाइटचे निरीक्षण करण्यासाठी लक्ष्य कंटेनरमधील `h1`~`h6` शीर्षके स्वयंचलितपणे पार्स करा.
- **असिंक्रोनस लोडिंग**: मार्कडाउन मजकूर एसिंक्रोनस पद्धतीने आपोआप प्राप्त करण्यासाठी निर्देशिका आयटमवर क्लिक करा आणि `Ing` लोडिंग ॲनिमेशन प्रदर्शित करून, सामग्री क्षेत्रामध्ये इंजेक्ट करा

## डेमो वापरा

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "वापर": "घटक वापरा"
});
</script>
```

## इंटरफेस पॅरामीटर्स

### गुणधर्म आणि पद्धती

- `toc.prefix`: राउटिंग उपसर्ग स्ट्रिंग मिळवा किंवा सेट करा (जसे की `"doc"`, ट्रेलिंग स्लॅश पर्यायी आहे), `README` की स्वयंचलितपणे रिक्त मार्गावर मॅप केली जाईल (म्हणजेच उपसर्ग स्वतःच)
- `toc.li`: निर्देशिका मल्टी-लँग्वेज जनरेशन फंक्शन मिळवा किंवा सेट करा `(lang) => ({ key: title })`
- `toc.mdUrl`: मार्कडाउन URL जनरेशन फंक्शन मिळवा किंवा सेट करा `(key, lang) => url`
- `toc.target`: संबंधित लक्ष्य प्रस्तुतीकरण नोड मिळवा किंवा सेट करा (जसे की `c-md`). निर्दिष्ट न केल्यास, ते स्वयंचलितपणे `c-md` / `main` / `article` सापडेल
- `toc.load(key)`: कीशी संबंधित दस्तऐवज लोडिंग आणि निर्देशिका विस्तार मॅन्युअली ट्रिगर करा
- `toc.sync()`: वर्तमान लक्ष्य नोडमधील शीर्षकाचे व्यक्तिचलितपणे पुन्हा विश्लेषण करा, दुय्यम निर्देशिका समक्रमित करा आणि स्थिती हायलाइट करा
