# დირექტორია ნავიგაციის კომპონენტი

- **საპასუხო უჯრა**: აჩვენეთ გვერდითი ზოლი ფართო ეკრანზე, ავტომატურად იშლება ვიწრო ეკრანზე და ითანამშრომლეთ `c-side` უჯრის და სათაურის ღილაკთან
- **მრავალენოვანი დრაივერი**: მხარს უჭერს ობიექტების ლექსიკონს ან მრავალენოვან ფუნქციებს, ავტომატურად პასუხობს ენის შეცვლას
- **ავტომატური ქვედირექტორია**: ავტომატურად გაანალიზეთ `h1`~`h6` სათაურები სამიზნე კონტეინერში, რათა შეიქმნას მეორადი დირექტორია და დააკვირდეს Hash-ის ხედის გადახვევის მონიშვნას.
- **ასინქრონული ჩატვირთვა**: დააწკაპუნეთ დირექტორიას ერთეულზე, რათა ავტომატურად მიიღოთ Markdown ტექსტი ასინქრონულად და შეიყვანოთ იგი შინაარსის არეალში, სადაც ნაჩვენებია `Ing` ჩატვირთვის ანიმაცია

## გამოიყენეთ დემო ვერსია

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "გამოიყენე კომპონენტი"
});
</script>
```

## ინტერფეისის პარამეტრები

### თვისებები და მეთოდები

- `toc.prefix`: მიიღეთ ან დააყენეთ მარშრუტიზაციის პრეფიქსის სტრიქონი (როგორიცაა `"doc"`, უკანა ხაზი არჩევითია), `README` კლავიში ავტომატურად აისახება ცარიელ გზაზე (ანუ თავად პრეფიქსი)
- `toc.li`: მიიღეთ ან დააყენეთ დირექტორია მრავალენოვანი გენერირების ფუნქცია `(lang) => ({ key: title })`
- `toc.mdUrl`: მიიღეთ ან დააყენეთ Markdown URL-ის შექმნის ფუნქცია `(key, lang) => url`
- `toc.target`: მიიღეთ ან დააყენეთ ასოცირებული სამიზნე გადაცემის კვანძი (როგორიცაა `c-md`). თუ არ არის მითითებული, ის ავტომატურად იპოვის `c-md` / `main` / `article`
- `toc.load(key)`: ხელით გაუშვით დოკუმენტის ჩატვირთვა და გასაღების შესაბამისი დირექტორია გაფართოება
- `toc.sync()`: ხელით ხელახლა გააანალიზეთ სათაური მიმდინარე სამიზნე კვანძში, მოახდინე მეორადი დირექტორიას სინქრონიზაცია და მონიშნეთ სტატუსი
