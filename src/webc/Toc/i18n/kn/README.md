# ಡೈರೆಕ್ಟರಿ ನ್ಯಾವಿಗೇಶನ್ ಕಾಂಪೊನೆಂಟ್

- ** ರೆಸ್ಪಾನ್ಸಿವ್ ಡ್ರಾಯರ್**: ವಿಶಾಲ ಪರದೆಯಲ್ಲಿ ಸೈಡ್‌ಬಾರ್ ಅನ್ನು ಪ್ರದರ್ಶಿಸಿ, ಕಿರಿದಾದ ಪರದೆಯಲ್ಲಿ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಕುಸಿಯುತ್ತದೆ ಮತ್ತು `c-side` ಡ್ರಾಯರ್ ಮತ್ತು ಶೀರ್ಷಿಕೆ ಟ್ರಿಗ್ಗರ್ ಬಟನ್‌ನೊಂದಿಗೆ ಸಹಕರಿಸುತ್ತದೆ
- **ಬಹು-ಭಾಷಾ ಚಾಲಕ**: ಆಬ್ಜೆಕ್ಟ್ ನಿಘಂಟು ಅಥವಾ ಬಹು-ಭಾಷಾ ಕಾರ್ಯಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ, ಭಾಷೆ ಸ್ವಿಚಿಂಗ್‌ಗೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪ್ರತಿಕ್ರಿಯಿಸುತ್ತದೆ
- **ಸ್ವಯಂಚಾಲಿತ ಉಪ ಡೈರೆಕ್ಟರಿ**: ದ್ವಿತೀಯ ಡೈರೆಕ್ಟರಿಯನ್ನು ರಚಿಸಲು ಮತ್ತು ಹ್ಯಾಶ್ ವ್ಯೂಪೋರ್ಟ್ ಸ್ಕ್ರೋಲಿಂಗ್ ಹೈಲೈಟ್ ಅನ್ನು ಮೇಲ್ವಿಚಾರಣೆ ಮಾಡಲು ಟಾರ್ಗೆಟ್ ಕಂಟೇನರ್‌ನಲ್ಲಿ `h1`~`h6` ಶೀರ್ಷಿಕೆಗಳನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಪಾರ್ಸ್ ಮಾಡಿ.
- **ಅಸಿಂಕ್ರೊನಸ್ ಲೋಡಿಂಗ್**: ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಮಾರ್ಕ್‌ಡೌನ್ ಪಠ್ಯವನ್ನು ಅಸಮಕಾಲಿಕವಾಗಿ ಪಡೆಯಲು ಡೈರೆಕ್ಟರಿ ಐಟಂ ಅನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ ಮತ್ತು ಅದನ್ನು ವಿಷಯ ಪ್ರದೇಶಕ್ಕೆ ಇಂಜೆಕ್ಟ್ ಮಾಡಿ, `Ing` ಲೋಡಿಂಗ್ ಅನಿಮೇಶನ್ ಅನ್ನು ಪ್ರದರ್ಶಿಸುತ್ತದೆ

## ಡೆಮೊ ಬಳಸಿ

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "ಬಳಕೆ": "ಉಪಯೋಗ ಘಟಕ"
});
</script>
```

## ಇಂಟರ್ಫೇಸ್ ನಿಯತಾಂಕಗಳು

### ಗುಣಲಕ್ಷಣಗಳು ಮತ್ತು ವಿಧಾನಗಳು

- `toc.prefix`: ರೂಟಿಂಗ್ ಪೂರ್ವಪ್ರತ್ಯಯ ಸ್ಟ್ರಿಂಗ್ ಅನ್ನು ಪಡೆಯಿರಿ ಅಥವಾ ಹೊಂದಿಸಿ (ಉದಾಹರಣೆಗೆ `"doc"`, ಟ್ರೇಲಿಂಗ್ ಸ್ಲ್ಯಾಷ್ ಐಚ್ಛಿಕವಾಗಿರುತ್ತದೆ), `README` ಕೀಯನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಖಾಲಿ ಮಾರ್ಗಕ್ಕೆ ಮ್ಯಾಪ್ ಮಾಡಲಾಗುತ್ತದೆ (ಅಂದರೆ ಪೂರ್ವಪ್ರತ್ಯಯ ಸ್ವತಃ)
- `toc.li`: ಡೈರೆಕ್ಟರಿ ಬಹು-ಭಾಷೆಯ ಉತ್ಪಾದನೆಯ ಕಾರ್ಯವನ್ನು ಪಡೆಯಿರಿ ಅಥವಾ ಹೊಂದಿಸಿ `(lang) => ({ key: title })`
- `toc.mdUrl`: ಮಾರ್ಕ್‌ಡೌನ್ URL ಉತ್ಪಾದನೆಯ ಕಾರ್ಯವನ್ನು ಪಡೆಯಿರಿ ಅಥವಾ ಹೊಂದಿಸಿ `(key, lang) => url`
- `toc.target`: ಸಂಯೋಜಿತ ಗುರಿ ರೆಂಡರಿಂಗ್ ನೋಡ್ ಅನ್ನು ಪಡೆಯಿರಿ ಅಥವಾ ಹೊಂದಿಸಿ (ಉದಾಹರಣೆಗೆ `c-md`). ನಿರ್ದಿಷ್ಟಪಡಿಸದಿದ್ದರೆ, ಅದು ಸ್ವಯಂಚಾಲಿತವಾಗಿ `c-md` / `main` / `article` ಅನ್ನು ಕಂಡುಕೊಳ್ಳುತ್ತದೆ
- `toc.load(key)`: ಕೈಯಾರೆ ಡಾಕ್ಯುಮೆಂಟ್ ಲೋಡಿಂಗ್ ಮತ್ತು ಕೀಗೆ ಅನುಗುಣವಾದ ಡೈರೆಕ್ಟರಿ ವಿಸ್ತರಣೆಯನ್ನು ಪ್ರಚೋದಿಸಿ
- `toc.sync()`: ಪ್ರಸ್ತುತ ಗುರಿ ನೋಡ್‌ನಲ್ಲಿ ಶೀರ್ಷಿಕೆಯನ್ನು ಹಸ್ತಚಾಲಿತವಾಗಿ ಮರು ಪಾರ್ಸ್ ಮಾಡಿ, ದ್ವಿತೀಯ ಡೈರೆಕ್ಟರಿಯನ್ನು ಸಿಂಕ್ರೊನೈಸ್ ಮಾಡಿ ಮತ್ತು ಸ್ಥಿತಿಯನ್ನು ಹೈಲೈಟ್ ಮಾಡಿ
