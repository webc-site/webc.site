# निर्देशिका नेभिगेसन कम्पोनेन्ट

- **उत्तरदायी दराज**: चौडा स्क्रिनमा साइडबार प्रदर्शन गर्नुहोस्, साँघुरो स्क्रिनमा स्वतः पतन गर्नुहोस् र `c-side` ड्रअर र शीर्षक ट्रिगर बटनसँग सहकार्य गर्नुहोस्
- **बहु-भाषा चालक**: वस्तु शब्दकोश वा बहु-भाषा प्रकार्यहरू समर्थन गर्दछ, स्वचालित रूपमा भाषा स्विचिङमा प्रतिक्रिया दिन्छ
- **स्वचालित उपनिर्देशिका**: स्वचालित रूपमा लक्ष्य कन्टेनरमा `h1`~`h6` शीर्षकहरू पार्स गर्नुहोस् माध्यमिक डाइरेक्टरी उत्पन्न गर्न र ह्यास भ्युपोर्ट स्क्रोलिङ हाइलाइटलाई निगरानी गर्न।
- **एसिन्क्रोनस लोडिङ**: मार्कडाउन पाठलाई एसिन्क्रोनस रूपमा स्वतः प्राप्त गर्न डाइरेक्टरी वस्तुमा क्लिक गर्नुहोस् र `Ing` लोडिङ एनिमेसन प्रदर्शन गर्दै, सामग्री क्षेत्रमा इन्जेक्सन गर्नुहोस्।

## डेमो प्रयोग गर्नुहोस्

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "कम्पोनेन्ट प्रयोग गर्नुहोस्"
});
</script>
```

## इन्टरफेस प्यारामिटरहरू

### गुण र विधिहरू

- `toc.prefix`: रूटिङ उपसर्ग स्ट्रिङ प्राप्त गर्नुहोस् वा सेट गर्नुहोस् (जस्तै `"doc"`, ट्रेलिङ स्ल्याश ऐच्छिक छ), `README` कुञ्जी स्वचालित रूपमा खाली मार्गमा म्याप हुनेछ (अर्थात उपसर्ग आफैं)।
- `toc.li`: निर्देशिका बहु-भाषा उत्पादन प्रकार्य प्राप्त वा सेट गर्नुहोस् `(lang) => ({ key: title })`
- `toc.mdUrl`: मार्कडाउन URL उत्पादन प्रकार्य प्राप्त गर्नुहोस् वा सेट गर्नुहोस् `(key, lang) => url`
- `toc.target`: सम्बन्धित लक्ष्य रेन्डरिङ नोड (जस्तै `c-md`) प्राप्त गर्नुहोस् वा सेट गर्नुहोस्। यदि निर्दिष्ट गरिएको छैन भने, यसले स्वचालित रूपमा `c-md` / `main` / `article` फेला पार्नेछ।
- `toc.load(key)`: कुञ्जीसँग सम्बन्धित कागजात लोड र डाइरेक्टरी विस्तार म्यानुअल रूपमा ट्रिगर गर्नुहोस्
- `toc.sync()`: हालको लक्ष्य नोडमा म्यानुअल रूपमा शीर्षकलाई पुन: पार्स गर्नुहोस्, माध्यमिक डाइरेक्टरी सिङ्क्रोनाइज गर्नुहोस् र स्थिति हाइलाइट गर्नुहोस्
