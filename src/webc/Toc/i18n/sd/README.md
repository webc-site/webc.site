# ڊاريڪٽري نيويگيشن جزو

- **جوابدار دراز**: وڏي اسڪرين ۾ سائڊبار ڏيکاريو، پاڻمرادو تنگ اسڪرين ۾ کوليو ۽ `c-side` دراز ۽ ٽائيٽل ٽرگر بٽڻ سان تعاون ڪريو
- **ملٽي-ٻولي ڊرائيور**: آبجیکٹ ڊڪشنري يا گھڻن ٻولين جي ڪمن کي سپورٽ ڪري ٿو، خود بخود ٻولي سوئچنگ جو جواب ڏئي ٿو
- **خودڪار ذيلي ڊاريڪٽري**: پاڻمرادو پارس ڪريو `h1`~`h6` عنوانن کي ٽارگيٽ ڪنٽينر ۾ ثانوي ڊاريڪٽري ٺاهڻ لاءِ ۽ مانيٽر ڪريو Hash viewport scrolling highlight.
- **Asynchronous loading**: ڊاريڪٽري آئٽم تي ڪلڪ ڪريو پاڻمرادو مارڪ ڊائون ٽيڪسٽ حاصل ڪرڻ لاءِ asynchronously ۽ ان کي مواد واري علائقي ۾ داخل ڪريو، ڏيکاريندي `Ing` انيميشن لوڊ ڪندي

## ڊيمو استعمال ڪريو

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "استعمال": "جزو استعمال ڪريو"
});
</script>
```

## انٽرفيس پيٽرول

### خاصيتون ۽ طريقا

- `toc.prefix`: حاصل ڪريو يا مقرر ڪريو روٽنگ پريفڪس اسٽرنگ (جهڙوڪ `"doc"`، ٽريلنگ سليش اختياري آهي)، `README` ڪيئي خودڪار طريقي سان هڪ خالي رستي ڏانهن ميپ ڪئي ويندي (يعني اڳي ئي پاڻ)
- `toc.li`: ڊاريڪٽري حاصل ڪريو يا سيٽ ڪريو ملٽي-ٻولي نسل جي فنڪشن `(lang) => ({ key: title })`
- `toc.mdUrl`: حاصل ڪريو يا سيٽ ڪريو مارڪ ڊائون URL جنريشن فنڪشن `(key, lang) => url`
- `toc.target`: حاصل ڪريو يا لاڳاپيل ٽارگيٽ رينڊرنگ نوڊ (جهڙوڪ `c-md`). جيڪڏهن بيان نه ڪيو ويو آهي، اهو خودڪار طريقي سان ڳولي سگهندو `c-md` / `main` / `article`
- `toc.load(key)`: دستي طور تي چاٻي سان لاڳاپيل دستاويز لوڊ ڪرڻ ۽ ڊاريڪٽري جي توسيع کي ٽريڪ ڪريو
- `toc.sync()`: دستي طور تي موجوده ٽارگيٽ نوڊ ۾ عنوان کي ٻيهر پارس ڪريو، ثانوي ڊاريڪٽري کي هم وقت سازي ڪريو ۽ صورتحال کي نمايان ڪريو
