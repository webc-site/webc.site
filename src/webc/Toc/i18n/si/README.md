# නාමාවලි සංචාලන සංරචකය

- **ප්‍රතිචාරාත්මක ලාච්චුව**: පුළුල් තිරයේ පැති තීරුව සංදර්ශන කරන්න, පටු තිරයක ස්වයංක්‍රීයව කඩා වැටෙන අතර `c-side` ලාච්චුව සහ මාතෘකා ප්‍රේරක බොත්තම සමඟ සහයෝගයෙන් කටයුතු කරන්න
- **බහු-භාෂා ධාවකය**: වස්තු ශබ්දකෝෂය හෝ බහු-භාෂා කාර්යයන් සඳහා සහය දක්වයි, භාෂා මාරුවට ස්වයංක්‍රීයව ප්‍රතිචාර දක්වයි
- **ස්වයංක්‍රීය උප බහලුම**: ද්විතියික නාමාවලියක් ජනනය කිරීමට සහ Hash viewport අනුචලන උද්දීපනය නිරීක්ෂණය කිරීමට ඉලක්කගත බහාලුම්වල ඇති `h1`~`h6` මාතෘකා ස්වයංක්‍රීයව විග්‍රහ කරන්න.
- **අසමමුහුර්ත පැටවීම**: මාර්ක්ඩවුන් පෙළ ස්වයංක්‍රීයව අසමමුහුර්තව ලබා ගැනීමට නාමාවලි අයිතමයක් මත ක්ලික් කර එය අන්තර්ගත ප්‍රදේශයට එන්නත් කරන්න, `Ing` පූරණ සජීවිකරණය පෙන්වයි

## Demo භාවිතා කරන්න

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "භාවිතා කරන්න": "භාවිතා සංරචකය"
});
</script>
```

## අතුරුමුහුණත් පරාමිතීන්

### ගුණාංග සහ ක්රම

- `toc.prefix`: රවුටින් උපසර්ග තන්තුව ලබා ගන්න හෝ සකසන්න (`"doc"` වැනි, පසුපස ස්ලෑෂ් විකල්පමය), `README` යතුර ස්වයංක්‍රීයව හිස් මාර්ගයකට සිතියම්ගත කෙරේ (එනම් උපසර්ගයම)
- `toc.li`: බහලුම බහු-භාෂා උත්පාදන ශ්‍රිතය ලබා ගන්න හෝ සකසන්න `(lang) => ({ key: title })`
- `toc.mdUrl`: Markdown URL උත්පාදන කාර්යය `(key, lang) => url` ලබා ගන්න හෝ සකසන්න
- `toc.target`: ආශ්‍රිත ඉලක්ක විදැහුම්කරණ නෝඩය ලබා ගන්න හෝ සකසන්න (`c-md` වැනි). නිශ්චිතව දක්වා නොමැති නම්, එය ස්වයංක්‍රීයව `c-md` / `main` / `article` සොයාගනු ඇත.
- `toc.load(key)`: යතුරට අනුරූප ලේඛන පැටවීම සහ නාමාවලි පුළුල් කිරීම අතින් ක්‍රියාරම්භ කරන්න
- `toc.sync()`: වත්මන් ඉලක්ක නෝඩයේ මාතෘකාව අතින් නැවත විග්‍රහ කරන්න, ද්විතියික නාමාවලිය සමමුහුර්ත කරන්න සහ තත්ත්වය ඉස්මතු කරන්න
