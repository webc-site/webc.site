# Каталогты шарлау құрамдас бөлігі

- **Жауап беретін тартпа**: бүйірлік тақтаны кең экранда көрсету, тар экранда автоматты түрде жиырылуы және `c-side` тартпасы мен тақырыпты іске қосу түймешігімен жұмыс істеу
- **Көп тілді драйвер**: нысан сөздігін немесе көп тілді функцияларды қолдайды, тілді ауыстыруға автоматты түрде жауап береді
- **Автоматты ішкі каталог**: мақсатты контейнердегі `h1`~`h6` тақырыптарды автоматты түрде талдаңыз және қосымша каталогты жасаңыз және хэшті қарау портының жылжуын бөлектеуді бақылаңыз.
- **Асинхронды жүктеу**: Markdown мәтінін синхронды түрде автоматты түрде алу және оны `Ing` жүктеу анимациясын көрсететін мазмұн аймағына енгізу үшін каталог элементін басыңыз.

## Демонстрацияны пайдаланыңыз

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "компонентті пайдалану"
});
</script>
```

## Интерфейс параметрлері

### Қасиеттер мен әдістер

- `toc.prefix`: Бағыттау префикс жолын алыңыз немесе орнатыңыз (мысалы, `"doc"`, кейінгі қиғаш сызық міндетті емес), `README` пернесі автоматты түрде бос жолға (яғни префикстің өзі) сәйкестендіріледі.
- `toc.li`: `(lang) => ({ key: title })` каталогты көп тілді құру функциясын алу немесе орнату
- `toc.mdUrl`: Markdown URL құру функциясын `(key, lang) => url` алыңыз немесе орнатыңыз
- `toc.target`: байланыстырылған мақсатты көрсету түйінін алыңыз немесе орнатыңыз (мысалы, `c-md`). Егер көрсетілмесе, ол автоматты түрде `c-md` / `main` / `article` табады.
- `toc.load(key)`: құжатты жүктеуді және кілтке сәйкес каталогты кеңейтуді қолмен іске қосу
- `toc.sync()`: ағымдағы мақсатты түйіндегі тақырыпты қолмен қайта талдау, қосымша каталогты синхрондау және күйді бөлектеу
