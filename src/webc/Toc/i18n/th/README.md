# ส่วนประกอบการนำทางไดเรกทอรี

- **ลิ้นชักที่ตอบสนอง**: แสดงแถบด้านข้างในหน้าจอกว้าง ยุบโดยอัตโนมัติในหน้าจอแคบ และทำงานร่วมกับ `c-side` ลิ้นชักและปุ่มทริกเกอร์ชื่อเรื่อง
- **ไดรเวอร์หลายภาษา**: รองรับพจนานุกรมออบเจ็กต์หรือฟังก์ชันหลายภาษา ตอบสนองต่อการเปลี่ยนภาษาโดยอัตโนมัติ
- **ไดเรกทอรีย่อยอัตโนมัติ**: แยกวิเคราะห์ชื่อ `h6` ในคอนเทนเนอร์เป้าหมายโดยอัตโนมัติเพื่อสร้างไดเรกทอรีรองและตรวจสอบไฮไลต์การเลื่อนวิวพอร์ตของ Hash
- **การโหลดแบบอะซิงโครนัส**: คลิกที่รายการไดเร็กทอรีเพื่อรับข้อความ Markdown แบบอะซิงโครนัสโดยอัตโนมัติ และแทรกลงในพื้นที่เนื้อหา โดยแสดงภาพเคลื่อนไหวการโหลด `Ing`

## ใช้การสาธิต

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "ใช้": "ใช้ส่วนประกอบ"
});
</script>
```

## พารามิเตอร์อินเทอร์เฟซ

### คุณสมบัติและวิธีการ

- `toc.prefix`: รับหรือตั้งค่าสตริงคำนำหน้าเส้นทาง (เช่น `"doc"` เครื่องหมายทับต่อท้ายเป็นทางเลือก) ปุ่ม `README` จะถูกแมปโดยอัตโนมัติกับเส้นทางว่าง (เช่น คำนำหน้าเอง)
- `toc.li`: รับหรือตั้งค่าฟังก์ชันการสร้างไดเร็กทอรีหลายภาษา `(lang) => ({ key: title })`
- `toc.mdUrl`: รับหรือตั้งค่าฟังก์ชันการสร้าง URL Markdown `(key, lang) => url`
- `toc.target`: รับหรือตั้งค่าโหนดการแสดงผลเป้าหมายที่เกี่ยวข้อง (เช่น `c-md`) หากไม่ได้ระบุ ระบบจะค้นหา `c-md` / `main` / `article` โดยอัตโนมัติ
- `toc.load(key)`: ทริกเกอร์การโหลดเอกสารและการขยายไดเร็กทอรีที่สอดคล้องกับคีย์ด้วยตนเอง
- `toc.sync()`: แยกวิเคราะห์ชื่อในโหนดเป้าหมายปัจจุบันด้วยตนเอง ซิงโครไนซ์ไดเร็กทอรีรองและไฮไลต์สถานะ
