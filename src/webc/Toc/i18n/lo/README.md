# Directory Navigation Component

- **ລີ້ນຊັກຕອບສະໜອງ**: ສະແດງແຖບດ້ານຂ້າງໃນໜ້າຈໍກວ້າງ, ຫຍໍ້ລົງໂດຍອັດຕະໂນມັດໃນໜ້າຈໍແຄບ ແລະຮ່ວມມືກັບ `c-side`ລິ້ນຊັກ ແລະປຸ່ມກະຕຸ້ນຫົວຂໍ້
- ** ໄດເວີຫຼາຍພາສາ**: ຮອງຮັບວັດຈະນານຸກົມວັດຖຸ ຫຼືຟັງຊັນຫຼາຍພາສາ, ຕອບສະໜອງອັດຕະໂນມັດກັບການປ່ຽນພາສາ
- **ໄດເລກະທໍລີຍ່ອຍອັດຕະໂນມັດ**: ແຍກແຍະ `h1`~`h6` ຫົວຂໍ້ອັດຕະໂນມັດໃນກ່ອງບັນຈຸເປົ້າໝາຍເພື່ອສ້າງໄດເລກະທໍລີສຳຮອງ ແລະຕິດຕາມຈຸດເດັ່ນຂອງການເລື່ອນມຸມເບິ່ງ Hash.
- **ການໂຫຼດແບບ Asynchronous**: ຄລິກໃສ່ລາຍການໄດເລກະທໍລີເພື່ອຮັບເອົາຂໍ້ຄວາມ Markdown ແບບອັດຕະໂນມັດ ແລະໃສ່ມັນເຂົ້າໄປໃນພື້ນທີ່ເນື້ອຫາ, ສະແດງ `Ing`ການໂຫຼດອະນິເມຊັນ.

## ໃຊ້ຕົວຢ່າງ

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "ໃຊ້ອົງປະກອບ"
});
</script>
```

## ຕົວກໍານົດການໃນການໂຕ້ຕອບ

### ຄຸນສົມບັດແລະວິທີການ

- `toc.prefix`: ຮັບເອົາ ຫຼືຕັ້ງສະຕຣິງຄຳນຳໜ້າເສັ້ນທາງ (ເຊັ່ນ `"doc"`, ເຄື່ອງໝາຍທັບຊ້ອນທ້າຍແມ່ນເປັນທາງເລືອກ), ປຸ່ມ `README` ຈະຖືກຕັ້ງແຜນທີ່ອັດຕະໂນມັດໄປຫາເສັ້ນທາງທີ່ຫວ່າງເປົ່າ (ເຊັ່ນ: ຄຳນຳໜ້າຂອງມັນເອງ)
- `toc.li`: ຮັບ ຫຼືຕັ້ງຟັງຊັນການຜະລິດຫຼາຍພາສາຂອງໄດເລກະທໍລີ `(lang) => ({ key: title })`
- `toc.mdUrl`: ຮັບ ຫຼືຕັ້ງຟັງຊັນການສ້າງ Markdown URL `(key, lang) => url`
- `toc.target`: ໄດ້​ຮັບ ຫຼື​ຕັ້ງ​ຂໍ້​ມູນ​ການ​ເຮັດ​ໃຫ້​ເປົ້າ​ຫມາຍ​ທີ່​ກ່ຽວ​ຂ້ອງ (ເຊັ່ນ​: `c-md`). ຖ້າບໍ່ໄດ້ລະບຸ, ມັນຈະຊອກຫາ `c-md` / `main` / `article`
- `toc.load(key)`: ກະຕຸ້ນການໂຫຼດເອກະສານດ້ວຍຕົນເອງ ແລະຂະຫຍາຍໄດເລກະທໍລີທີ່ສອດຄ້ອງກັບກະແຈ
- `toc.sync()`: ແຍກ​ຫົວ​ຂໍ້​ຄືນ​ໃໝ່​ດ້ວຍ​ຕົນ​ເອງ​ໃນ​ໂນດ​ເປົ້າ​ໝາຍ​ປະ​ຈຸ​ບັນ, ຊິງ​ໂຄ​ຣ​ໄນ​ໄດ​ເຣັກ​ທໍ​ຣີ​ຮອງ ແລະ​ສະ​ຖາ​ນະ​ການ​ໄຮ​ໄລ້
