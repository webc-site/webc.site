# Компонента за навигација во директориумот

- **Фока која реагира**: Прикажете ја страничната лента на широк екран, автоматски се собира на тесен екран и соработувајте со `c-side` фиоката и копчето за активирање наслов
- **Дивер за повеќе јазици**: Поддржува речник на објекти или функции на повеќе јазици, автоматски реагира на префрлување јазик
- **Автоматски поддиректориум**: Автоматски анализирајте ги насловите `h1`~`h6` во целниот контејнер за да генерирате секундарен директориум и да го надгледувате нагласувањето на лизгачкиот приказ на Hash.
- **Асинхроно вчитување**: Кликнете на ставка од директориум за автоматски да го добиете асинхроно текстот Markdown и да го внесете во областа за содржина, прикажувајќи `Ing` анимација за вчитување

## Користете го демо

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "користи компонента"
});
</script>
```

## Параметри на интерфејсот

### Својства и методи

- `toc.prefix`: Добијте или поставете ја низата на префиксот за насочување (како што е `"doc"`, задоцната коса црта е изборна), копчето `README` автоматски ќе се мапира на празна патека (т.е. самиот префикс)
- `toc.li`: Земете или поставете ја функцијата за генерирање повеќејазични директориуми `(lang) => ({ key: title })`
- `toc.mdUrl`: Добијте или поставете ја функцијата за генерирање URL на Markdown `(key, lang) => url`
- `toc.target`: Добијте или поставете го поврзаниот јазол за рендерирање на целта (како што е `c-md`). Ако не е наведено, автоматски ќе најде `c-md` / `main` / `article`
- `toc.load(key)`: Рачно активирајте го вчитувањето на документот и проширувањето на директориумот што одговара на клучот
- `toc.sync()`: Рачно повторно анализирајте го насловот во тековниот целен јазол, синхронизирајте го секундарниот директориум и означете го статусот
