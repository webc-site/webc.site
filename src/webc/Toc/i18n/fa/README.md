# مؤلفه ناوبری دایرکتوری

- **کشوی پاسخگو**: نوار کناری را در صفحه عریض نمایش دهید، به طور خودکار در صفحه باریک جمع می شود و با `c-side` کشو و دکمه ماشه عنوان همکاری می کند.
- **درایور چند زبانه**: از فرهنگ لغت شی یا عملکردهای چند زبانه پشتیبانی می کند، به طور خودکار به تعویض زبان پاسخ می دهد
- **دایرکتوری فرعی خودکار**: به طور خودکار عناوین `h1`~`h6` را در ظرف مورد نظر تجزیه کنید تا یک فهرست ثانویه ایجاد شود و برجسته شدن پیمایش درگاه نمای هش نظارت شود.
- **بارگیری ناهمزمان**: روی یک مورد دایرکتوری کلیک کنید تا به طور خودکار متن Markdown را به صورت ناهمزمان دریافت کنید و آن را به ناحیه محتوا تزریق کنید و `Ing` انیمیشن بارگیری را نمایش دهید.

## از دمو استفاده کنید

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "استفاده از جزء"
});
</script>
```

## پارامترهای رابط

### خواص و روش ها

- <b id============================================================================================
- `toc.li`: تابع تولید چند زبانه دایرکتوری را دریافت یا تنظیم کنید `(lang) => ({ key: title })`
- `toc.mdUrl`: تابع تولید URL Markdown `(key, lang) => url` را دریافت یا تنظیم کنید
- `toc.target`: گره رندر هدف مرتبط را دریافت یا تنظیم کنید (مانند `c-md`). اگر مشخص نشده باشد، به طور خودکار `c-md` / `main` / `article` را پیدا می کند.
- `toc.load(key)`: بارگیری سند و گسترش دایرکتوری مربوط به کلید را به صورت دستی فعال کنید
- `toc.sync()`: به صورت دستی عنوان را در گره هدف فعلی تجزیه و تحلیل کنید، دایرکتوری ثانویه را همگام سازی کنید و وضعیت را برجسته کنید
