# Компонент навігації каталогом

- **Адаптивний ящик**: відображати бічну панель на широкому екрані, автоматично згортати на вузькому екрані та співпрацювати з `c-side` ящиком і кнопкою запуску заголовка
- **Багатомовний драйвер**: підтримує словник об’єктів або багатомовні функції, автоматично реагує на перемикання мови
- **Автоматичний підкаталог**: автоматично аналізуйте заголовки `h1`~`h6` у цільовому контейнері, щоб створити вторинний каталог і контролювати підсвічування вікна перегляду Hash.
- **Асинхронне завантаження**: клацніть елемент каталогу, щоб автоматично асинхронно отримати текст Markdown і вставити його в область вмісту, відображаючи `Ing` анімацію завантаження

## Використовуйте демо

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "використовувати компонент"
});
</script>
```

## Параметри інтерфейсу

### Властивості та методи

- `toc.prefix`: Отримайте або встановіть рядок префікса маршрутизації (наприклад, `"doc"`, коса риска в кінці необов’язкова), ключ `README` буде автоматично зіставлено з порожнім шляхом (тобто самим префіксом)
- `toc.li`: отримати або встановити функцію створення багатомовного каталогу `(lang) => ({ key: title })`
- `toc.mdUrl`: отримати або встановити функцію генерації URL-адреси Markdown `(key, lang) => url`
- `toc.target`: отримати або встановити пов’язаний цільовий вузол відтворення (наприклад, `c-md`). Якщо не вказано, автоматично буде знайдено `c-md` / `main` / `article`
- `toc.load(key)`: вручну запустити завантаження документа та розширення каталогу відповідно до ключа
- `toc.sync()`: вручну повторно проаналізуйте заголовок у поточному цільовому вузлі, синхронізуйте вторинний каталог і виділіть статус
