# Компонент за навигация в директория

- **Адаптивно чекмедже**: Показване на страничната лента в широк екран, автоматично свиване в тесен екран и сътрудничество с `c-side` чекмедже и бутон за задействане на заглавие
- **Многоезичен драйвер**: Поддържа обектен речник или многоезични функции, автоматично реагира на превключване на езика
- **Автоматична поддиректория**: Автоматично анализирайте `h1`~`h6` заглавията в целевия контейнер, за да генерирате вторична директория и да наблюдавате осветяването на превъртащия прозорец за хеширане.
- **Асинхронно зареждане**: Щракнете върху елемент от директория, за да получите автоматично Markdown текст асинхронно и да го инжектирате в областта на съдържанието, показвайки `Ing` анимация за зареждане

## Използвайте демонстрацията

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "използване": "използване на компонент"
});
</script>
```

## Параметри на интерфейса

### Свойства и методи

- `toc.prefix`: Вземете или задайте низа на префикса за маршрутизиране (като `"doc"`, крайната наклонена черта не е задължителна), ключът `README` автоматично ще бъде съпоставен с празен път (т.е. самият префикс)
- `toc.li`: Вземете или задайте функцията за генериране на многоезични директории `(lang) => ({ key: title })`
- `toc.mdUrl`: Вземете или задайте функцията за генериране на URL адреса на Markdown `(key, lang) => url`
- `toc.target`: Вземете или задайте свързания целеви възел за изобразяване (като `c-md`). Ако не е указано, автоматично ще намери `c-md` / `main` / `article`
- `toc.load(key)`: Ръчно задействане на зареждане на документ и разширяване на директория, съответстващо на ключ
- `toc.sync()`: Ръчно анализирайте повторно заглавието в текущия целеви възел, синхронизирайте вторичната директория и маркирайте състоянието
