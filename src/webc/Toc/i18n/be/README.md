# Кампанент навігацыі па каталогу

- **Спагадная скрыня**: адлюстроўваць бакавую панэль на шырокім экране, аўтаматычна згортваць на вузкім экране і ўзаемадзейнічаць з `c-side` скрыняй і кнопкай запуску загалоўка
- **Шматмоўны драйвер**: падтрымлівае слоўнік аб'ектаў або шматмоўныя функцыі, аўтаматычна рэагуе на пераключэнне мовы
- **Аўтаматычны падкаталог**: Аўтаматычны разбор загалоўкаў `h1`~`h6` у мэтавым кантэйнеры для стварэння другаснага каталога і маніторынгу пракруткі пракруткі прагляду Hash.
- **Асінхронная загрузка**: націсніце на элемент каталога, каб аўтаматычна асінхронна атрымаць тэкст Markdown і ўставіць яго ў вобласць змесціва, паказваючы анімацыю загрузкі `Ing`

## Выкарыстоўвайце дэма

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "выкарыстоўваць кампанент"
});
</script>
```

## Параметры інтэрфейсу

### Уласцівасці і метады

- `toc.prefix`: атрымаць або задаць радок прэфікса маршрутызацыі (напрыклад, `"doc"`, касая рыса ў канцы неабавязковая), ключ `README` будзе аўтаматычна супастаўляцца з пустым шляхам (г.зн. самім прэфіксам)
- `toc.li`: атрымаць або ўсталяваць функцыю стварэння шматмоўнага каталога `(lang) => ({ key: title })`
- `toc.mdUrl`: атрымаць або ўсталяваць функцыю генерацыі URL Markdown `(key, lang) => url`
- `toc.target`: атрымаць або ўсталяваць звязаны мэтавы вузел рэндэрынгу (напрыклад, `c-md`). Калі не пазначана, ён аўтаматычна знойдзе `c-md` / `main` / `article`
- `toc.load(key)`: уручную запусціць загрузку дакумента і пашырэнне каталога ў адпаведнасці з ключом
- `toc.sync()`: Паўторны аналіз загалоўка ў бягучым мэтавым вузле ўручную, сінхранізацыя другаснага каталога і вылучэнне стану
