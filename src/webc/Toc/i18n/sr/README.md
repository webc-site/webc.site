# Компонента за навигацију директоријума

- **Реакциона фиока**: Прикажите бочну траку на широком екрану, аутоматски скупите на уском екрану и сарађујте са <б ид="1"> фиоком и дугметом за покретање наслова
- **Вишејезички управљачки програм**: Подржава речник објеката или вишејезичне функције, аутоматски реагује на промену језика
- **Аутоматски поддиректоријум**: Аутоматски рашчланите <б ид="1">~<б ид="2"> наслове у циљном контејнеру да бисте генерисали секундарни директоријум и надгледали истицање померања хеш поља приказа.
- **Асинхроно учитавање**: Кликните на ставку директоријума да бисте аутоматски асинхроно добили Маркдовн текст и убацили га у област садржаја, приказујући <б ид="1"> анимацију учитавања

## Користите демо

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "користи": "користи компоненту"
});
</script>
```

## Параметри интерфејса

### Особине и методе

- <б ид="1">: Набавите или поставите стринг префикса за рутирање (као што је <б ид="2">, задња коса црта је опциона), кључ <б ид="3"> ће аутоматски бити мапиран у празну путању (тј. сам префикс)
- <б ид="1">: Преузмите или подесите функцију генерисања више језика <б ид="2">
- <б ид="1">: Преузмите или подесите функцију Маркдовн генерисања УРЛ адресе <б ид="2">
- <б ид="1">: Преузмите или подесите повезани циљни чвор за приказивање (као што је <б ид="2">). Ако није наведено, аутоматски ће пронаћи <б ид="3"> / <б ид="4"> / <б ид="5">
- <б ид="1">: Ручно покрените учитавање документа и проширење директоријума који одговара кључу
- <б ид="1">: Ручно поново анализирајте наслов у тренутном циљном чвору, синхронизујте секундарни директоријум и означите статус
