# רכיב ניווט בספריות

- **מגירה רספונסיבית**: הצג סרגל צד במסך רחב, כיווץ אוטומטי במסך צר ושתף פעולה עם `c-side` מגירה וכפתור הפעלת הכותרת
- **מנהל התקן מרובה שפות**: תומך בפונקציות מילון אובייקטים או מרובות שפות, מגיב אוטומטית להחלפת שפה
- **ספריית משנה אוטומטית**: נתח אוטומטית את הכותרות `h1`~`h6` במיכל היעד כדי ליצור ספרייה משנית ולנטר את הדגשת גלילה של נקודת ה-Hash.
- **טעינה אסינכרונית**: לחץ על פריט ספרייה כדי לקבל אוטומטית טקסט Markdown באופן אסינכרוני ולהחדיר אותו לאזור התוכן, תוך הצגת אנימציית טעינה `Ing`

## השתמש בהדגמה

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "השתמש ברכיב"
});
</script>
```

## פרמטרים של ממשק

### מאפיינים ושיטות

- `toc.prefix`: קבל או הגדר את מחרוזת קידומת הניתוב (כגון `"doc"`, הלוכסן האחורי הוא אופציונלי), המפתח `README` ימופה אוטומטית לנתיב ריק (כלומר הקידומת עצמה)
- `toc.li`: קבל או הגדר את פונקציית יצירת מספר השפות של ספריות `(lang) => ({ key: title })`
- `toc.mdUrl`: קבל או הגדר את פונקציית יצירת כתובת האתר של Markdown `(key, lang) => url`
- `toc.target`: קבל או הגדר את צומת עיבוד היעד המשויך (כגון `c-md`). אם לא צוין, הוא ימצא אוטומטית את `c-md` / `main` / `article`
- `toc.load(key)`: הפעל באופן ידני טעינת מסמכים והרחבת ספריות בהתאם למפתח
- `toc.sync()`: נתח מחדש באופן ידני את הכותרת בצומת היעד הנוכחי, סנכרן את הספרייה המשנית והדגש סטטוס
