# Գրացուցակի նավիգացիոն բաղադրիչ

- **Արձագանքող դարակ**. Ցուցադրել կողագոտին լայն էկրանով, ինքնաբերաբար փլվել նեղ էկրանին և համագործակցել `c-side` դարակի և վերնագրի գործարկման կոճակի հետ:
- **Բազմալեզու վարորդ**. Աջակցում է օբյեկտների բառարանի կամ բազմալեզու գործառույթներին, ինքնաբերաբար արձագանքում է լեզվի փոխարկմանը
- **Ավտոմատ ենթացանց **. Ավտոմատ կերպով վերլուծեք `h1`~`h6` վերնագրերը թիրախային կոնտեյների մեջ՝ երկրորդական գրացուցակ ստեղծելու և Hash տեսադաշտի ոլորման կարևորությունը վերահսկելու համար:
- **Ասինխրոն բեռնում**․ սեղմեք գրացուցակի տարրի վրա՝ ավտոմատ կերպով ասինխրոն կերպով Markdown տեքստը ստանալու և այն ներարկելու բովանդակության տարածք՝ ցուցադրելով `Ing` բեռնվող անիմացիա։

## Օգտագործեք ցուցադրությունը

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  «օգտագործել»: «օգտագործել բաղադրիչ»
});
</script>
```

## Ինտերֆեյսի պարամետրեր

### Հատկություններ և մեթոդներ

- `toc.prefix`. Ստացեք կամ սահմանեք երթուղային նախածանցի տողը (օրինակ՝ `"doc"`, վերջավոր շեղը կամընտիր է), `README` ստեղնը ավտոմատ կերպով կարտացոլվի դատարկ ուղու վրա (այսինքն հենց նախածանցը)
- `toc.li`. Ստացեք կամ սահմանեք գրացուցակի բազմալեզու ստեղծման գործառույթը `(lang) => ({ key: title })`
- `toc.mdUrl`. Ստացեք կամ սահմանեք Markdown URL-ի ստեղծման գործառույթը `(key, lang) => url`
- `c-md` / `main` / `article`
- `toc.load(key)`. ձեռքով գործարկել փաստաթղթի բեռնումը և բանալիին համապատասխան գրացուցակի ընդլայնումը
- `toc.sync()`. Ձեռքով վերանայեք վերնագիրը ընթացիկ թիրախային հանգույցում, համաժամացրեք երկրորդական գրացուցակը և ընդգծեք կարգավիճակը
