# مكون التنقل في الدليل

- **درج سريع الاستجابة**: عرض الشريط الجانبي في شاشة عريضة، ويمكن طيه تلقائيًا في شاشة ضيقة والتعاون مع `c-side` وزر تشغيل العنوان
- ** برنامج تشغيل متعدد اللغات **: يدعم قاموس الكائنات أو وظائف متعددة اللغات، ويستجيب تلقائيًا لتبديل اللغة
- **الدليل الفرعي التلقائي**: تحليل العناوين `h1`~`h6` تلقائيًا في الحاوية الهدف لإنشاء دليل ثانوي ومراقبة تمييز التمرير في إطار عرض التجزئة.
- **تحميل غير متزامن**: انقر فوق عنصر الدليل للحصول تلقائيًا على نص Markdown بشكل غير متزامن وإدخاله في منطقة المحتوى، مع عرض `Ing` رسوم متحركة للتحميل

## استخدم العرض التوضيحي

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "استخدام": "استخدام المكون"
});
</script>
```

## معلمات الواجهة

### الخصائص والأساليب

- `toc.prefix`: احصل على سلسلة بادئة التوجيه أو قم بتعيينها (مثل `"doc"`، الشرطة المائلة اللاحقة اختيارية)، سيتم تعيين المفتاح `README` تلقائيًا إلى مسار فارغ (أي البادئة نفسها)
- `toc.li`: احصل على أو قم بتعيين وظيفة إنشاء الدليل متعدد اللغات `(lang) => ({ key: title })`
- `toc.mdUrl`: احصل على أو قم بتعيين وظيفة إنشاء عنوان URL لـ Markdown `(key, lang) => url`
- `toc.target`: احصل على أو قم بتعيين عقدة العرض المستهدفة المرتبطة (مثل `c-md`). إذا لم يتم تحديده، فسيتم العثور تلقائيًا على `c-md` / `main` / `article`
- `toc.load(key)`: تشغيل تحميل المستند وتوسيع الدليل المطابق للمفتاح يدويًا
- `toc.sync()`: إعادة تحليل العنوان يدويًا في العقدة الهدف الحالية ومزامنة الدليل الثانوي وتمييز الحالة
