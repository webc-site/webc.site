# សមាសធាតុរុករកថត

- ** Responsive drawer**៖ បង្ហាញរបារចំហៀងនៅក្នុងអេក្រង់ធំទូលាយ បង្រួមដោយស្វ័យប្រវត្តិក្នុងអេក្រង់តូចចង្អៀត ហើយសហការជាមួយ `c-side` ថតឯកសារ និងប៊ូតុងកេះចំណងជើង
- **កម្មវិធីបញ្ជាពហុភាសា**៖ គាំទ្រវចនានុក្រមវត្ថុ ឬមុខងារពហុភាសា ឆ្លើយតបដោយស្វ័យប្រវត្តិចំពោះការប្តូរភាសា
- ** ថតរងដោយស្វ័យប្រវត្តិ**៖ ញែកចំណងជើង `h1`~`h6` ដោយស្វ័យប្រវត្តិនៅក្នុងធុងគោលដៅដើម្បីបង្កើតថតបន្ទាប់បន្សំ និងតាមដានការរំកិលទិដ្ឋភាព Hash រំកិលបន្លិច។
- **ការ​ផ្ទុក​អសមកាល**៖ ចុច​លើ​ធាតុ​ថត​ដើម្បី​ទទួល​បាន​អត្ថបទ Markdown ដោយ​ស្វ័យ​ប្រវត្តិ​ដោយ​អសមកាល ហើយ​បញ្ចូល​វា​ទៅ​ក្នុង​ផ្ទៃ​មាតិកា ដោយ​បង្ហាញ `Ing`កំពុង​ផ្ទុក​ចលនា

## ប្រើការបង្ហាញ

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "ប្រើ​សមាសភាគ"
});
</script>
```

## ប៉ារ៉ាម៉ែត្រចំណុចប្រទាក់

### លក្ខណៈសម្បត្តិនិងវិធីសាស្រ្ត

- `toc.prefix`៖ ទទួល ឬកំណត់​ខ្សែអក្សរ​បុព្វបទ​ផ្លូវ (ដូចជា `"doc"` សញ្ញា​កាត់​បន្ទាប់​គឺ​ជា​ជម្រើស) គ្រាប់ចុច `README` នឹង​ត្រូវ​បាន​គូស​ផែនទី​ដោយ​ស្វ័យ​ប្រវត្តិ​ទៅ​ផ្លូវ​ទទេ (ឧ. បុព្វបទ​ខ្លួនវា)
- `toc.li`៖ ទទួល ឬកំណត់មុខងារបង្កើតពហុភាសារបស់ថត `(lang) => ({ key: title })`
- `toc.mdUrl`៖ ទទួល ឬកំណត់មុខងារបង្កើត URL Markdown `(key, lang) => url`
- `toc.target`៖ ទទួល ឬកំណត់ថ្នាំងបង្ហាញគោលដៅដែលពាក់ព័ន្ធ (ដូចជា `c-md`)។ បើ​មិន​បាន​បញ្ជាក់​ទេ វា​នឹង​រក​ឃើញ​ដោយ​ស្វ័យ​ប្រវត្តិ `c-md` / `main` / `article`
- `toc.load(key)`៖ ចាប់ផ្តើមការផ្ទុកឯកសារដោយដៃ និងការពង្រីកថតដែលត្រូវគ្នានឹងគន្លឹះ
- `toc.sync()`៖ ញែកចំណងជើងឡើងវិញដោយដៃនៅក្នុងថ្នាំងគោលដៅបច្ចុប្បន្ន ធ្វើសមកាលកម្មថតបន្ទាប់បន្សំ និងស្ថានភាពបន្លិច
