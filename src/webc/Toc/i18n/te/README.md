# డైరెక్టరీ నావిగేషన్ భాగం

- **ప్రతిస్పందించే డ్రాయర్**: వైడ్ స్క్రీన్‌లో సైడ్‌బార్‌ని ప్రదర్శించండి, ఇరుకైన స్క్రీన్‌లో స్వయంచాలకంగా కూలిపోతుంది మరియు `c-side` డ్రాయర్ మరియు టైటిల్ ట్రిగ్గర్ బటన్‌తో సహకరిస్తుంది
- **బహుళ భాషా డ్రైవర్**: ఆబ్జెక్ట్ డిక్షనరీ లేదా బహుళ-భాషా ఫంక్షన్‌లకు మద్దతు ఇస్తుంది, స్వయంచాలకంగా భాష మార్పిడికి ప్రతిస్పందిస్తుంది.
- **ఆటోమేటిక్ సబ్‌డైరెక్టరీ**: సెకండరీ డైరెక్టరీని రూపొందించడానికి మరియు హాష్ వీక్షణపోర్ట్ స్క్రోలింగ్ హైలైట్‌ని పర్యవేక్షించడానికి లక్ష్య కంటైనర్‌లోని `h1`~`h6` శీర్షికలను స్వయంచాలకంగా అన్వయించండి.
- **అసమకాలిక లోడింగ్**: స్వయంచాలకంగా మార్క్‌డౌన్ వచనాన్ని అసమకాలికంగా పొందేందుకు డైరెక్టరీ ఐటెమ్‌పై క్లిక్ చేసి, `Ing` లోడింగ్ యానిమేషన్‌ను ప్రదర్శిస్తూ కంటెంట్ ప్రాంతంలోకి ఇంజెక్ట్ చేయండి

## డెమో ఉపయోగించండి

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "ఉపయోగించు": "ఉపయోగించు భాగం"
});
</script>
```

## ఇంటర్ఫేస్ పారామితులు

### లక్షణాలు మరియు పద్ధతులు

- `toc.prefix`: రౌటింగ్ ప్రిఫిక్స్ స్ట్రింగ్‌ను పొందండి లేదా సెట్ చేయండి (`"doc"` వంటివి, ట్రైలింగ్ స్లాష్ ఐచ్ఛికం), `README` కీ స్వయంచాలకంగా ఖాళీ మార్గానికి మ్యాప్ చేయబడుతుంది (అంటే ఉపసర్గ కూడా)
- `toc.li`: డైరెక్టరీ బహుళ-భాషా ఉత్పత్తి ఫంక్షన్ `(lang) => ({ key: title })`ని పొందండి లేదా సెట్ చేయండి
- `toc.mdUrl`: మార్క్‌డౌన్ URL జనరేషన్ ఫంక్షన్ `(key, lang) => url`ని పొందండి లేదా సెట్ చేయండి
- `toc.target`: అనుబంధిత లక్ష్యం రెండరింగ్ నోడ్‌ను పొందండి లేదా సెట్ చేయండి (`c-md` వంటివి). పేర్కొనకపోతే, అది స్వయంచాలకంగా `c-md` / `main` / `article`ని కనుగొంటుంది
- `toc.load(key)`: మాన్యువల్‌గా ట్రిగ్గర్ డాక్యుమెంట్ లోడింగ్ మరియు కీకి సంబంధించిన డైరెక్టరీ విస్తరణ
- `toc.sync()`: ప్రస్తుత లక్ష్య నోడ్‌లో శీర్షికను మాన్యువల్‌గా మళ్లీ అన్వయించండి, సెకండరీ డైరెక్టరీని సమకాలీకరించండి మరియు స్థితిని హైలైట్ చేయండి
