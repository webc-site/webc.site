# அடைவு வழிசெலுத்தல் கூறு

- ** பதிலளிக்கக்கூடிய அலமாரி**: பரந்த திரையில் பக்கப்பட்டியைக் காண்பிக்கும், குறுகிய திரையில் தானாகவே சரிந்து, `c-side` டிராயர் மற்றும் தலைப்பு தூண்டுதல் பொத்தானுடன் ஒத்துழைக்கும்
- **பல மொழி இயக்கி**: பொருள் அகராதி அல்லது பல மொழி செயல்பாடுகளை ஆதரிக்கிறது, மொழி மாறுதலுக்கு தானாகவே பதிலளிக்கிறது
- **தானியங்கி துணை அடைவு**: இரண்டாம் நிலை கோப்பகத்தை உருவாக்க மற்றும் ஹாஷ் வியூபோர்ட் ஸ்க்ரோலிங் ஹைலைட்டை கண்காணிக்க இலக்கு கொள்கலனில் உள்ள `h1`~`h6` தலைப்புகளை தானாக அலசவும்.
- **ஒத்திசைவற்ற ஏற்றுதல்**: மார்க் டவுன் உரையை ஒத்திசைவற்ற முறையில் தானாகப் பெற ஒரு கோப்பக உருப்படியைக் கிளிக் செய்து, `Ing` ஏற்றுதல் அனிமேஷனைக் காட்டும்.

## டெமோவைப் பயன்படுத்தவும்

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "பயன்படுத்து": "உபயோக கூறு"
});
</script>
```

## இடைமுக அளவுருக்கள்

### பண்புகள் மற்றும் முறைகள்

- `toc.prefix`: ரூட்டிங் முன்னொட்டு சரத்தைப் பெறவும் அல்லது அமைக்கவும் (`"doc"` போன்றவை, ட்ரெயிலிங் ஸ்லாஷ் விருப்பமானது), `README` விசை தானாகவே வெற்றுப் பாதைக்கு மேப் செய்யப்படும் (அதாவது முன்னொட்டு தானே)
- `toc.li`: அடைவு பல மொழி உருவாக்க செயல்பாட்டைப் பெறவும் அல்லது அமைக்கவும் `(lang) => ({ key: title })`
- `toc.mdUrl`: மார்க் டவுன் URL உருவாக்க செயல்பாட்டைப் பெறவும் அல்லது அமைக்கவும் `(key, lang) => url`
- `toc.target`: தொடர்புடைய இலக்கு ரெண்டரிங் முனையைப் பெறவும் அல்லது அமைக்கவும் (`c-md` போன்றவை). குறிப்பிடப்படவில்லை என்றால், அது தானாகவே `c-md` / `main` / `article`ஐக் கண்டறியும்
- `toc.load(key)`: கைமுறையாக ஆவண ஏற்றுதல் மற்றும் விசையுடன் தொடர்புடைய அடைவு விரிவாக்கம்
- `toc.sync()`: தற்போதைய இலக்கு முனையில் தலைப்பை கைமுறையாக மீண்டும் அலசவும், இரண்டாம் நிலை கோப்பகத்தை ஒத்திசைக்கவும் மற்றும் நிலையை முன்னிலைப்படுத்தவும்
