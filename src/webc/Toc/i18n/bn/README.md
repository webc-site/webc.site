# ডিরেক্টরি নেভিগেশন উপাদান

- **প্রতিক্রিয়াশীল ড্রয়ার**: প্রশস্ত স্ক্রিনে সাইডবার প্রদর্শন করুন, স্বয়ংক্রিয়ভাবে সংকীর্ণ স্ক্রিনে ভেঙে পড়বে এবং `c-side` ড্রয়ার এবং শিরোনাম ট্রিগার বোতামের সাথে সহযোগিতা করুন
- **মাল্টি-ল্যাংগুয়েজ ড্রাইভার**: অবজেক্ট ডিকশনারি বা বহু-ভাষা ফাংশন সমর্থন করে, স্বয়ংক্রিয়ভাবে ভাষা পরিবর্তনে সাড়া দেয়
- **স্বয়ংক্রিয় সাবডিরেক্টরি**: একটি সেকেন্ডারি ডিরেক্টরি তৈরি করতে এবং হ্যাশ ভিউপোর্ট স্ক্রোলিং হাইলাইট নিরীক্ষণ করতে লক্ষ্য কন্টেইনারে স্বয়ংক্রিয়ভাবে `h1`~`h6` শিরোনাম পার্স করুন৷
- **অসিঙ্ক্রোনাস লোডিং**: অসিঙ্ক্রোনাসভাবে মার্কডাউন টেক্সট স্বয়ংক্রিয়ভাবে প্রাপ্ত করতে একটি ডিরেক্টরি আইটেমে ক্লিক করুন এবং `Ing` লোডিং অ্যানিমেশন প্রদর্শন করে বিষয়বস্তু এলাকায় এটি ইনজেকশন করুন

## ডেমো ব্যবহার করুন

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "ব্যবহার": "উপাদান ব্যবহার করুন"
});
</script>
```

## ইন্টারফেস পরামিতি

### বৈশিষ্ট্য এবং পদ্ধতি

- `toc.prefix`: রাউটিং প্রিফিক্স স্ট্রিং পান বা সেট করুন (যেমন `"doc"`, ট্রেইলিং স্ল্যাশ ঐচ্ছিক), `README` কী স্বয়ংক্রিয়ভাবে একটি খালি পথে ম্যাপ করা হবে (যেমন উপসর্গ নিজেই)
- `toc.li`: ডিরেক্টরি বহু-ভাষা প্রজন্ম ফাংশন পান বা সেট করুন `(lang) => ({ key: title })`৷
- `toc.mdUrl`: মার্কডাউন URL জেনারেশন ফাংশন পান বা সেট করুন `(key, lang) => url`৷
- `toc.target`: সংশ্লিষ্ট টার্গেট রেন্ডারিং নোড পান বা সেট করুন (যেমন `c-md`)। নির্দিষ্ট করা না থাকলে, এটি স্বয়ংক্রিয়ভাবে `c-md` / `main` / `article` খুঁজে পাবে
- `toc.load(key)`: ম্যানুয়ালি ডকুমেন্ট লোডিং এবং কী-এর সাথে সম্পর্কিত ডিরেক্টরি সম্প্রসারণ ট্রিগার করুন
- `toc.sync()`: বর্তমান টার্গেট নোডে ম্যানুয়ালি শিরোনামটি পুনরায় পার্স করুন, সেকেন্ডারি ডিরেক্টরি সিঙ্ক্রোনাইজ করুন এবং স্থিতি হাইলাইট করুন
