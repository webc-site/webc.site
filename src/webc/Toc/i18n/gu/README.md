# ડિરેક્ટરી નેવિગેશન ઘટક

- **રિસ્પોન્સિવ ડ્રોઅર**: પહોળી સ્ક્રીનમાં સાઇડબાર પ્રદર્શિત કરો, સાંકડી સ્ક્રીનમાં આપમેળે સંકુચિત થાઓ અને `c-side` ડ્રોઅર અને શીર્ષક ટ્રિગર બટન સાથે સહકાર આપો
- **મલ્ટી-લેંગ્વેજ ડ્રાઇવર**: ઑબ્જેક્ટ ડિક્શનરી અથવા મલ્ટિ-લેંગ્વેજ ફંક્શનને સપોર્ટ કરે છે, ભાષા સ્વિચિંગને આપમેળે પ્રતિસાદ આપે છે
- **ઓટોમેટિક સબડિરેક્ટરી**: સેકન્ડરી ડાયરેક્ટરી જનરેટ કરવા અને હેશ વ્યુપોર્ટ સ્ક્રોલીંગ હાઇલાઇટને મોનિટર કરવા માટે લક્ષ્ય કન્ટેનરમાં `h1`~`h6` ટાઇટલને આપમેળે પાર્સ કરો.
- **અસુમેળ લોડિંગ**: અસુમેળ રૂપે માર્કડાઉન ટેક્સ્ટને આપમેળે મેળવવા માટે ડિરેક્ટરી આઇટમ પર ક્લિક કરો અને `Ing` લોડિંગ એનિમેશન પ્રદર્શિત કરીને તેને સામગ્રી ક્ષેત્રમાં દાખલ કરો

## ડેમોનો ઉપયોગ કરો

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "ઉપયોગ": "ઘટકનો ઉપયોગ કરો"
});
</script>
```

## ઇન્ટરફેસ પરિમાણો

### ગુણધર્મો અને પદ્ધતિઓ

- `toc.prefix`: રૂટીંગ ઉપસર્ગ સ્ટ્રિંગ મેળવો અથવા સેટ કરો (જેમ કે `"doc"`, પાછળનો સ્લેશ વૈકલ્પિક છે), `README` કી આપમેળે ખાલી પાથ પર મેપ થઈ જશે (એટલે ​​​​કે ઉપસર્ગ પોતે)
- `toc.li`: ડાયરેક્ટરી મલ્ટિ-લેંગ્વેજ જનરેશન ફંક્શન મેળવો અથવા સેટ કરો `(lang) => ({ key: title })`
- `toc.mdUrl`: માર્કડાઉન URL જનરેશન ફંક્શન મેળવો અથવા સેટ કરો `(key, lang) => url`
- `toc.target`: સંકળાયેલ લક્ષ્ય રેન્ડરિંગ નોડ મેળવો અથવા સેટ કરો (જેમ કે `c-md`). જો ઉલ્લેખિત ન હોય, તો તે આપમેળે `c-md` / `main` / `article` શોધશે
- `toc.load(key)`: કીને અનુરૂપ દસ્તાવેજ લોડિંગ અને ડિરેક્ટરી વિસ્તરણને મેન્યુઅલી ટ્રિગર કરો
- `toc.sync()`: વર્તમાન લક્ષ્ય નોડમાં શીર્ષકને મેન્યુઅલી ફરીથી પાર્સ કરો, ગૌણ નિર્દેશિકા અને હાઇલાઇટ સ્થિતિને સિંક્રનાઇઝ કરો
