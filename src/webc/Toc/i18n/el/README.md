# Στοιχείο πλοήγησης καταλόγου

- **Συρτάρι με απόκριση**: Εμφάνιση πλευρικής γραμμής σε ευρεία οθόνη, συμπτύσσεται αυτόματα σε στενή οθόνη και συνεργάζεται με το κουμπί ενεργοποίησης συρταριού και τίτλου `c-side`
- **Πρόγραμμα οδήγησης πολλών γλωσσών**: Υποστηρίζει λεξικό αντικειμένων ή λειτουργίες πολλών γλωσσών, ανταποκρίνεται αυτόματα στην εναλλαγή γλώσσας
- **Αυτόματος υποκατάλογος**: Αναλύστε αυτόματα τους τίτλους `h1`~`h6` στο κοντέινερ προορισμού για να δημιουργήσετε έναν δευτερεύοντα κατάλογο και να παρακολουθήσετε την επισήμανση κύλισης της θύρας προβολής Hash.
- **Ασύγχρονη φόρτωση**: Κάντε κλικ σε ένα στοιχείο καταλόγου για αυτόματη λήψη κειμένου Markdown ασύγχρονα και εισαγωγή του στην περιοχή περιεχομένου, εμφανίζοντας `Ing` κινούμενη εικόνα φόρτωσης

## Χρησιμοποιήστε το demo

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "use": "use component"
});
</script>
```

## Παράμετροι διεπαφής

### Ιδιότητες και μέθοδοι

- `toc.prefix`: Λάβετε ή ορίστε τη συμβολοσειρά του προθέματος δρομολόγησης (όπως `"doc"`, η τελευταία κάθετο είναι προαιρετική), το κλειδί `README` θα αντιστοιχιστεί αυτόματα σε μια κενή διαδρομή (δηλαδή το ίδιο το πρόθεμα)
- `toc.li`: Αποκτήστε ή ορίστε τη λειτουργία δημιουργίας πολλών γλωσσών καταλόγου `(lang) => ({ key: title })`
- `toc.mdUrl`: Αποκτήστε ή ορίστε τη συνάρτηση δημιουργίας URL Markdown `(key, lang) => url`
- `toc.target`: Λάβετε ή ορίστε τον σχετικό κόμβο απόδοσης στόχου (όπως `c-md`). Εάν δεν έχει καθοριστεί, θα βρει αυτόματα `c-md` / `main` / `article`
- `toc.load(key)`: Μη αυτόματη ενεργοποίηση φόρτωσης εγγράφου και επέκταση καταλόγου που αντιστοιχεί στο κλειδί
- `toc.sync()`: Μη αυτόματα αναλύστε ξανά τον τίτλο στον τρέχοντα κόμβο στόχο, συγχρονίστε τον δευτερεύοντα κατάλογο και επισημάνετε την κατάσταση
