# निर्देशिका नेविगेशन घटक

- **रिस्पॉन्सिव ड्रॉअर**: चौड़ी स्क्रीन में साइडबार प्रदर्शित करें, संकीर्ण स्क्रीन में स्वचालित रूप से संक्षिप्त करें और `c-side` ड्रॉअर और शीर्षक ट्रिगर बटन के साथ सहयोग करें
- **मल्टी-लैंग्वेज ड्राइवर**: ऑब्जेक्ट डिक्शनरी या मल्टी-लैंग्वेज फ़ंक्शंस का समर्थन करता है, स्वचालित रूप से भाषा स्विचिंग पर प्रतिक्रिया करता है
- **स्वचालित उपनिर्देशिका**: द्वितीयक निर्देशिका उत्पन्न करने और हैश व्यूपोर्ट स्क्रॉलिंग हाइलाइट की निगरानी करने के लिए लक्ष्य कंटेनर में `h1`~`h6` शीर्षकों को स्वचालित रूप से पार्स करें।
- **एसिंक्रोनस लोडिंग**: स्वचालित रूप से मार्कडाउन टेक्स्ट को एसिंक्रोनस रूप से प्राप्त करने के लिए निर्देशिका आइटम पर क्लिक करें और इसे सामग्री क्षेत्र में इंजेक्ट करें, `Ing` लोडिंग एनीमेशन प्रदर्शित करें

## डेमो का प्रयोग करें

```html
<c-toc></c-toc>
<c-md></c-md>

<script type="module">
import "webc.site/Toc.js";

const toc = document.querySelector("c-toc");
toc.target = document.querySelector("c-md");
toc.prefix = "doc";
toc.mdUrl = (key, lang) => "/doc/" + lang + "/" + key + ".md";
toc.li = (lang) => ({
  "README": "WebC.site",
  "उपयोग करें": "घटक का उपयोग करें"
});
</script>
```

## इंटरफ़ेस पैरामीटर

### गुण और विधियाँ

- `toc.prefix`: रूटिंग उपसर्ग स्ट्रिंग प्राप्त करें या सेट करें (जैसे `"doc"`, अनुगामी स्लैश वैकल्पिक है), `README` कुंजी स्वचालित रूप से एक खाली पथ पर मैप की जाएगी (अर्थात उपसर्ग स्वयं)
- `toc.li`: डायरेक्टरी मल्टी-लैंग्वेज जेनरेशन फ़ंक्शन `(lang) => ({ key: title })` प्राप्त करें या सेट करें
- `toc.mdUrl`: मार्कडाउन यूआरएल जेनरेशन फ़ंक्शन `(key, lang) => url` प्राप्त करें या सेट करें
- `toc.target`: संबंधित लक्ष्य रेंडरिंग नोड प्राप्त करें या सेट करें (जैसे कि `c-md`)। यदि निर्दिष्ट नहीं है, तो यह स्वचालित रूप से `c-md` / `main` / `article` ढूंढ लेगा
- `toc.load(key)`: कुंजी के अनुरूप दस्तावेज़ लोडिंग और निर्देशिका विस्तार को मैन्युअल रूप से ट्रिगर करें
- <बी आईडी = "1">: वर्तमान लक्ष्य नोड में शीर्षक को मैन्युअल रूप से पुन: पार्स करें, द्वितीयक निर्देशिका को सिंक्रनाइज़ करें और स्थिति को हाइलाइट करें
