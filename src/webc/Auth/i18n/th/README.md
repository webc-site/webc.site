# การเข้าสู่ระบบการตรวจสอบสิทธิ์และการลงทะเบียน

รวมการลงทะเบียนและการเข้าสู่ระบบอีเมลและหมายเลขโทรศัพท์มือถือ การตรวจสอบรหัสยืนยัน การเข้าสู่ระบบด้วยรหัสผ่าน และการเข้าสู่ระบบอย่างรวดเร็วของบุคคลที่สาม

- รองรับการป้อนอีเมลและหมายเลขโทรศัพท์มือถือ
- ป้ายลอยน้ำที่มีเนื้อแก้วเหลว
- รองรับการนับถอยหลังรหัสยืนยัน SMS
- รองรับการเข้าสู่ระบบ OAuth ของบุคคลที่สามอย่างรวดเร็วและคำแนะนำที่ผูกมัด

## ใช้การสาธิต

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onSignup = async (mail, name, password, code) => {
  return [0, mail, name, code];
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("การรับรองความถูกต้องสำเร็จ:", e.detail);
});
</script>
```

## สถานะคงที่

- `0` (`STATE_MAIL`): ป้อนอีเมล์
- `1` (`STATE_CODE`): การลงทะเบียนรหัสยืนยันอีเมล
- `2` (`STATE_PASSWD`): เข้าสู่ระบบด้วยรหัสผ่านอีเมล
- `10` (`STATE_PHONE`): กรอกหมายเลขโทรศัพท์มือถือ
- `11` (`STATE_SMS_CODE`): การยืนยันรหัสยืนยันทาง SMS
- `Array` (`OAUTH_HINT`): รายการคำแนะนำการเข้าสู่ระบบของบุคคลที่สาม

## คุณสมบัติและฟังก์ชันฮุก

- `step`: สถานะปัจจุบัน (ตัวเลขหรืออาร์เรย์)
- `mail`: อีเมล
- `phone`: หมายเลขโทรศัพท์มือถือ
- `onSignup(mail, name, password, code)`: ลงทะเบียนการโทรกลับ
- `onResend(mail)`: ส่งรหัสยืนยันกลับอีกครั้ง
- `onLogin(mail, password)`: โทรกลับเข้าสู่ระบบด้วยรหัสผ่าน
- `onSmsSend(phone)`: ส่ง SMS โทรกลับรหัสยืนยัน
- `onSmsVerify(phone, code)`: การยืนยัน SMS โทรกลับรหัสยืนยัน
- `onPassport(provider)`: โทรกลับเข้าสู่ระบบด่วนของบุคคลที่สาม
- `onReset(mail)`: ลืมการโทรกลับเพื่อรีเซ็ตรหัสผ่าน
