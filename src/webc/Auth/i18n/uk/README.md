# Автентифікація входу та реєстрації

Інтегруйте реєстрацію та вхід за номером електронної пошти та мобільного телефону, перевірку коду підтвердження, вхід за паролем і швидкий вхід сторонніх розробників.

- Підтримує перемикання вкладок між електронною адресою та номером мобільного телефону
- Плаваючі етикетки з текстурою рідкого скла
- Підтримується вибір коду міста кількох країн і зворотний відлік коду підтвердження SMS
- Підтримка стороннього OAuth швидкого входу та прив’язаних інструкцій

## Використовуйте демо

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onMail = async (mail) => {
  // Повернення коду статусу: 1 для реєстрації коду підтвердження, 2 для входу з паролем або повернення стороннього масиву для входу ["google", "apple"]
  return 2;
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("Автентифікація успішна:", e.detail);
});
</script>
```

## константа стану

- `0` (`STATE_MAIL`): введення електронної пошти
- `1` (`STATE_CODE`): реєстрація коду підтвердження електронної пошти
- `2` (`STATE_PASSWD`): пароль електронної пошти для входу
- `10` (`STATE_PHONE`): Введіть номер мобільного телефону
- `11` (`STATE_SMS_CODE`): підтвердження коду підтвердження SMS
- `Array` (`OAUTH_HINT`): список інструкцій із входу сторонніх розробників

## Властивості та функції підключення

- `step`: поточний статус (число або масив)
- `mail`: електронна пошта
- `phone`: номер мобільного телефону
- `cc`: міжнародний телефонний код (за замовчуванням 86)
- `onMail(mail)`: зворотний дзвінок перевірки електронної пошти
- `onSignup(mail, name, password)`: Зареєструвати зворотний виклик
- `onLogin(mail, password)`: Зворотний дзвінок для входу з паролем
- `onSmsSend(phone, cc)`: Надіслати зворотній дзвінок із кодом підтвердження SMS
- `onSmsVerify(phone, cc, code)`: SMS-повідомлення з кодом підтвердження зворотного зв’язку
- `onPassport(provider)`: зворотний дзвінок для швидкого входу сторонніх розробників
- `onReset(mail)`: Зворотний виклик для скидання пароля
