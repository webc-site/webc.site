# Аутентификация входа и регистрации

Интегрируйте регистрацию и вход в систему по электронной почте и номеру мобильного телефона, проверку проверочного кода, вход по паролю и быстрый вход через стороннюю систему.

- Поддержка ввода адреса электронной почты и номера мобильного телефона
- Плавающие этикетки с текстурой жидкого стекла
- Поддержка обратного отсчета кода подтверждения по SMS
- Поддержка стороннего быстрого входа в систему OAuth и руководства по привязке

## Используйте демо-версию

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onSignup = async (mail, name, password, code) => {
  return [0, mail, name, code];
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("Аутентификация прошла успешно:", e.detail);
});
</script>
```

## константа статуса

- `0` (`STATE_MAIL`): ввод электронной почты.
- `1` (`STATE_CODE`): регистрация кода подтверждения по электронной почте.
- `2` (`STATE_PASSWD`): вход с паролем по электронной почте.
- `10` (`STATE_PHONE`): введите номер мобильного телефона.
- `11` (`STATE_SMS_CODE`): проверка кода подтверждения по SMS.
- `Array` (`OAUTH_HINT`): список сторонних инструкций по входу в систему.

## Свойства и функции перехвата

- `step`: текущий статус (число или массив)
- `mail`: электронная почта
- `phone`: номер мобильного телефона.
- `onSignup(mail, name, password, code)`: зарегистрировать обратный вызов
- `onResend(mail)`: повторная отправка обратного вызова с кодом подтверждения.
- `onLogin(mail, password)`: обратный вызов для входа в систему с паролем.
- `onSmsSend(phone)`: отправить обратный вызов с кодом подтверждения по SMS.
- `onSmsVerify(phone, code)`: обратный вызов с кодом подтверждения по SMS
- `onPassport(provider)`: сторонний обратный вызов для быстрого входа в систему.
- `onReset(mail)`: обратный вызов для сброса пароля
