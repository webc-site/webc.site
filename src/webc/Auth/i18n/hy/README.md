# Նույնականացում մուտք և գրանցում

Ինտեգրել էլփոստի և բջջային հեռախոսահամարի գրանցումը և մուտքը, հաստատման կոդի հաստատումը, գաղտնաբառի մուտքը և երրորդ կողմի արագ մուտքը:

- Աջակցում է ներդիրների անցումը էլփոստի հասցեի և բջջային հեռախոսահամարի միջև
- Լողացող պիտակներ հեղուկ ապակու հյուսվածքով
- Աջակցում է մի քանի երկրների տարածքային կոդի ընտրությանը և SMS հաստատման կոդի հետհաշվարկին
- Աջակցեք երրորդ կողմի OAuth-ի արագ մուտքին և կապակցված ուղեցույցին

## Օգտագործեք ցուցադրությունը

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onMail = async (mail) => {
  // Վերադարձի կարգավիճակի կոդը՝ 1 հաստատման կոդի գրանցման համար, 2՝ գաղտնաբառի մուտքի համար, կամ վերադարձի երրորդ կողմի մուտքի զանգված ["google", "apple"]
  return 2;
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log ("Նույնականացումը հաջողվեց:", e.detail);
});
</script>
```

## կարգավիճակի հաստատուն

- `0` (`STATE_MAIL`). էլփոստի մուտքագրում
- `1` (`STATE_CODE`). էլփոստի հաստատման կոդի գրանցում
- `2` (`STATE_PASSWD`). էլփոստի գաղտնաբառի մուտք
- `10` (`STATE_PHONE`): Մուտքագրեք բջջային հեռախոսահամարը
- `11` (`STATE_SMS_CODE`). SMS հաստատման կոդի հաստատում
- `Array` (`OAUTH_HINT`). Երրորդ կողմի մուտքի ուղեցույցի ցուցակ

## Հատկություններ և կեռիկի գործառույթներ

- `step`՝ ընթացիկ կարգավիճակը (համար կամ զանգված)
- `mail`՝ էլ
- `phone`՝ բջջային հեռախոսահամար
- `cc`. միջազգային զանգի կոդ (կանխադրված 86)
- `onMail(mail)`. էլփոստի ստուգման հետ կանչ
- `onSignup(mail, name, password)`. Գրանցեք հետզանգ
- `onLogin(mail, password)`. Գաղտնաբառի մուտքի հետ կանչ
- `onSmsSend(phone, cc)`. ուղարկեք SMS հաստատման կոդը հետ կանչելու համար
- `onSmsVerify(phone, cc, code)`. Ստուգման SMS հաստատման կոդը հետ կանչ
- `onPassport(provider)`. երրորդ կողմի արագ մուտքի հետ կանչ
- `onReset(mail)`. Մոռացել եք գաղտնաբառը վերականգնելու հետ կանչը
