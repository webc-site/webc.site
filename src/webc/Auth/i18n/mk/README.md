# Најава и регистрација за автентикација

Интегрирајте регистрација и најавување на е-пошта и број на мобилен телефон, потврда на кодот за потврда, најавување со лозинка и брзо најавување од трета страна.

- Поддржете го внесувањето на е-пошта и бројот на мобилниот телефон
- Лебдечки етикети со текстура на течно стакло
- Поддржете го одбројувањето на кодот за потврда на СМС
- Поддршка за брзо најавување и врзани насоки од трета страна на OAuth

## Користете го демо

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onSignup = async (mail, name, password, code) => {
  return [0, mail, name, code];
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log ("Успешна автентикација:", e.detail);
});
</script>
```

## статус константа

- `0` (`STATE_MAIL`): Внесување на е-пошта
- `1` (`STATE_CODE`): Регистрација на кодот за потврда на е-пошта
- `2` (`STATE_PASSWD`): Најава за лозинка за е-пошта
- `10` (`STATE_PHONE`): Внесете број на мобилен телефон
- `11` (`STATE_SMS_CODE`): Потврда со СМС код за потврда
- `Array` (`OAUTH_HINT`): Список со водич за најавување од трета страна

## Својства и функции на кука

- `step`: моментален статус (број или низа)
- `mail`: е-пошта
- `phone`: број на мобилен телефон
- `onSignup(mail, name, password, code)`: Регистрирајте повратен повик
- `onResend(mail)`: Испратете повторно повратен повик на кодот за потврда
- `onLogin(mail, password)`: Повратен повик за најава за лозинка
- `onSmsSend(phone)`: Испратете СМС код за потврда на повратен повик
- `onSmsVerify(phone, code)`: Повратен повик за верификација СМС код
- `onPassport(provider)`: Брзо повратен повик за најавување од трета страна
- `onReset(mail)`: заборавив повратен повик за ресетирање на лозинката
