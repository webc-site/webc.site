# ავტორიზაცია შესვლა და რეგისტრაცია

ელ.ფოსტისა და მობილური ტელეფონის ნომრის რეგისტრაცია და შესვლა, დამადასტურებელი კოდის დადასტურება, პაროლის შესვლა და მესამე მხარის სწრაფი შესვლა.

- ელ.ფოსტის და მობილური ტელეფონის ნომრის შეყვანის მხარდაჭერა
- მცურავი ეტიკეტები თხევადი მინის ტექსტურით
- SMS-ის დამადასტურებელი კოდის დათვლის მხარდაჭერა
- მხარი დაუჭირეთ მესამე მხარის OAuth-ის სწრაფ შესვლას და შეკრულ მითითებებს

## გამოიყენეთ დემო ვერსია

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onSignup = async (mail, name, password, code) => {
  return [0, mail, name, code];
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("ავთენტიფიკაცია წარმატებულია:", e.detail);
});
</script>
```

## სტატუსი მუდმივი

- `0` (`STATE_MAIL`): ელფოსტის შეყვანა
- `1` (`STATE_CODE`): ელ.ფოსტის დამადასტურებელი კოდის რეგისტრაცია
- `2` (`STATE_PASSWD`): ელ.ფოსტის პაროლის შესვლა
- `10` (`STATE_PHONE`): შეიყვანეთ მობილური ტელეფონის ნომერი
- `11` (`STATE_SMS_CODE`): SMS დამადასტურებელი კოდის დადასტურება
- `Array` (`OAUTH_HINT`): მესამე მხარის შესვლის სახელმძღვანელოს სია

## თვისებები და კაკლის ფუნქციები

- `step`: მიმდინარე სტატუსი (რიცხვი ან მასივი)
- `mail`: ელფოსტა
- `phone`: მობილური ტელეფონის ნომერი
- `onSignup(mail, name, password, code)`: დაარეგისტრირეთ უკურეკვა
- `onResend(mail)`: ხელახლა გაგზავნეთ დამადასტურებელი კოდის გამოძახება
- `onLogin(mail, password)`: პაროლით შესვლის გამოძახება
- `onSmsSend(phone)`: გაგზავნეთ SMS დამადასტურებელი კოდის გამოძახება
- `onSmsVerify(phone, code)`: გადამოწმების SMS დამადასტურებელი კოდის გამოძახება
- `onPassport(provider)`: მესამე მხარის სწრაფი შესვლის გამოძახება
- `onReset(mail)`: დაგავიწყდათ პაროლის გადატვირთვის გამოძახება
