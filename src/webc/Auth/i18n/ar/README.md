# مصادقة تسجيل الدخول والتسجيل

دمج تسجيل البريد الإلكتروني ورقم الهاتف المحمول وتسجيل الدخول والتحقق من رمز التحقق وتسجيل الدخول بكلمة المرور وتسجيل الدخول السريع لجهة خارجية.

- يدعم التبديل بين عنوان البريد الإلكتروني ورقم الهاتف المحمول
- ملصقات عائمة ذات ملمس زجاجي سائل
- يدعم اختيار رمز المنطقة متعدد البلدان والعد التنازلي لرمز التحقق عبر الرسائل القصيرة
- دعم تسجيل الدخول السريع لـ OAuth لجهة خارجية وتوجيهات ملزمة

## استخدم العرض التوضيحي

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onMail = async (mail) => {
  // إرجاع رمز الحالة: 1 لتسجيل رمز التحقق، 2 لتسجيل الدخول بكلمة مرور، أو إرجاع مصفوفة تسجيل دخول الطرف الثالث ["google"، "apple"]
  return 2;
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("نجحت المصادقة:"، e.detail);
});
</script>
```

## ثابت الوضع

- `0` (`STATE_MAIL`): إدخال البريد الإلكتروني
- `1` (`STATE_CODE`): تسجيل رمز التحقق من البريد الإلكتروني
- `2` (`STATE_PASSWD`): تسجيل الدخول بكلمة مرور البريد الإلكتروني
- `10` (`STATE_PHONE`): أدخل رقم الهاتف المحمول
- `11` (`STATE_SMS_CODE`): التحقق من رمز التحقق عبر الرسائل القصيرة
- `Array` (`OAUTH_HINT`): قائمة دليل تسجيل الدخول للجهات الخارجية

## خصائص ووظائف الخطاف

- `step`: الحالة الحالية (رقم أو صفيف)
- `mail`: البريد الإلكتروني
- `phone`: رقم الهاتف المحمول
- `cc`: رمز الاتصال الدولي (الافتراضي 86)
- `onMail(mail)`: رد الاتصال للتحقق من البريد الإلكتروني
- `onSignup(mail, name, password)`: تسجيل رد الاتصال
- `onLogin(mail, password)`: رد اتصال تسجيل الدخول بكلمة المرور
- `onSmsSend(phone, cc)`: إرسال رد الاتصال برمز التحقق عبر الرسائل القصيرة
- `onSmsVerify(phone, cc, code)`: رد الاتصال برمز التحقق عبر الرسائل القصيرة SMS
- `onPassport(provider)`: رد اتصال سريع لتسجيل الدخول من جهة خارجية
- `onReset(mail)`: نسيت رد الاتصال بإعادة تعيين كلمة المرور
