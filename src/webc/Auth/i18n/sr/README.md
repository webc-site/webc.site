# Пријава и регистрација за аутентификацију

Интегришите регистрацију и пријаву на број е-поште и мобилног телефона, верификацију кода, пријаву лозинке и брзу пријаву треће стране.

- Подржава пребацивање картица између адресе е-поште и броја мобилног телефона
- Плутајуће налепнице са текстуром течног стакла
- Подржава избор позивног броја за више земаља и одбројавање СМС верификационог кода
- Подржава брзу пријаву на ОАутх треће стране и везана упутства

## Користите демо

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onMail = async (mail) => {
  // Врати статусни код: 1 за регистрацију верификационог кода, 2 за пријаву лозинком или врати поље за пријављивање треће стране ["гоогле", "аппле"]
  return 2;
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  цонсоле.лог("Аутентификација је успела:", е.детаил);
});
</script>
```

## статус константан

- <б ид="1"> (<б ид="2">): Унос е-поште
- <б ид="1"> (<б ид="2">): Регистрација кода за верификацију е-поште
- <б ид="1"> (<б ид="2">): Лозинка за пријаву путем е-поште
- <б ид="1"> (<б ид="2">): Унесите број мобилног телефона
- <б ид="1"> (<б ид="2">): СМС верификациони код верификације
- <б ид="1"> (<б ид="2">): листа водича за пријављивање треће стране

## Својства и функције куке

- <б ид="1">: тренутни статус (број или низ)
- <б ид="1">: Е-пошта
- <б ид="1">: број мобилног телефона
- <б ид="1">: међународни позивни број (подразумевано 86)
- <б ид="1">: повратни позив за проверу е-поште
- <б ид="1">: Региструјте повратни позив
- <б ид="1">: Повратни позив за пријаву са лозинком
- <б ид="1">: Пошаљи СМС верификациони код за повратни позив
- <б ид="1">: верификациони СМС верификациони код за повратни позив
- <б ид="1">: Повратни позив за брзо пријављивање треће стране
- <б ид="1">: Заборављена лозинка за ресетовање повратног позива
