# Вход и регистрация за удостоверяване

Интегрирайте регистрация и влизане в имейл и номер на мобилен телефон, проверка на код за потвърждение, влизане с парола и бързо влизане на трети страни.

- Поддържа превключване на раздели между имейл адрес и номер на мобилен телефон
- Плаващи етикети с текстура на течно стъкло
- Поддържа избор на регионален код за няколко държави и обратно отброяване на SMS код за потвърждение
- Поддържайте OAuth от трети страни за бързо влизане и свързани насоки

## Използвайте демонстрацията

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onMail = async (mail) => {
  // Върнете код за състояние: 1 за регистрация на код за потвърждение, 2 за влизане с парола или върнете масив за вход от трета страна ["google", "apple"]
  return 2;
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("Удостоверяването е успешно:", e.detail);
});
</script>
```

## константа на състоянието

- `0` (`STATE_MAIL`): Въвеждане на имейл
- `1` (`STATE_CODE`): Регистрация с код за потвърждение на имейл
- `2` (`STATE_PASSWD`): Имейл парола за влизане
- `10` (`STATE_PHONE`): Въведете номер на мобилен телефон
- `11` (`STATE_SMS_CODE`): SMS проверка с код за потвърждение
- `Array` (`OAUTH_HINT`): Списък с ръководства за влизане на трети страни

## Свойства и куки функции

- `step`: текущо състояние (число или масив)
- `mail`: Имейл
- `phone`: номер на мобилен телефон
- `cc`: международен телефонен код (по подразбиране 86)
- `onMail(mail)`: Обратно извикване за проверка на имейл
- `onSignup(mail, name, password)`: Регистрирайте обратно повикване
- `onLogin(mail, password)`: Обратно извикване при влизане с парола
- `onSmsSend(phone, cc)`: Изпратете обратно повикване с код за потвърждение чрез SMS
- `onSmsVerify(phone, cc, code)`: Обратно извикване на код за потвърждение на SMS за потвърждение
- `onPassport(provider)`: Обратно извикване за бързо влизане на трета страна
- `onReset(mail)`: Обратно извикване за нулиране на забравена парола
