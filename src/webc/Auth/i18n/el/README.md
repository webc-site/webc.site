# Είσοδος και εγγραφή ελέγχου ταυτότητας

Ενσωματώστε την εγγραφή και τη σύνδεση με τον αριθμό ηλεκτρονικού ταχυδρομείου και τον αριθμό κινητού τηλεφώνου, την επαλήθευση κωδικού επαλήθευσης, τη σύνδεση με κωδικό πρόσβασης και τη γρήγορη σύνδεση τρίτων.

- Υποστηρίζει εναλλαγή καρτελών μεταξύ διεύθυνσης email και αριθμού κινητού τηλεφώνου
- Πλωτές ετικέτες με υφή υγρού γυαλιού
- Υποστηρίζει επιλογή κωδικού περιοχής πολλών χωρών και αντίστροφη μέτρηση κωδικού επαλήθευσης SMS
- Υποστήριξη γρήγορης σύνδεσης και δεσμευμένης καθοδήγησης OAuth τρίτων

## Χρησιμοποιήστε το demo

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onMail = async (mail) => {
  // Κωδικός κατάστασης επιστροφής: 1 για εγγραφή κωδικού επαλήθευσης, 2 για σύνδεση με κωδικό πρόσβασης ή επιστροφή συστοιχίας σύνδεσης τρίτου μέρους ["google", "apple"]
  return 2;
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("Ο έλεγχος ταυτότητας επιτυχής:", e.detail);
});
</script>
```

## σταθερή κατάσταση

- `0` (`STATE_MAIL`): Εισαγωγή email
- `1` (`STATE_CODE`): Εγγραφή κωδικού επαλήθευσης ηλεκτρονικού ταχυδρομείου
- `2` (`STATE_PASSWD`): Είσοδος κωδικού πρόσβασης μέσω email
- `10` (`STATE_PHONE`): Εισαγάγετε τον αριθμό κινητού τηλεφώνου
- `11` (`STATE_SMS_CODE`): Επαλήθευση κωδικού επαλήθευσης SMS
- `Array` (`OAUTH_HINT`): Λίστα οδηγών σύνδεσης τρίτων

## Ιδιότητες και λειτουργίες αγκίστρου

- `step`: τρέχουσα κατάσταση (αριθμός ή πίνακας)
- `mail`: Email
- `phone`: αριθμός κινητού τηλεφώνου
- `cc`: διεθνής κωδικός κλήσης (προεπιλογή 86)
- `onMail(mail)`: Επιστροφή κλήσης ελέγχου ηλεκτρονικού ταχυδρομείου
- `onSignup(mail, name, password)`: Εγγραφή επανάκλησης
- `onLogin(mail, password)`: Επανάκληση σύνδεσης με κωδικό πρόσβασης
- `onSmsSend(phone, cc)`: Αποστολή επανάκλησης κωδικού επαλήθευσης SMS
- `onSmsVerify(phone, cc, code)`: Επανάκληση κωδικού επαλήθευσης SMS επαλήθευσης
- `onPassport(provider)`: Γρήγορη επανάκληση σύνδεσης τρίτου μέρους
- `onReset(mail)`: Ξέχασα την επανάκληση επαναφοράς κωδικού πρόσβασης
