# Аўтэнтыфікацыя ўваходу і рэгістрацыі

Інтэгруйце рэгістрацыю і ўваход у сістэму электроннай пошты і нумара мабільнага тэлефона, праверку праверачнага кода, пароль і старонні хуткі ўваход.

- Падтрымка ўводу электроннай пошты і нумара мабільнага тэлефона
- Плывучыя этыкеткі з тэкстурай вадкага шкла
- Падтрымка зваротнага адліку кода праверкі SMS
- Падтрымка старонняга OAuth хуткага ўваходу і звязаных інструкцый

## Выкарыстоўвайце дэма

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onSignup = async (mail, name, password, code) => {
  return [0, mail, name, code];
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("Паспяховая аўтэнтыфікацыя:", e.detail);
});
</script>
```

## канстанта стану

- `0` (`STATE_MAIL`): увод электроннай пошты
- `1` (`STATE_CODE`): Рэгістрацыя кода праверкі электроннай пошты
- `2` (`STATE_PASSWD`): Пароль для ўваходу па электроннай пошце
- `10` (`STATE_PHONE`): Увядзіце нумар мабільнага тэлефона
- `11` (`STATE_SMS_CODE`): праверка кода праверкі SMS
- `Array` (`OAUTH_HINT`): спіс старонніх інструкцый па ўваходзе

## Уласцівасці і функцыі падключэння

- `step`: бягучы стан (лік або масіў)
- `mail`: электронная пошта
- `phone`: нумар мабільнага тэлефона
- `onSignup(mail, name, password, code)`: Зарэгістраваць зваротны званок
- `onResend(mail)`: паўторна адправіць зваротны выклік з кодам спраўджання
- `onLogin(mail, password)`: зваротны выклік для ўваходу ў сістэму з паролем
- `onSmsSend(phone)`: Адправіць зваротны выклік з кодам пацверджання праз SMS
- `onSmsVerify(phone, code)`: зваротны выклік кода праверкі праз SMS
- `onPassport(provider)`: старонні зваротны званок хуткага ўваходу
- `onReset(mail)`: Забыты зваротны выклік для скіду пароля
