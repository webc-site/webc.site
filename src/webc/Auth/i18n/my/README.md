# စစ်မှန်ကြောင်းအထောက်အထားဝင်ရောက်ခြင်းနှင့်မှတ်ပုံတင်ခြင်း။

အီးမေးလ်နှင့် မိုဘိုင်းလ်ဖုန်းနံပါတ် မှတ်ပုံတင်ခြင်းနှင့် ဝင်ရောက်ခြင်း၊ အတည်ပြုကုဒ် အတည်ပြုခြင်း၊ စကားဝှက်ဝင်ရောက်ခြင်းနှင့် ပြင်ပကုမ္ပဏီ အမြန်ဝင်ရောက်ခြင်းတို့ကို ပေါင်းစပ်ပါ။

- အီးမေးလ်လိပ်စာနှင့် မိုဘိုင်းဖုန်းနံပါတ်ကြားတွင် တက်ဘ်ပြောင်းခြင်းကို ပံ့ပိုးပေးသည်။
- အရည်ဖန်သားထည်ဖြင့် ရေပေါ်တံဆိပ်များ
- နိုင်ငံပေါင်းစုံ ဧရိယာကုဒ်ရွေးချယ်မှုနှင့် SMS အတည်ပြုကုဒ် နှစ်သစ်ကို ပံ့ပိုးပေးသည်။
- Third-party OAuth အမြန်ဝင်ရောက်ပြီး ကန့်သတ်လမ်းညွှန်မှုကို ပံ့ပိုးပါ။

## ဒီမိုကိုသုံးပါ။

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onMail = async (mail) => {
  // အခြေအနေကုဒ်ပြန်ပို့ခြင်း- အတည်ပြုကုဒ်မှတ်ပုံတင်ခြင်းအတွက် 1၊ စကားဝှက်ဝင်ရောက်မှုအတွက် 2 သို့မဟုတ် ပြင်ပကုမ္ပဏီ အကောင့်ဝင်ခင်းကျင်းခြင်း ["google", "apple"]
  return 2;
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("Authentication အောင်မြင်ပြီ:", e.detail);
});
</script>
```

## အခြေနေ အဆက်မပြတ်

- `0` (`STATE_MAIL`): အီးမေးလ် ထည့်သွင်းမှု
- `1` (`STATE_CODE`): အီးမေးလ် အတည်ပြုကုဒ် မှတ်ပုံတင်ခြင်း။
- `2` (`STATE_PASSWD`): အီးမေးလ် စကားဝှက် အကောင့်ဝင်ပါ။
- `10` (`STATE_PHONE`): မိုဘိုင်းလ်ဖုန်းနံပါတ်ကို ထည့်ပါ။
- `11` (`STATE_SMS_CODE`): SMS အတည်ပြုကုဒ် အတည်ပြုခြင်း။
- `Array` (`OAUTH_HINT`): ပြင်ပအဖွဲ့အစည်း အကောင့်ဝင်ခြင်း လမ်းညွှန်စာရင်း

## ဂုဏ်သတ္တိများနှင့် ချိတ်လုပ်ဆောင်ချက်များ

- `step`- လက်ရှိအခြေအနေ (နံပါတ် သို့မဟုတ် ခင်းကျင်းမှု)
- `mail`- အီးမေးလ်
- `phone`- မိုဘိုင်းဖုန်းနံပါတ်
- `cc`- နိုင်ငံတကာ ဖုန်းခေါ်ဆိုမှုကုဒ် (မူလ 86)
- `onMail(mail)`- အီးမေးလ် ပြန်ခေါ်ရန် စစ်ဆေးပါ။
- `onSignup(mail, name, password)`- ဖုန်းခေါ်ဆိုမှုကို မှတ်ပုံတင်ပါ။
- `onLogin(mail, password)`- စကားဝှက်ဖြင့် ဝင်ရောက်ပြီး ပြန်ခေါ်ပါ။
- `onSmsSend(phone, cc)`- SMS အတည်ပြုကုဒ်ကို ပြန်ခေါ်ပါ။
- `onSmsVerify(phone, cc, code)`- အတည်ပြုခြင်း SMS အတည်ပြုကုဒ် ပြန်ခေါ်ခြင်း။
- `onPassport(provider)`- ပြင်ပကုမ္ပဏီ အမြန်ဝင်ရောက်ပြီး ပြန်ခေါ်ပါ။
- `onReset(mail)`- စကားဝှက်ကို ပြန်သတ်မှတ်ရန် မေ့သွားသဖြင့် ပြန်ခေါ်ပါ။
