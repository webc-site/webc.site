# அங்கீகார உள்நுழைவு மற்றும் பதிவு

மின்னஞ்சல் மற்றும் மொபைல் எண் பதிவு மற்றும் உள்நுழைவு, சரிபார்ப்பு குறியீடு சரிபார்ப்பு, கடவுச்சொல் உள்நுழைவு மற்றும் மூன்றாம் தரப்பு விரைவான உள்நுழைவு ஆகியவற்றை ஒருங்கிணைக்கவும்.

- ஆதரவு மின்னஞ்சல் மற்றும் மொபைல் ஃபோன் எண் உள்ளீடு
- திரவ கண்ணாடி அமைப்புடன் மிதக்கும் லேபிள்கள்
- எஸ்எம்எஸ் சரிபார்ப்புக் குறியீடு கவுண்டவுனை ஆதரிக்கவும்
- மூன்றாம் தரப்பு OAuth விரைவு உள்நுழைவு மற்றும் கட்டுப்பட்ட வழிகாட்டலை ஆதரிக்கவும்

## டெமோவைப் பயன்படுத்தவும்

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onSignup = async (mail, name, password, code) => {
  return [0, mail, name, code];
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("அங்கீகாரம் வெற்றிகரமாக:", e.detail);
});
</script>
```

## நிலை நிலையானது

- `0` (`STATE_MAIL`): மின்னஞ்சல் உள்ளீடு
- `1` (`STATE_CODE`): மின்னஞ்சல் சரிபார்ப்புக் குறியீடு பதிவு
- `2` (`STATE_PASSWD`): மின்னஞ்சல் கடவுச்சொல் உள்நுழைவு
- `10` (`STATE_PHONE`): மொபைல் ஃபோன் எண்ணை உள்ளிடவும்
- `11` (`STATE_SMS_CODE`): SMS சரிபார்ப்புக் குறியீடு சரிபார்ப்பு
- `Array` (`OAUTH_HINT`): மூன்றாம் தரப்பு உள்நுழைவு வழிகாட்டி பட்டியல்

## பண்புகள் மற்றும் கொக்கி செயல்பாடுகள்

- `step`: தற்போதைய நிலை (எண் அல்லது வரிசை)
- `mail`: மின்னஞ்சல்
- `phone`: மொபைல் ஃபோன் எண்
- `onSignup(mail, name, password, code)`: திரும்ப அழைப்பைப் பதிவுசெய்க
- `onResend(mail)`: சரிபார்ப்புக் குறியீட்டின் அழைப்பை மீண்டும் அனுப்பவும்
- `onLogin(mail, password)`: கடவுச்சொல் உள்நுழைவு திரும்ப திரும்ப
- `onSmsSend(phone)`: SMS சரிபார்ப்புக் குறியீட்டை அழைப்பை அனுப்பவும்
- `onSmsVerify(phone, code)`: சரிபார்ப்பு SMS சரிபார்ப்புக் குறியீட்டை திரும்பப் பெறுதல்
- `onPassport(provider)`: மூன்றாம் தரப்பு விரைவான உள்நுழைவு அழைப்பு
- `onReset(mail)`: கடவுச்சொல்லை மீட்டமைக்கும் அழைப்பை மறந்துவிட்டேன்
