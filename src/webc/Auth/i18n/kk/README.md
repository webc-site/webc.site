# Аутентификация логин және тіркеу

Электрондық пошта мен ұялы телефон нөмірін тіркеу мен кіруді, растау кодын тексеруді, құпия сөзге кіруді және үшінші тараптың жылдам кіруін біріктіріңіз.

- Электрондық пошта мекенжайы мен ұялы телефон нөмірі арасында қойынды ауысуын қолдайды
- Сұйық шыны құрылымы бар қалқымалы жапсырмалар
- Көп елдің аймақ кодын таңдауды және SMS растау кодын кері санауды қолдайды
- Үшінші тараптың OAuth жылдам кіруін және байланыстырылған нұсқауларын қолдау

## Демонстрацияны пайдаланыңыз

```html
<c-auth></c-auth>

<script type="module">
import "webc.site/Auth.js";

const auth = document.querySelector("c-auth");

auth.onMail = async (mail) => {
  // Күй кодын қайтару: растау кодын тіркеу үшін 1, құпия сөзге кіру үшін 2 немесе үшінші тараптың кіру массивін қайтару ["google", "apple"]
  return 2;
};

auth.onLogin = async (mail, password) => {
  return [0, mail];
};

auth.addEventListener("auth", (e) => {
  console.log("Аутентификация сәтті өтті:", e.detail);
});
</script>
```

## күй тұрақтысы

- `0` (`STATE_MAIL`): Электрондық поштаны енгізу
- `1` (`STATE_CODE`): Электрондық поштаны растау кодын тіркеу
- `2` (`STATE_PASSWD`): Электрондық пошта құпия сөзімен кіру
- `10` (`STATE_PHONE`): Ұялы телефон нөмірін енгізіңіз
- `11` (`STATE_SMS_CODE`): SMS растау кодын тексеру
- `Array` (`OAUTH_HINT`): Үшінші тараптың кіру нұсқаулығы тізімі

## Қасиеттер және ілмек функциялары

- `step`: ағымдағы күй (сан немесе массив)
- `mail`: электрондық пошта
- `phone`: ұялы телефон нөмірі
- `cc`: халықаралық теру коды (әдепкі 86)
- `onMail(mail)`: электрондық поштаны тексеру кері қоңырау
- `onSignup(mail, name, password)`: кері қоңырауды тіркеу
- `onLogin(mail, password)`: Құпия сөзбен кіруге кері қоңырау шалу
- `onSmsSend(phone, cc)`: SMS растау кодын кері қоңырауды жіберу
- `onSmsVerify(phone, cc, code)`: Тексеру SMS растау коды кері қоңырау
- `onPassport(provider)`: Үшінші тараптың жылдам кіру кері қоңырауы
- `onReset(mail)`: құпия сөзді ысыруды ұмытып қалдыңыз, кері қоңырау шалыңыз
