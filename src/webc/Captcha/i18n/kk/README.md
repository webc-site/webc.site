# Тексеру коды қалқымалы қабаты

Графикалық түртуге негізделген растау коды қалқымалы терезе.

- Қалқымалы терезенің өзара әрекеттесуін және ESC/жабу қолдауын жүзеге асыру үшін BoxX-пен біріктірілген
- Фондық сурет негізінде мақсатты басыңыз
- Қадамды нұқуды болдырмау және автоматты қайталау механизмін қолдайды
- пайдалану
  * Қоғамдық желі:`https://captcha.webc.pub`
  * Жеке орналастыру: [captcha_srv](https://crates.io/crates/captcha_srv)

## Демонстрацияны пайдаланыңыз

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // Тексергеннен кейін таңбалауышты серверге жіберіңіз
  console.log("Тексеруден өткен таңбалауыш:", таңбалауыш);
}
```

## қайтаратын мән

Функцияны шақыру `Promise<string | undefined>` қайтарады:
- **Тексеруден өтті**: Base64URL кодталған (толтырусыз) растау кодын таңбалауыш жолын қайтарады.
- **Жабу немесе Болдырмау**: `undefined` дегенге оралу.

## Тексеру процесі және кері есептен шығару

1. **Триггерді тексеру**: Frontend қоңыраулары `Captcha()`.
2. **Диаграмманы алу**: `Captcha.js` Басылған сурет пен идентификаторды алу үшін `GET /` - `captcha_srv` әрекетін бастаңыз.
3. **Координатты тексеру**: Пайдаланушы шертуді аяқтағаннан кейін, координаттарды тексеру үшін `Captcha.js` `POST /` - `captcha_srv` аралығын бастайды. Тексеру сәтті болса, Base64URL кодталған таңбалауышы қайтарылады.
4. **Бек-енді растау**: Фронт-эндер Токенді веб-сайт серверіне жібереді, ал сервер Tokenді бірден тексеру және жою үшін `captcha_srv` және `GET /verify/{token}` шақырады.

### Есептен шығару нұсқаулары

Веб-сайт сервері фронт-end жіберген `token` мәнін алғаннан кейін, ол `captcha_srv` қызметіне сұрауды бастауы керек:

- **Сұраныс интерфейсі**:`GET /verify/{token}`
- **Жол параметрі**: `token` (база64URL жолы алдыңғы жақтан қайтарылады)
- **Нәтижені қайтару**: `1` тексеруден өткенін және жарамды екенін білдіреді (автоматты түрде жойылады); `0` жарамсыз немесе есептен шығарылған дегенді білдіреді.
