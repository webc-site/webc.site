# সত্যাপন ক'ড পপআপ স্তৰ

গ্ৰাফিক ক্লিকৰ ওপৰত ভিত্তি কৰি সত্যাপন ক'ড পপ-আপ উইণ্ড'।

- পপ-আপ উইন্ডো পাৰস্পৰিক ক্ৰিয়া আৰু ESC/বন্ধ সমৰ্থন প্ৰণয়ন কৰিবলে BoxX ৰ সৈতে সংযুক্ত কৰা হৈছে
- পটভূমিৰ ছবিৰ ওপৰত ভিত্তি কৰি লক্ষ্য ক্লিক কৰক
- ষ্টেপ ক্লিক পূৰ্বৱৰ্তী অৱস্থালৈ আৰু স্বয়ংক্ৰিয় পুনৰ চেষ্টা ব্যৱস্থা সমৰ্থন কৰে
- ব্যৱহাৰ
  * ৰাজহুৱা নেটৱৰ্ক:`https://captcha.webc.pub`
  * ব্যক্তিগত মোতায়েন: [captcha_srv](https://crates.io/crates/captcha_srv)

## ডেমো ব্যৱহাৰ কৰক

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // সত্যাপনৰ পিছত, টোকেনটো বেকএণ্ডলৈ জমা দিয়ক
  console.log("সত্যাপন টোকেন পাছ কৰা হৈছে:", টোকেন);
}
```

## মূল্য ঘূৰাই দিয়ক

ফাংচনটো কল কৰিলে `Promise<string | undefined>`:
- **সত্যাপন পাছ কৰা হৈছে**: Base64URL এনকোড কৰা (কোনো পেডিং নাই) সত্যাপন ক'ড টোকেন ষ্ট্ৰিং ঘূৰাই দিয়ে।
- **বন্ধ বা বাতিল**: `undefined` লৈ উভতি যাওক।

## পৰীক্ষণ প্ৰক্ৰিয়া আৰু বেক-এণ্ড ৰাইট-অফ

1. **ট্ৰিগাৰ বৈধকৰণ**: ফ্ৰন্টএণ্ডে `Captcha()` কল কৰে।
2. **চাৰ্ট পাওক**: `Captcha.js` ক্লিক কৰা ছবি আৰু আইডি পাবলৈ `GET /` ৰ পৰা `captcha_srv` লৈ আৰম্ভ কৰক।
3. **স্থানাংক সত্যাপন**: ব্যৱহাৰকাৰীয়ে ক্লিক সম্পূৰ্ণ কৰাৰ পিছত, `Captcha.js` এ `POST /` ৰ পৰা `captcha_srv` লৈ আৰম্ভ কৰে স্থানাংক পৰীক্ষা কৰিবলৈ। যদি সত্যাপন সফল হয়, এটা Base64URL এনকোড কৰা টোকেন ঘূৰাই দিয়া হব।
4. **বেক-এণ্ড পৰীক্ষণ**: ফ্ৰন্ট-এণ্ডে টোকেন ৱেবছাইট বেকএণ্ডলৈ জমা দিয়ে, আৰু বেকএণ্ডে টোকেনক একেলগে পৰীক্ষা আৰু ধ্বংস কৰিবলৈ `captcha_srv` আৰু `GET /verify/{token}` কল কৰে।

### বেক-এণ্ড ৰাইট-অফ নিৰ্দেশনা

ৱেবছাইট বেকএণ্ডে ফ্ৰন্ট-এণ্ডে জমা দিয়া `token` গ্ৰহণ কৰাৰ পিছত, ইয়াক `captcha_srv` সেৱালৈ এটা অনুৰোধ আৰম্ভ কৰিব লাগিব:

- **অনুৰোধ আন্তঃপৃষ্ঠ**:`GET /verify/{token}`
- **পথ প্ৰাচল**: `token` (Base64URL স্ট্ৰিং সন্মুখৰ শেষৰ দ্বাৰা ঘূৰাই দিয়া হৈছে)
- **ৰিটাৰ্ণ ফলাফল**: `1` ৰ অৰ্থ হ'ল সত্যাপন পাছ কৰা হৈছে আৰু বৈধ (স্বয়ংক্ৰিয়ভাৱে ধ্বংস কৰা হ'ব); `0` মানে অবৈধ বা লিখি পেলোৱা হৈছে।
