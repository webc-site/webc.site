# Слой всплывающего окна с кодом подтверждения

Всплывающее окно с кодом подтверждения при щелчке по графическому изображению.

- В сочетании с BoxX для реализации взаимодействия с всплывающими окнами и поддержки ESC/закрытия.
- Нажмите цель на основе фонового изображения
- Поддерживает отмену пошагового щелчка и механизм автоматической повторной попытки.
- использовать
  * Общественная сеть:`https://captcha.webc.pub`
  * Частное развертывание: [captcha_srv](https://crates.io/crates/captcha_srv)

## Используйте демо-версию

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // После проверки отправьте токен на серверную часть
  console.log("Токен проверки пройден:", token);
}
```

## возвращаемое значение

Вызов функции возвращает `Promise<string | undefined>`:
- **Проверка пройдена**: возвращает строку токена кода подтверждения в кодировке Base64URL (без заполнения).
- **Закрыть или отменить**: возврат к `undefined`.

## Процесс верификации и бэк-энд списание

1. **Проверка триггера**: интерфейсные вызовы `Captcha()`.
2. **Получить диаграмму**: `Captcha.js` Перейдите от `GET /` к `captcha_srv`, чтобы получить изображение и идентификатор, по которому щелкнули.
3. **Проверка координат**: после того, как пользователь завершает щелчок, `Captcha.js` инициирует `POST /` к `captcha_srv` для проверки координат. Если проверка прошла успешно, будет возвращен токен в кодировке Base64URL.
4. **Верхняя проверка**: внешний интерфейс отправляет токен на серверную часть веб-сайта, а серверная часть вызывает `captcha_srv` и `GET /verify/{token}` для немедленной проверки и уничтожения токена.

### Инструкции по резервному списанию

После того как серверная часть веб-сайта получит `token`, отправленный внешним интерфейсом, ей необходимо инициировать запрос к службе `captcha_srv`:

- **Интерфейс запроса**:`GET /verify/{token}`
- **Параметр пути**: `token` (строка Base64URL, возвращаемая внешним интерфейсом)
- **Результат возврата**: `1` означает, что проверка пройдена и действительна (будет автоматически уничтожена); `0` означает недействительный или списанный.
