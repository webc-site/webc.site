# சரிபார்ப்புக் குறியீடு பாப்அப் லேயர்

கிராஃபிக் கிளிக் அடிப்படையில் சரிபார்ப்புக் குறியீடு பாப்-அப் சாளரம்.

- பாப்-அப் விண்டோ இன்டராக்ஷன் மற்றும் ESC/close support ஐ செயல்படுத்த BoxX உடன் இணைந்து
- பின்னணி படத்தின் அடிப்படையில் இலக்கைக் கிளிக் செய்யவும்
- படி கிளிக் செயல்தவிர்க்க மற்றும் தானியங்கி மறுமுயற்சி பொறிமுறையை ஆதரிக்கிறது
- பயன்படுத்த
  * பொது நெட்வொர்க்:`https://captcha.webc.pub`
  * தனிப்பட்ட வரிசைப்படுத்தல்: [captcha_srv](https://crates.io/crates/captcha_srv)

## டெமோவைப் பயன்படுத்தவும்

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // சரிபார்த்த பிறகு, டோக்கனை பின்தளத்தில் சமர்ப்பிக்கவும்
  console.log("சரிபார்ப்பு நிறைவேற்றப்பட்ட டோக்கன்:", டோக்கன்);
}
```

## திரும்ப மதிப்பு

செயல்பாட்டை அழைப்பது `Promise<string | undefined>`:
- **சரிபார்ப்பு நிறைவேற்றப்பட்டது**: Base64URL குறியிடப்பட்ட (பேடிங் இல்லை) சரிபார்ப்புக் குறியீட்டை டோக்கன் சரத்தை வழங்கும்.
- **மூடு அல்லது ரத்துசெய்**: `undefined` க்கு திரும்பவும்.

## சரிபார்ப்பு செயல்முறை மற்றும் பின்-இறுதியில் எழுதுதல்

1. ** தூண்டுதல் சரிபார்ப்பு**: முன்பக்க அழைப்புகள் `Captcha()`.
2. ** விளக்கப்படத்தைப் பெறவும்**: `Captcha.js` கிளிக் செய்த படம் மற்றும் ஐடியைப் பெற `GET /` முதல் `captcha_srv` வரை தொடங்கவும்.
3. **ஒருங்கிணைப்பு சரிபார்ப்பு**: பயனர் கிளிக் செய்த பிறகு, ஆயங்களைச் சரிபார்க்க `Captcha.js` `POST /` to `captcha_srv` ஐ துவக்குகிறது. சரிபார்ப்பு வெற்றிகரமாக இருந்தால், Base64URL குறியிடப்பட்ட டோக்கன் திரும்பப் பெறப்படும்.
4. **பின்-இறுதிச் சரிபார்ப்பு**: முன்-முனையானது டோக்கனை இணையதளத்தின் பின்தளத்தில் சமர்ப்பிக்கிறது, மேலும் பின்தளமானது `captcha_srv` மற்றும் `GET /verify/{token}` டோக்கனை ஒரே நேரத்தில் சரிபார்த்து அழிக்க அழைக்கிறது.

### பின்-இறுதி எழுதுதல் வழிமுறைகள்

முன்-இறுதியால் சமர்ப்பிக்கப்பட்ட `token`ஐ இணையதளப் பின்தளம் பெற்ற பிறகு, அது `captcha_srv` சேவைக்கான கோரிக்கையைத் தொடங்க வேண்டும்:

- **கோரிக்கை இடைமுகம்**:`GET /verify/{token}`
- **பாதை அளவுரு**: `token` (Base64URL சரம் முன் இறுதியில் திரும்பியது)
- **திரும்ப முடிவு**: `1` என்பது சரிபார்ப்பு கடந்து செல்லுபடியாகும் (தானாக அழிக்கப்படும்); `0` என்றால் செல்லாதது அல்லது எழுதப்பட்டுவிட்டது.
