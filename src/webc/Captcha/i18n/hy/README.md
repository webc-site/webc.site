# Հաստատման կոդի ելնող շերտ

Ստուգման կոդի բացվող պատուհան՝ հիմնված գրաֆիկական սեղմման վրա:

- Համակցված է BoxX-ի հետ՝ իրականացնելու թռուցիկ պատուհանի փոխազդեցություն և ESC/փակ աջակցություն
- Սեղմեք թիրախը՝ հիմնվելով ֆոնային պատկերի վրա
- Աջակցում է քայլ սեղմելու հետարկման և ավտոմատ կրկնակի փորձարկման մեխանիզմին
- օգտագործել
  * Հանրային ցանց՝`https://captcha.webc.pub`
  * Մասնավոր տեղակայում՝ [captcha_srv](https://crates.io/crates/captcha_srv)

## Օգտագործեք ցուցադրությունը

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // Ստուգումից հետո նշեք նշանը backend-ին
  console.log ("Ստուգումն անցել է Token:", նշան);
}
```

## վերադարձի արժեքը

Ֆունկցիան կանչելը վերադարձնում է `Promise<string | undefined>`.
- **Ստուգումն անցավ**. վերադարձնում է Base64URL կոդավորված (առանց լրացման) հաստատման կոդը Token տողը:

## Ստուգման գործընթաց և հետին պլանի դուրսգրում

1. **Տիգերի վավերացում**. Frontend զանգեր `Captcha()`:
2. **Ստացեք գծապատկերը**. `Captcha.js` Սկսեք `GET /` դեպի `captcha_srv`՝ սեղմված պատկերն ու ID-ն ստանալու համար:
3. **Կորդինատի ստուգում**. օգտատերն ավարտելուց հետո սեղմումը, `Captcha.js`-ը սկսում է `POST /` դեպի `captcha_srv` կոորդինատները ստուգելու համար: Եթե ​​հաստատումը հաջող է, Base64URL կոդավորված Token-ը կվերադարձվի:
4. **Back-end ստուգում**. Front-end-ը ներկայացնում է Token-ը կայքի հետին մասում, և backend-ը զանգահարում է `captcha_srv` և `GET /verify/{token}`՝ ստուգելու և ոչնչացնելու Token-ը միանգամից:

### Հետևյալ մասի դուրսգրման հրահանգներ

Այն բանից հետո, երբ վեբկայքի հետնամասը կստանա `token` կողմից ներկայացված ճակատային մասը, այն պետք է հարցում սկսի `captcha_srv` ծառայությանը.

- **Պահանջել ինտերֆեյս**:`GET /verify/{token}`
- **Ճանապարհի պարամետր**. `token` (Base64URL տողը վերադարձված է առջևի կողմից)
- **Վերադարձի արդյունքը**. `1` նշանակում է, որ հաստատումն անցել է և վավեր (ավտոմատ կերպով կկործանվի); `0` նշանակում է անվավեր կամ դուրս է գրվել:
