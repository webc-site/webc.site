# සත්‍යාපන කේත උත්පතන ස්ථරය

ග්‍රැෆික් ක්ලික් මත පදනම් වූ සත්‍යාපන කේතය උත්පතන කවුළුව.

- උත්පතන කවුළු අන්තර්ක්‍රියා සහ ESC/සමීප සහාය ක්‍රියාත්මක කිරීමට BoxX සමඟ ඒකාබද්ධ වේ
- පසුබිම් රූපය මත පදනම්ව ඉලක්කය ක්ලික් කරන්න
- පියවර ක්ලික් අහෝසි කිරීමට සහ ස්වයංක්‍රීය නැවත උත්සාහ කිරීමේ යාන්ත්‍රණයට සහය දක්වයි
- භාවිතා කරන්න
  * පොදු ජාලය:`https://captcha.webc.pub`
  * පුද්ගලික යෙදවීම: [captcha_srv](https://crates.io/crates/captcha_srv)

## Demo භාවිතා කරන්න

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // සත්‍යාපනය කිරීමෙන් පසු, ටෝකනය පසු අන්තයට ඉදිරිපත් කරන්න
  console.log("සත්‍යාපනය සමත් වූ ටෝකනය:", ටෝකනය);
}
```

## ආපසු වටිනාකම

ශ්‍රිතය ඇමතීමෙන් `Promise<string | undefined>`:
- **සත්‍යාපනය සමත් විය**: Base64URL කේතනය කළ (පෑඩිං නැත) සත්‍යාපන කේතය ටෝකන් තන්තුව ආපසු ලබා දෙයි.
- **වසන්න හෝ අවලංගු කරන්න**: `undefined` වෙත ආපසු යන්න.

## සත්‍යාපන ක්‍රියාවලිය සහ පසු-අන්ත ලිවීම

1. **ප්‍රේරක වලංගුකරණය**: ඉදිරිපස ඇමතුම් `Captcha()`.
2. **ප්‍රස්ථාරය ලබා ගන්න**: `Captcha.js` ක්ලික් කළ රූපය සහ හැඳුනුම්පත ලබා ගැනීමට `GET /` සිට `captcha_srv` දක්වා ආරම්භ කරන්න.
3. ** සම්බන්ධීකරණ සත්‍යාපනය**: පරිශීලකයා ක්ලික් කිරීම සම්පූර්ණ කළ පසු, `Captcha.js` ඛණ්ඩාංක සත්‍යාපනය කිරීමට `POST /` සිට `captcha_srv` දක්වා ආරම්භ කරයි. සත්‍යාපනය සාර්ථක නම්, Base64URL කේතනය කළ ටෝකනයක් ආපසු ලබා දෙනු ඇත.
4. **පසු අන්ත සත්‍යාපනය**: ඉදිරිපස අන්තය වෙබ් අඩවි පසුපෙළ වෙත ටෝකනය ඉදිරිපත් කරයි, සහ පසු අන්තය `captcha_srv` සහ `GET /verify/{token}` ටෝකනය එකවර සත්‍යාපනය කර විනාශ කිරීමට අමතයි.

### පසු-අන්ත ලිවීමේ උපදෙස්

ඉදිරි අන්තය මඟින් ඉදිරිපත් කරන ලද `token` වෙබ් අඩවිය පසුපෙළට ලැබුණු පසු, එය `captcha_srv` සේවාව වෙත ඉල්ලීමක් ආරම්භ කිරීමට අවශ්‍ය වේ:

- **ඉල්ලුම් අතුරු මුහුණත**:`GET /verify/{token}`
- **මාර්ග පරාමිතිය**: `token` (Base64URL තන්තුව ඉදිරි අන්තයෙන් ආපසු ලබා දී ඇත)
- **ආපසු ප්‍රතිඵලය**: `1` යන්නෙන් අදහස් වන්නේ සත්‍යාපනය සම්මත වී වලංගු වේ (ස්වයංක්‍රීයව විනාශ වනු ඇත); `0` යන්නෙන් අදහස් වන්නේ වලංගු නොවන හෝ කපා හැර ඇති බවයි.
