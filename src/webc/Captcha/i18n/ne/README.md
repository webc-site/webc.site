# प्रमाणिकरण कोड पपअप तह

ग्राफिक क्लिकमा आधारित प्रमाणीकरण कोड पप-अप विन्डो।

- पप-अप विन्डो अन्तरक्रिया र ESC/निकट समर्थन लागू गर्न BoxX सँग संयुक्त
- पृष्ठभूमि छविमा आधारित लक्ष्य क्लिक गर्नुहोस्
- चरण क्लिक अनडू र स्वचालित पुन: प्रयास संयन्त्र समर्थन गर्दछ
- प्रयोग गर्नुहोस्
  * सार्वजनिक नेटवर्क:`https://captcha.webc.pub`
  * निजी परिनियोजन: [captcha_srv](https://crates.io/crates/captcha_srv)

## डेमो प्रयोग गर्नुहोस्

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // प्रमाणीकरण पछि, ब्याकइन्डमा टोकन पेश गर्नुहोस्
  console.log("प्रमाणीकरण पारित टोकन:", टोकन);
}
```

## फिर्ता मूल्य

प्रकार्यलाई कल गर्दा `Promise<string | undefined>` फर्काउँछ:
- **प्रमाणीकरण पास भयो**: Base64URL एन्कोडेड (कुनै प्याडिङ) प्रमाणिकरण कोड टोकन स्ट्रिङ फर्काउँछ।
- **बन्द वा रद्द**: `undefined` मा फर्कनुहोस्।

## प्रमाणीकरण प्रक्रिया र ब्याक-एन्ड राइट-अफ

1. **ट्रिगर प्रमाणीकरण**: फ्रन्टएन्ड कलहरू `Captcha()`।
2. **चार्ट प्राप्त गर्नुहोस्**: `Captcha.js` सुरु गर्नुहोस् `GET /` मा `captcha_srv` क्लिक गरिएको छवि र ID प्राप्त गर्न।
3. **अर्डिनेट प्रमाणिकरण**: प्रयोगकर्ताले क्लिक पूरा गरेपछि, `Captcha.js` प्रारम्भ गर्दछ `POST /` देखि `captcha_srv` निर्देशांकहरू प्रमाणित गर्न। यदि प्रमाणीकरण सफल भयो भने, एउटा Base64URL एन्कोड गरिएको टोकन फिर्ता गरिनेछ।
4. **ब्याक-एन्ड प्रमाणीकरण**: फ्रन्ट-एन्डले वेबसाइट ब्याकइन्डमा टोकन पेश गर्दछ, र ब्याकइन्डले टोकनलाई एकैचोटि प्रमाणित गर्न र नष्ट गर्न `captcha_srv` र `GET /verify/{token}` कल गर्दछ।

### ब्याक-एन्ड राइट-अफ निर्देशनहरू

वेबसाइट ब्याकइन्डले फ्रन्ट-एन्ड द्वारा पेश गरेको `token` प्राप्त गरेपछि, यसले `captcha_srv` सेवामा अनुरोध सुरु गर्न आवश्यक छ:

- **अनुरोध इन्टरफेस**:`GET /verify/{token}`
- **पथ प्यारामिटर**: `token` (बेस ६४URL स्ट्रिङ अगाडिको छेउबाट फर्काइयो)
- **रिटर्न नतिजा**: `1` को अर्थ प्रमाणीकरण पारित र मान्य छ (स्वतः नष्ट हुनेछ); `0` भनेको अवैध वा राइट अफ गरिएको हो।
