# ચકાસણી કોડ પોપઅપ સ્તર

ગ્રાફિક ક્લિક પર આધારિત ચકાસણી કોડ પોપ-અપ વિન્ડો.

- પોપ-અપ વિન્ડો ક્રિયાપ્રતિક્રિયા અને ESC/ક્લોઝ સપોર્ટને અમલમાં મૂકવા માટે BoxX સાથે સંયુક્ત
- પૃષ્ઠભૂમિ છબી પર આધારિત લક્ષ્ય પર ક્લિક કરો
- સ્ટેપ ક્લિક પૂર્વવત્ અને સ્વચાલિત પુનઃપ્રયાસ મિકેનિઝમને સપોર્ટ કરે છે
- ઉપયોગ
  * સાર્વજનિક નેટવર્ક:`https://captcha.webc.pub`
  * ખાનગી જમાવટ: [captcha_srv](https://crates.io/crates/captcha_srv)

## ડેમોનો ઉપયોગ કરો

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // ચકાસણી પછી, બેકએન્ડ પર ટોકન સબમિટ કરો
  console.log("ચકાસણી પાસ ટોકન:", ટોકન);
}
```

## વળતર મૂલ્ય

ફંક્શનને કૉલ કરવાથી `Promise<string | undefined>` પરત મળે છે:
- **ચકાસણી પાસ**: Base64URL એન્કોડેડ (કોઈ પેડિંગ નહીં) વેરિફિકેશન કોડ ટોકન સ્ટ્રિંગ પરત કરે છે.
- **બંધ કરો અથવા રદ કરો**: `undefined` પર પાછા ફરો.

## ચકાસણી પ્રક્રિયા અને બેક-એન્ડ રાઈટ-ઓફ

1. **ટ્રિગર માન્યતા**: ફ્રન્ટએન્ડ કૉલ્સ `Captcha()`.
2. **ચાર્ટ મેળવો**: `Captcha.js` ક્લિક કરેલી છબી અને ID મેળવવા માટે `GET /` થી `captcha_srv` શરૂ કરો.
3. **સંકલન ચકાસણી**: વપરાશકર્તા ક્લિક પૂર્ણ કરે તે પછી, કોઓર્ડિનેટ્સ ચકાસવા માટે `POST /` થી `captcha_srv` શરૂ કરે છે. જો ચકાસણી સફળ થશે, તો Base64URL એન્કોડેડ ટોકન પરત કરવામાં આવશે.
4. **બેક-એન્ડ વેરિફિકેશન**: ફ્રન્ટ-એન્ડ વેબસાઇટ બેકએન્ડ પર ટોકન સબમિટ કરે છે, અને બેકએન્ડ ટોકનને એકસાથે ચકાસવા અને નાશ કરવા માટે `captcha_srv` અને `GET /verify/{token}`ને કૉલ કરે છે.

### બેક-એન્ડ લખવા-બંધ સૂચનાઓ

વેબસાઇટ બેકએન્ડને ફ્રન્ટ-એન્ડ દ્વારા સબમિટ કરેલ `token` પ્રાપ્ત કર્યા પછી, તેને `captcha_srv` સેવાને વિનંતી કરવાની જરૂર છે:

- **વિનંતી ઇન્ટરફેસ**:`GET /verify/{token}`
- **પાથ પેરામીટર**: `token` (બેઝ 64URL સ્ટ્રિંગ આગળના છેડે પરત કરવામાં આવી છે)
- **રીટર્ન પરિણામ**: `1` મતલબ કે ચકાસણી પસાર થઈ ગઈ છે અને માન્ય છે (આપમેળે નાશ પામશે); `0` મતલબ અમાન્ય અથવા રાઈટ ઓફ કરવામાં આવેલ છે.
