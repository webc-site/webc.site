# ଯାଞ୍ଚ କୋଡ୍ ପପ୍ଅପ୍ ସ୍ତର |

ଗ୍ରାଫିକ୍ କ୍ଲିକ୍ ଉପରେ ଆଧାର କରି ଯାଞ୍ଚ କୋଡ୍ ପପ୍-ଅପ୍ ୱିଣ୍ଡୋ |

- ପପ୍-ଅପ୍ ୱିଣ୍ଡୋ ଇଣ୍ଟରାକେସନ୍ ଏବଂ ESC / ବନ୍ଦ ସମର୍ଥନକୁ କାର୍ଯ୍ୟକାରୀ କରିବା ପାଇଁ BoxX ସହିତ ମିଶ୍ରିତ |
- ପୃଷ୍ଠଭୂମି ପ୍ରତିଛବି ଉପରେ ଆଧାର କରି ଲକ୍ଷ୍ୟ କ୍ଲିକ୍ କରନ୍ତୁ |
- ଷ୍ଟେପ୍ କ୍ଲିକ୍ ପୂର୍ବବତ୍ ଏବଂ ସ୍ୱୟଂଚାଳିତ ପୁନ ry ଚେଷ୍ଟା ପ୍ରଣାଳୀକୁ ସମର୍ଥନ କରେ |
- ବ୍ୟବହାର କରନ୍ତୁ |
  * ସର୍ବସାଧାରଣ ନେଟୱାର୍କ: `https://captcha.webc.pub` |
  * ବ୍ୟକ୍ତିଗତ ନିୟୋଜନ: [capcha_srv] (/ 0)

## ଡେମୋ ବ୍ୟବହାର କରନ୍ତୁ |

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // ଯାଞ୍ଚ ପରେ, ବ୍ୟାକେଣ୍ଡରେ ଟୋକେନ୍ ଦାଖଲ କରନ୍ତୁ |
  console.log ("ଯାଞ୍ଚ ଟୋକେନ୍ ପାସ୍ ହେଲା:", ଟୋକେନ୍);
}
```

## ଫେରସ୍ତ ମୂଲ୍ୟ

ଫଙ୍କସନ୍ କୁ କଲ୍ କରିବା `Promise<string | undefined>`:
- ** ଯାଞ୍ଚ ପାସ୍ ହୋଇଛି **: Base64URL ଏନକୋଡେଡ୍ (ପ୍ୟାଡିଂ ନାହିଁ) ଯାଞ୍ଚ କୋଡ୍ ଟୋକେନ୍ ଷ୍ଟ୍ରିଙ୍ଗକୁ ଫେରସ୍ତ କରେ |
- ** ବନ୍ଦ କିମ୍ବା ବାତିଲ୍ **: `undefined` କୁ ଫେରନ୍ତୁ |

## ଯାଞ୍ଚ ପ୍ରକ୍ରିୟା ଏବଂ ବ୍ୟାକ୍-ଏଣ୍ଡ୍ ଲିଖନ |

1. ** ଟ୍ରିଗର ବ valid ଧତା **: ଫ୍ରଣ୍ଟେଣ୍ଡ କଲ୍ `Captcha()` |
2. ** ଚାର୍ଟ ପାଆନ୍ତୁ **: `Captcha.js` କ୍ଲିକ୍ ହୋଇଥିବା ପ୍ରତିଛବି ଏବଂ ID ପାଇବାକୁ `GET /` ରୁ `captcha_srv` ଆରମ୍ଭ କରନ୍ତୁ |
3. ** ସମନ୍ୱୟ ଯାଞ୍ଚ **: ଉପଭୋକ୍ତା କ୍ଲିକ୍ ସମାପ୍ତ କରିବା ପରେ, `Captcha.js` ସଂଯୋଜନା ଯାଞ୍ଚ କରିବାକୁ `POST /` ରୁ `captcha_srv` ଆରମ୍ଭ କରେ | ଯଦି ଯାଞ୍ଚ ସଫଳ ହୁଏ, ଏକ Base64URL ଏନକୋଡେଡ୍ ଟୋକେନ୍ ଫେରସ୍ତ ହେବ |
4. ** ବ୍ୟାକ୍-ଏଣ୍ଡ ଯାଞ୍ଚ **: ଫ୍ରଣ୍ଟ-ଏଣ୍ଡ ଟୋକେନକୁ ୱେବସାଇଟ୍ ବ୍ୟାକେଣ୍ଡକୁ ଦାଖଲ କରେ, ଏବଂ ବ୍ୟାକଏଣ୍ଡ କଲ୍ `captcha_srv` ଏବଂ `GET /verify/{token}` ଥରେ ଟୋକେନ୍ ଯାଞ୍ଚ ଏବଂ ନଷ୍ଟ କରିବାକୁ କଲ୍ କରେ |

### ବ୍ୟାକ୍-ଏଣ୍ଡ୍ ଲିଖନ ନିର୍ଦ୍ଦେଶାବଳୀ |

ୱେବସାଇଟ୍ ବ୍ୟାକେଣ୍ଡ୍ ଫ୍ରଣ୍ଟ-ଏଣ୍ଡ ଦ୍ୱାରା ଦାଖଲ ହୋଇଥିବା `token` ପାଇବା ପରେ, ଏହା `captcha_srv` ସେବାକୁ ଏକ ଅନୁରୋଧ ଆରମ୍ଭ କରିବା ଆବଶ୍ୟକ:

- ** ଇଣ୍ଟରଫେସ୍ ଅନୁରୋଧ **: `GET /verify/{token}` |
- ** ପଥ ପାରାମିଟର **: `token` (Base64URL ଷ୍ଟ୍ରିଙ୍ଗ ଆଗ ଭାଗ ଦ୍ୱାରା ଫେରିଛି)
- ** ଫେରସ୍ତ ଫଳାଫଳ **: `1` ଅର୍ଥାତ୍ ଯାଞ୍ଚ ପାସ୍ ହୋଇଛି ଏବଂ ବ valid ଧ (ସ୍ୱୟଂଚାଳିତ ଭାବରେ ନଷ୍ଟ ହୋଇଯିବ); `0` ଅର୍ଥ ଅବ alid ଧ କିମ୍ବା ଲିଖିତ ହୋଇସାରିଛି |
