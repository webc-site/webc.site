# सत्यापन कोड पॉपअप परत

ग्राफिक क्लिक के आधार पर सत्यापन कोड पॉप-अप विंडो।

- पॉप-अप विंडो इंटरेक्शन और ईएससी/क्लोज सपोर्ट को लागू करने के लिए BoxX के साथ संयुक्त
- पृष्ठभूमि छवि के आधार पर लक्ष्य पर क्लिक करें
- चरण क्लिक पूर्ववत और स्वचालित पुनः प्रयास तंत्र का समर्थन करता है
- उपयोग
  * सार्वजनिक नेटवर्क:`https://captcha.webc.pub`
  * निजी परिनियोजन: [captcha_srv](https://crates.io/crates/captcha_srv)

## डेमो का प्रयोग करें

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // सत्यापन के बाद, टोकन को बैकएंड पर सबमिट करें
  कंसोल.लॉग ("सत्यापन पारित टोकन:", टोकन);
}
```

## वापसी मूल्य

फ़ंक्शन को कॉल करने से `Promise<string | undefined>` प्राप्त होता है:
- **सत्यापन पारित**: Base64URL एन्कोडेड (कोई पैडिंग नहीं) सत्यापन कोड टोकन स्ट्रिंग लौटाता है।
- **बंद करें या रद्द करें**: `undefined` पर वापस लौटें।

## सत्यापन प्रक्रिया और बैक-एंड राइट-ऑफ़

1. **ट्रिगर सत्यापन**: फ्रंटएंड कॉल `Captcha()`।
2. **चार्ट प्राप्त करें**: `Captcha.js` क्लिक की गई छवि और आईडी प्राप्त करने के लिए `GET /` से `captcha_srv` आरंभ करें।
3. **समन्वय सत्यापन**: उपयोगकर्ता द्वारा क्लिक पूरा करने के बाद, `Captcha.js` निर्देशांक को सत्यापित करने के लिए `POST /` से `captcha_srv` शुरू करता है। यदि सत्यापन सफल होता है, तो Base64URL एन्कोडेड टोकन वापस कर दिया जाएगा।
4. **बैक-एंड सत्यापन**: फ्रंट-एंड टोकन को वेबसाइट बैकएंड पर सबमिट करता है, और बैकएंड टोकन को एक ही बार में सत्यापित और नष्ट करने के लिए `captcha_srv` और `GET /verify/{token}` पर कॉल करता है।

### बैक-एंड राइट-ऑफ़ निर्देश

वेबसाइट बैकएंड को फ्रंट-एंड द्वारा सबमिट किया गया `token` प्राप्त होने के बाद, उसे `captcha_srv` सेवा के लिए एक अनुरोध शुरू करने की आवश्यकता होती है:

- **अनुरोध इंटरफ़ेस**:`GET /verify/{token}`
- **पथ पैरामीटर**: `token` (Base64URL स्ट्रिंग फ्रंट एंड द्वारा लौटाई गई)
- **वापसी परिणाम**: `1` का अर्थ है कि सत्यापन पारित हो गया है और वैध है (स्वचालित रूप से नष्ट हो जाएगा); `0` का अर्थ है अमान्य या बट्टे खाते में डाल दिया गया है।
