# لایه بازشو کد تأیید

پنجره پاپ آپ کد تأیید بر اساس کلیک گرافیکی.

- همراه با BoxX برای اجرای تعامل پنجره پاپ آپ و پشتیبانی ESC/close
- بر اساس تصویر پس زمینه روی هدف کلیک کنید
- پشتیبانی از خنثیسازی کلیک مرحله ای و مکانیزم تلاش مجدد خودکار
- استفاده کنید
  * شبکه عمومی:`https://captcha.webc.pub`
  * استقرار خصوصی: [captcha_srv](https://crates.io/crates/captcha_srv)

## از دمو استفاده کنید

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // پس از تأیید، توکن را به باطن ارسال کنید
  console.log("Verification pass Token:", token);
}
```

## ارزش بازگشتی

فراخوانی تابع `Promise<string | undefined>` را برمی گرداند:
- **Verification Passed**: رشته رمز تأیید کد شده Base64URL (بدون بالشتک) را برمی‌گرداند.
- **بستن یا لغو**: بازگشت به `undefined`.

## فرآیند تأیید و بازنویسی

1. **تأیید اعتبار محرک**: فراخوانی `Captcha()`.
2. **دریافت نمودار**: `Captcha.js` `GET /` را به `captcha_srv` راه اندازی کنید تا روی تصویر و شناسه کلیک کنید.
3. **تأیید مختصات**: پس از اینکه کاربر کلیک را کامل کرد، `Captcha.js` `POST /` تا `captcha_srv` را برای تأیید مختصات آغاز می کند. اگر تأیید موفقیت آمیز باشد، یک توکن رمزگذاری شده Base64URL برگردانده می شود.
4. **تأیید بک‌اند**: فرانت‌اند توکن را به باطن وب‌سایت ارسال می‌کند، و باطن با `captcha_srv` و `GET /verify/{token}` تماس می‌گیرد تا توکن را به یکباره تأیید و نابود کند.

### دستورالعمل‌های حذف بک‌اند

پس از دریافت `token` ارائه شده توسط بخش جلویی وب سایت، باید درخواستی را به سرویس `captcha_srv` ارسال کند:

- **واسط درخواست**:`GET /verify/{token}`
- **پارامتر مسیر**: `token` (رشته Base64URL توسط قسمت جلو برگردانده شد)
- **نتیجه بازگشت **: `1` به این معنی است که تأیید تأیید شده است و معتبر است (به طور خودکار از بین می رود). `0` به معنای نامعتبر است یا حذف شده است.
