# Слој на скокачки код за потврда

Појавен прозорец за кодот за верификација врз основа на графички клик.

- Во комбинација со BoxX за спроведување на интеракција со скокачки прозорец и поддршка за ESC/затворање
- Кликнете на целта врз основа на сликата за позадина
- Поддржува механизам за враќање на чекор-клик и автоматско повторување
- употреба
  * Јавна мрежа:`https://captcha.webc.pub`
  * Приватно распоредување: [captcha_srv](https://crates.io/crates/captcha_srv)

## Користете го демо

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // По верификацијата, доставете го токенот до задниот дел
  console.log ("Потврдена е токен:", токен);
}
```

## повратна вредност

Повикувањето на функцијата враќа `Promise<string | undefined>`:
- **Верификацијата е помината**: Ја враќа кодираната Base64URL (без полнење) кодот за верификација низа токен.
- **Затвори или Откажи**: Врати се на `undefined`.

## Процес на верификација и отпишување назад

1. **Потврда за активирање**: Повици од предниот дел `Captcha()`.
2. **Добијте графикон**: `Captcha.js` иницирајте `GET /` до `captcha_srv` за да добиете кликна слика и проект.
3. **Потврда на координати**: Откако корисникот ќе го заврши кликнувањето, `Captcha.js` иницира `POST /` до `captcha_srv` за да ги потврди координатите. Ако потврдата е успешна, ќе се врати токен кодиран со Base64URL.
4. **Потврда од задна страна**: предниот дел го доставува токенот до задниот дел на веб-локацијата, а задниот дел ги повикува `captcha_srv` и `GET /verify/{token}` за да го потврдат и уништи токенот одеднаш.

### Инструкции за отпишување на задниот дел

Откако заднината на веб-локацијата ќе го добие `token` поднесен од предниот дел, треба да иницира барање до услугата `captcha_srv`:

- **Побарајте интерфејс**:`GET /verify/{token}`
- **Параметар на патека**: `token` (низата Base64URL вратена од предниот крај)
- **Врати резултат**: `1` значи дека потврдата е помината и валидна (автоматски ќе биде уништена); `0` значи неважечки или е отпишан.
