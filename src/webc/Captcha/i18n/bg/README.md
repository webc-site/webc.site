# Изскачащ слой с код за потвърждение

Изскачащ прозорец с код за потвърждение въз основа на графично щракване.

- Комбиниран с BoxX за внедряване на взаимодействие с изскачащи прозорци и поддръжка за ESC/затваряне
- Кликнете върху целта въз основа на фоновото изображение
- Поддържа стъпково щракване за отмяна и механизъм за автоматичен повторен опит
- използване
  * Обществена мрежа:`https://captcha.webc.pub`
  * Частно внедряване: [captcha_srv](https://crates.io/crates/captcha_srv)

## Използвайте демонстрацията

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // След проверка изпратете токена към бекенда
  console.log("Проверката е преминала Токен:", токен);
}
```

## върната стойност

Извикването на функцията връща `Promise<string | undefined>`:
- **Потвърждението е преминало**: Връща Base64URL кодиран (без подпълване) код за потвърждение Токен низ.
- **Затваряне или Отказ**: Върнете се към `undefined`.

## Процес на проверка и обратно отписване

1. **Потвърждение на задействане**: Frontend извиквания `Captcha()`.
2. **Вземете диаграма**: `Captcha.js` Стартирайте `GET /` към `captcha_srv`, за да получите кликнато изображение и ID.
3. **Проверка на координати**: След като потребителят завърши щракването, `Captcha.js` инициира `POST /` към `captcha_srv` за проверка на координатите. Ако проверката е успешна, ще бъде върнат токен, кодиран с Base64URL.
4. **Потвърждение в задния край**: Предният край изпраща Токена към бекенда на уебсайта, а бекендът извиква `captcha_srv` и `GET /verify/{token}`, за да потвърди и унищожи Токена наведнъж.

### Инструкции за обратно отписване

След като бекендът на уебсайта получи `token`, изпратен от предния край, той трябва да инициира заявка към услугата `captcha_srv`:

- **Интерфейс за заявка**:`GET /verify/{token}`
- **Параметър на пътя**: `token` (Base64URL низ, върнат от предния край)
- **Върнат резултат**: `1` означава, че проверката е преминала и е валидна (ще бъде автоматично унищожена); `0` означава невалиден или е бил отписан.
