# تصديق ڪوڊ پاپ اپ پرت

تصديق ڪوڊ پاپ اپ ونڊو گرافڪ ڪلڪ جي بنياد تي.

- BoxX سان گڏ پاپ اپ ونڊو رابطي ۽ ESC / بند سپورٽ کي لاڳو ڪرڻ لاءِ
- پس منظر جي تصوير جي بنياد تي ٽارگيٽ تي ڪلڪ ڪريو
- سپورٽ قدم ڪلڪ واپس ڪريو ۽ خودڪار طريقي سان ٻيهر ڪوشش ڪريو
- استعمال ڪرڻ
  * عوامي نيٽ ورڪ:`https://captcha.webc.pub`
  * پرائيويٽ ڊيپلائيمينٽ: [captcha_srv](https://crates.io/crates/captcha_srv)

## ڊيمو استعمال ڪريو

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // تصديق کان پوء، ٽوڪن جمع ڪريو پس منظر ڏانهن
  console.log("تصديق منظور ٿيل ٽوڪن:"، ٽوڪن)؛
}
```

## واپسي جي قيمت

فنڪشن کي ڪال ڪرڻ سان واپسي `Promise<string | undefined>`:
- **تصديق پاس ٿيل**: واپس ڪري ٿو Base64URL انڪوڊ ٿيل (نه پيڊنگ) تصديقي ڪوڊ ٽوڪن اسٽرنگ.
- **بند يا منسوخ**: واپس وڃو `undefined`.

## تصديق جي عمل ۽ پوئتي-آخر لکڻ بند

1. **ٽريگر جي تصديق**: فرنٽيڊ ڪالز `Captcha()`.
2. **چارٽ حاصل ڪريو**: `Captcha.js` شروع ڪريو `GET /` ڏانهن `captcha_srv` ڪلڪ ڪيل تصوير ۽ ID حاصل ڪرڻ لاءِ.
3. **Coordinate verification**: يوزر ڪلڪ مڪمل ڪرڻ کان پوءِ، `Captcha.js` شروع ڪري ٿو `POST /` کان `captcha_srv` همراهن جي تصديق ڪرڻ لاءِ. جيڪڏهن تصديق ڪامياب ٿئي ٿي، هڪ Base64URL انڪوڊ ٿيل ٽوڪن واپس ڪيو ويندو.
4. **بئڪ-اينڊ جي تصديق**: فرنٽ-اينڊ ٽوڪن کي ويب سائيٽ جي پس منظر ۾ جمع ڪري ٿو، ۽ بيڪ اينڊ ڪال ڪري ٿو `captcha_srv` ۽ `GET /verify/{token}` ٽوڪن کي هڪ ڀيرو تصديق ڪرڻ ۽ تباهه ڪرڻ لاءِ.

### پوئتي-آخر لکڻ بند هدايتون

ويب سائيٽ جي پس منظر حاصل ڪرڻ کان پوءِ `token` فرنٽ-اينڊ طرفان جمع ڪرايل، ان کي `captcha_srv` سروس ڏانهن هڪ درخواست شروع ڪرڻ جي ضرورت آهي:

- **درخواست انٽرفيس**:`GET /verify/{token}`
- **رستو پيٽرولر**: `token` (بيس 64URL اسٽرنگ اڳئين آخر کان واپس آيو)
- **واپسي جو نتيجو**: `1` مطلب ته تصديق ٿي چڪي آهي ۽ صحيح (خود بخود تباهه ٿي ويندي)؛ `0` جو مطلب آهي غلط يا لکيو ويو آهي بند.
