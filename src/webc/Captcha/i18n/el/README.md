# Αναδυόμενο επίπεδο κωδικού επαλήθευσης

Αναδυόμενο παράθυρο κωδικού επαλήθευσης βάσει γραφικού κλικ.

- Συνδυάζεται με το BoxX για την εφαρμογή αλληλεπίδρασης αναδυόμενων παραθύρων και υποστήριξης ESC/close
- Κάντε κλικ στο στόχο με βάση την εικόνα φόντου
- Υποστηρίζει μηχανισμό αναίρεσης βήματος κλικ και αυτόματης επανάληψης
- χρήση
  * Δημόσιο δίκτυο:`https://captcha.webc.pub`
  * Ιδιωτική ανάπτυξη: [captcha_srv](https://crates.io/crates/captcha_srv)

## Χρησιμοποιήστε το demo

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // Μετά την επαλήθευση, υποβάλετε το διακριτικό στο backend
  console.log("Verification passed Token:", token);
}
```

## επιστρεφόμενη τιμή

Η κλήση της συνάρτησης επιστρέφει `Promise<string | undefined>`:
- **Επαλήθευση πέρασε**: Επιστρέφει τη συμβολοσειρά του κωδικού επαλήθευσης κωδικοποιημένου από το Base64URL (χωρίς padding).
- **Κλείσιμο ή Ακύρωση**: Επιστροφή στο `undefined`.

## Διαδικασία επαλήθευσης και διαγραφή back-end

1. **Επικύρωση ενεργοποίησης**: Κλήσεις διεπαφής `Captcha()`.
2. **Λήψη γραφήματος**: `Captcha.js` Εκκινήστε το `GET /` σε `captcha_srv` για να λάβετε την εικόνα και το αναγνωριστικό στα οποία έγινε κλικ.
3. **Επαλήθευση συντεταγμένων**: Αφού ο χρήστης ολοκληρώσει το κλικ, το `Captcha.js` εκκινεί το `POST /` έως το `captcha_srv` για να επαληθεύσει τις συντεταγμένες. Εάν η επαλήθευση είναι επιτυχής, θα επιστραφεί ένα κωδικοποιημένο διακριτικό Base64URL.
4. **Επαλήθευση Back-end**: Το front-end υποβάλλει το Token στο backend του ιστότοπου και το backend καλεί τα `captcha_srv` και τα `GET /verify/{token}` για επαλήθευση και καταστροφή του Token αμέσως.

### Οδηγίες διαγραφής back-end

Αφού το backend του ιστότοπου λάβει το `token` που υποβλήθηκε από το front-end, πρέπει να ξεκινήσει ένα αίτημα στην υπηρεσία `captcha_srv`:

- **Αίτημα διεπαφής**:`GET /verify/{token}`
- **Παράμετρος διαδρομής**: `token` (συμβολοσειρά Base64URL που επιστράφηκε από τη διεπαφή)
- **Αποτέλεσμα επιστροφής**: `1` σημαίνει ότι η επαλήθευση έχει περάσει και είναι έγκυρη (θα καταστραφεί αυτόματα). `0` σημαίνει μη έγκυρο ή έχει διαγραφεί.
