# Искачући слој са верификационим кодом

Искачући прозор кода за верификацију заснован на графичком клику.

- У комбинацији са БокКс-ом за имплементацију интеракције искачућих прозора и подршке за ЕСЦ/затварање
- Кликните на циљ на основу слике у позадини
- Подржава механизам поништавања корака клика и аутоматског поновног покушаја
- користити
  * Јавна мрежа:<б ид="1">
  * Приватно распоређивање: [цаптцха_срв](https://crates.io/crates/captcha_srv)

## Користите демо

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // Након верификације, доставите токен у позадину
  цонсоле.лог("Верификација је прошла токен:", токен);
}
```

## повратна вредност

Позивање функције враћа <б ид="1">:
- **Верификација је прошла**: Враћа Басе64УРЛ кодиран (без допуна) верификациони код стринг токена.
- **Затвори или откажи**: Вратите се на <б ид="1">.

## Процес верификације и бацк-енд отпис

1. **Провера окидача**: Фронтенд позиви <б ид="1">.
2. **Набавите графикон**: <б ид="1"> Покрените <б ид="3"> на <б ид="2"> да бисте добили слику и ИД на које сте кликнули.
3. **Верификација координата**: Након што корисник заврши клик, <б ид="1"> покреће <б ид="3"> у <б ид="2"> да би потврдио координате. Ако је верификација успешна, токен кодиран Басе64УРЛ ће бити враћен.
4. **Позадинска верификација**: Фронт-енд шаље токен на позадину веб-сајта, а позадински систем позива <б ид="1"> и <б ид="2"> да верификује и уништи токен одједном.

### Бацк-енд упутства за отпис

Након што позадински део веб-сајта прими <б ид="1"> који је послао фронт-енд, потребно је да покрене захтев за услугу <б ид="2">:

- **Интерфејс захтева**:<б ид="1">
- **Параметар путање**: <б ид="1"> (низ Басе64УРЛ који враћа предњи крај)
- **Врати резултат**: <б ид="1"> значи да је верификација прошла и важећа (биће аутоматски уништена); <б ид="2"> значи неважећи или је отписан.
