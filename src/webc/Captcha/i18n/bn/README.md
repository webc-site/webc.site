# যাচাইকরণ কোড পপআপ স্তর

গ্রাফিক ক্লিকের উপর ভিত্তি করে যাচাইকরণ কোড পপ-আপ উইন্ডো।

- পপ-আপ উইন্ডো ইন্টারঅ্যাকশন এবং ESC/ক্লোজ সমর্থন বাস্তবায়ন করতে BoxX-এর সাথে মিলিত
- ব্যাকগ্রাউন্ড ইমেজ উপর ভিত্তি করে লক্ষ্য ক্লিক করুন
- ধাপে ক্লিক পূর্বাবস্থায় এবং স্বয়ংক্রিয় পুনরায় চেষ্টা প্রক্রিয়া সমর্থন করে
- ব্যবহার
  * পাবলিক নেটওয়ার্ক:`https://captcha.webc.pub`
  * ব্যক্তিগত স্থাপনা: [ক্যাপচা_এসআরভি](https://crates.io/crates/captcha_srv)

## ডেমো ব্যবহার করুন

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // যাচাই করার পরে, ব্যাকএন্ডে টোকেন জমা দিন
  console.log("যাচাইকরণ পাস টোকেন:", টোকেন);
}
```

## রিটার্ন মান

ফাংশন কল করলে `Promise<string | undefined>` ফিরে আসে:
- **যাচাই পাস**: Base64URL এনকোড করা (কোন প্যাডিং নেই) যাচাইকরণ কোড টোকেন স্ট্রিং ফেরত দেয়।
- **বন্ধ বা বাতিল**: `undefined` এ ফিরে যান।

## যাচাইকরণ প্রক্রিয়া এবং ব্যাক-এন্ড লেখা বন্ধ

1. **ট্রিগার বৈধতা**: ফ্রন্টএন্ড কল `Captcha()`।
2. **চার্ট পান**: `Captcha.js` ক্লিক করা ছবি এবং আইডি পেতে `GET /` থেকে `captcha_srv` শুরু করুন।
3. **সমন্বয় যাচাই**: ব্যবহারকারী ক্লিক সম্পূর্ণ করার পরে, স্থানাঙ্ক যাচাই করতে `POST /` থেকে `captcha_srv` শুরু করে৷ যাচাইকরণ সফল হলে, একটি Base64URL এনকোডেড টোকেন ফেরত দেওয়া হবে।
4. **ব্যাক-এন্ড ভেরিফিকেশন**: ফ্রন্ট-এন্ড ওয়েবসাইট ব্যাকএন্ডে টোকেন জমা দেয় এবং ব্যাকএন্ড একবারে টোকেন যাচাই ও ধ্বংস করতে `captcha_srv` এবং `GET /verify/{token}` কল করে।

### ব্যাক-এন্ড লেখা বন্ধ নির্দেশাবলী

ওয়েবসাইট ব্যাকএন্ড ফ্রন্ট-এন্ড দ্বারা জমা দেওয়া `token` পাওয়ার পরে, এটিকে `captcha_srv` পরিষেবাতে একটি অনুরোধ শুরু করতে হবে:

- **রিকোয়েস্ট ইন্টারফেস**:`GET /verify/{token}`
- **পাথ প্যারামিটার**: `token` (Base64URL স্ট্রিং সামনের প্রান্তে ফিরে এসেছে)
- **রিটার্ন ফলাফল**: `1` মানে যাচাইকরণ পাস এবং বৈধ (স্বয়ংক্রিয়ভাবে ধ্বংস হয়ে যাবে); `0` মানে অবৈধ বা লেখা বন্ধ করা হয়েছে৷
