# ಪರಿಶೀಲನೆ ಕೋಡ್ ಪಾಪ್ಅಪ್ ಲೇಯರ್

ಗ್ರಾಫಿಕ್ ಕ್ಲಿಕ್ ಆಧರಿಸಿ ಪರಿಶೀಲನೆ ಕೋಡ್ ಪಾಪ್-ಅಪ್ ವಿಂಡೋ.

- ಪಾಪ್-ಅಪ್ ವಿಂಡೋ ಸಂವಹನ ಮತ್ತು ESC/ಕ್ಲೋಸ್ ಬೆಂಬಲವನ್ನು ಕಾರ್ಯಗತಗೊಳಿಸಲು BoxX ನೊಂದಿಗೆ ಸಂಯೋಜಿಸಲಾಗಿದೆ
- ಹಿನ್ನೆಲೆ ಚಿತ್ರವನ್ನು ಆಧರಿಸಿ ಗುರಿಯನ್ನು ಕ್ಲಿಕ್ ಮಾಡಿ
- ಹಂತ ಕ್ಲಿಕ್ ರದ್ದುಗೊಳಿಸುವಿಕೆ ಮತ್ತು ಸ್ವಯಂಚಾಲಿತ ಮರುಪ್ರಯತ್ನ ಕಾರ್ಯವಿಧಾನವನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ
- ಬಳಸಿ
  * ಸಾರ್ವಜನಿಕ ನೆಟ್‌ವರ್ಕ್:`https://captcha.webc.pub`
  * ಖಾಸಗಿ ನಿಯೋಜನೆ: [captcha_srv](https://crates.io/crates/captcha_srv)

## ಡೆಮೊ ಬಳಸಿ

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // ಪರಿಶೀಲನೆಯ ನಂತರ, ಟೋಕನ್ ಅನ್ನು ಬ್ಯಾಕೆಂಡ್‌ಗೆ ಸಲ್ಲಿಸಿ
  console.log("ಪರಿಶೀಲನೆ ಅಂಗೀಕರಿಸಿದ ಟೋಕನ್:", ಟೋಕನ್);
}
```

## ಮೌಲ್ಯವನ್ನು ಹಿಂದಿರುಗಿಸುತ್ತದೆ

ಫಂಕ್ಷನ್‌ಗೆ ಕರೆ ಮಾಡುವುದರಿಂದ `Promise<string | undefined>`:
- **ಪರಿಶೀಲನೆ ಅಂಗೀಕರಿಸಲಾಗಿದೆ**: Base64URL ಎನ್‌ಕೋಡ್ ಮಾಡಲಾದ (ಯಾವುದೇ ಪ್ಯಾಡಿಂಗ್) ಪರಿಶೀಲನಾ ಕೋಡ್ ಟೋಕನ್ ಸ್ಟ್ರಿಂಗ್ ಅನ್ನು ಹಿಂತಿರುಗಿಸುತ್ತದೆ.
- **ಮುಚ್ಚು ಅಥವಾ ರದ್ದು**: `undefined` ಗೆ ಹಿಂತಿರುಗಿ.

## ಪರಿಶೀಲನೆ ಪ್ರಕ್ರಿಯೆ ಮತ್ತು ಬ್ಯಾಕ್-ಎಂಡ್ ರೈಟ್-ಆಫ್

1. **ಪ್ರಚೋದಕ ಮೌಲ್ಯೀಕರಣ**: ಮುಂಭಾಗದ ಕರೆಗಳು `Captcha()`.
2. **ಚಾರ್ಟ್ ಪಡೆಯಿರಿ**: `Captcha.js` ಕ್ಲಿಕ್ ಮಾಡಿದ ಚಿತ್ರ ಮತ್ತು ID ಅನ್ನು ಪಡೆಯಲು `GET /` ನಿಂದ `captcha_srv` ಅನ್ನು ಪ್ರಾರಂಭಿಸಿ.
3. **ನಿರ್ದೇಶನ ಪರಿಶೀಲನೆ**: ಬಳಕೆದಾರರು ಕ್ಲಿಕ್ ಅನ್ನು ಪೂರ್ಣಗೊಳಿಸಿದ ನಂತರ, ನಿರ್ದೇಶಾಂಕಗಳನ್ನು ಪರಿಶೀಲಿಸಲು `Captcha.js` `POST /` ರಿಂದ `captcha_srv` ಅನ್ನು ಪ್ರಾರಂಭಿಸುತ್ತದೆ. ಪರಿಶೀಲನೆ ಯಶಸ್ವಿಯಾದರೆ, Base64URL ಎನ್‌ಕೋಡ್ ಮಾಡಿದ ಟೋಕನ್ ಅನ್ನು ಹಿಂತಿರುಗಿಸಲಾಗುತ್ತದೆ.
4. **ಬ್ಯಾಕ್-ಎಂಡ್ ಪರಿಶೀಲನೆ**: ಮುಂಭಾಗದ ತುದಿಯು ವೆಬ್‌ಸೈಟ್ ಬ್ಯಾಕೆಂಡ್‌ಗೆ ಟೋಕನ್ ಅನ್ನು ಸಲ್ಲಿಸುತ್ತದೆ ಮತ್ತು ಟೋಕನ್ ಅನ್ನು ಒಮ್ಮೆಗೇ ಪರಿಶೀಲಿಸಲು ಮತ್ತು ನಾಶಮಾಡಲು ಬ್ಯಾಕೆಂಡ್ `captcha_srv` ಮತ್ತು `GET /verify/{token}` ಗೆ ಕರೆ ಮಾಡುತ್ತದೆ.

### ಬ್ಯಾಕ್-ಎಂಡ್ ರೈಟ್-ಆಫ್ ಸೂಚನೆಗಳು

ವೆಬ್‌ಸೈಟ್ ಬ್ಯಾಕೆಂಡ್ ಫ್ರಂಟ್-ಎಂಡ್ ಸಲ್ಲಿಸಿದ `token` ಅನ್ನು ಸ್ವೀಕರಿಸಿದ ನಂತರ, ಅದು `captcha_srv` ಸೇವೆಗೆ ವಿನಂತಿಯನ್ನು ಪ್ರಾರಂಭಿಸುವ ಅಗತ್ಯವಿದೆ:

- **ವಿನಂತಿ ಇಂಟರ್ಫೇಸ್**:`GET /verify/{token}`
- **ಪಾತ್ ಪ್ಯಾರಾಮೀಟರ್**: `token` (Base64URL ಸ್ಟ್ರಿಂಗ್ ಅನ್ನು ಮುಂಭಾಗದ ತುದಿಯಿಂದ ಹಿಂತಿರುಗಿಸಲಾಗಿದೆ)
- **ರಿಟರ್ನ್ ಫಲಿತಾಂಶ**: `1` ಎಂದರೆ ಪರಿಶೀಲನೆಯನ್ನು ರವಾನಿಸಲಾಗಿದೆ ಮತ್ತು ಮಾನ್ಯವಾಗಿದೆ (ಸ್ವಯಂಚಾಲಿತವಾಗಿ ನಾಶವಾಗುತ್ತದೆ); `0` ಎಂದರೆ ಅಮಾನ್ಯ ಅಥವಾ ಬರೆಯಲಾಗಿದೆ.
