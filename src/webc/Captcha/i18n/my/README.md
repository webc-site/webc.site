# အတည်ပြုကုဒ် ပေါ်လာသော အလွှာ

ဂရပ်ဖစ်ကလစ်ကို အခြေခံ၍ အတည်ပြုကုဒ် ပေါ်လာသော ဝင်းဒိုး။

- ပေါ့ပ်အပ်ဝင်းဒိုး အပြန်အလှန်တုံ့ပြန်မှုနှင့် ESC/အနီးကပ်ပံ့ပိုးမှုတို့ကို အကောင်အထည်ဖေါ်ရန် BoxX နှင့် ပေါင်းစပ်ထားသည်။
- နောက်ခံပုံပေါ်အခြေခံ၍ ပစ်မှတ်ကိုနှိပ်ပါ။
- ခြေလှမ်းကလစ်မှပြန်ဖျက်ခြင်းနှင့် အလိုအလျောက်ပြန်လည်ကြိုးစားခြင်း ယန္တရားကို ပံ့ပိုးပေးသည်။
- အသုံးပြု
  * အများသူငှာ ကွန်ရက်-`https://captcha.webc.pub`
  * သီးသန့်အသုံးပြုမှု- [captcha_srv](https://crates.io/crates/captcha_srv)

## ဒီမိုကိုသုံးပါ။

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // အတည်ပြုပြီးနောက်၊ တိုကင်ကို နောက်ကွယ်မှ တင်သွင်းပါ။
  console.log("အတည်ပြုခြင်းလွန် တိုကင်:", တိုကင်);
}
```

## ပြန်လာတန်ဖိုး

လုပ်ဆောင်ချက်ကိုခေါ်ဆိုခြင်းသည် `Promise<string | undefined>`:
- **အတည်ပြုခြင်းပြီးသွားသည်**- Base64URL ကုဒ်သွင်းထားသော (အကွက်မရှိ) အတည်ပြုကုဒ် တိုကင်စာကြောင်းကို ပြန်ပေးသည်။
- **ပိတ် သို့မဟုတ် ပယ်ဖျက်ပါ**- `undefined` သို့ ပြန်သွားပါ။

## အတည်ပြုခြင်းလုပ်ငန်းစဉ်နှင့် နောက်ကွယ်မှ နုတ်ထွက်ခြင်း။

1. **အစပျိုးအတည်ပြုခြင်း**- Frontend ခေါ်ဆိုမှုများ `Captcha()`။
2. **ဇယားကိုရယူပါ**- `Captcha.js`နှိပ်ထားသော ပုံနှင့် ID ကိုရယူရန် `GET /`ကို `captcha_srv`ကို စတင်ပါ။
3. **ညှိနှိုင်းအတည်ပြုခြင်း**- အသုံးပြုသူသည် ကလစ်ကို အပြီးသတ်ပြီးနောက်၊ သြဒိနိတ်များကို အတည်ပြုရန် `Captcha.js`မှ `POST /`မှ စတင်ပါသည်။ အတည်ပြုခြင်းအောင်မြင်ပါက၊ Base64URL ကုဒ်ဝှက်ထားသော တိုကင်တစ်ခုကို ပြန်ပေးပါမည်။
4. **Back-end အတည်ပြုခြင်း**- ရှေ့တန်းမှ တိုကင်ကို ဝဘ်ဆိုက်နောက်ကွယ်သို့ ပေးပို့ပြီး နောက်ခံသည် တိုကင်ကို အတည်ပြုရန်နှင့် ဖျက်ဆီးရန် `captcha_srv`နှင့် `GET /verify/{token}`ကို ခေါ်ဆိုပါသည်။

### Back-end ရေး-ပိတ် ညွှန်ကြားချက်များ

ဝဘ်ဆိုက်နောက်ကွယ်မှသည် ရှေ့ဆုံးမှတင်ပြသော `token`ကို လက်ခံရရှိပြီးနောက်၊ ၎င်းသည် `captcha_srv`ဝန်ဆောင်မှုသို့ တောင်းဆိုချက်တစ်ခုကို စတင်ရန် လိုအပ်သည်-

- **တောင်းဆိုမှု အင်တာဖေ့စ်**:`GET /verify/{token}`
- **လမ်းကြောင်း ကန့်သတ်ချက်**- `token` (ရှေ့ဆုံးမှ Base64URL စာကြောင်း ပြန်ပေးသည်)
- **Return ရလဒ်**: `1` ဆိုသည်မှာ အတည်ပြုခြင်း အောင်မြင်ပြီး တရားဝင်သည် (အလိုအလျောက် ပျက်ပြားသွားလိမ့်မည်)။ `0` ဆိုသည်မှာ မမှန်ကန်ပါ သို့မဟုတ် ပယ်ချခံရသည်ဟု ဆိုလိုသည်။
