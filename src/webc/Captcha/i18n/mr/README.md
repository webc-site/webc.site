# सत्यापन कोड पॉपअप स्तर

ग्राफिक क्लिकवर आधारित सत्यापन कोड पॉप-अप विंडो.

- पॉप-अप विंडो संवाद आणि ESC/क्लोज सपोर्ट लागू करण्यासाठी BoxX सह एकत्रित
- पार्श्वभूमी प्रतिमेवर आधारित लक्ष्य क्लिक करा
- स्टेप क्लिक पूर्ववत आणि स्वयंचलित पुन्हा प्रयत्न करण्याच्या यंत्रणेस समर्थन देते
- वापर
  * सार्वजनिक नेटवर्क:`https://captcha.webc.pub`
  * खाजगी उपयोजन: [captcha_srv](https://crates.io/crates/captcha_srv)

## डेमो वापरा

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // पडताळणीनंतर, टोकन बॅकएंडवर सबमिट करा
  console.log("सत्यापन पास टोकन:", टोकन);
}
```

## परतावा मूल्य

फंक्शनला कॉल केल्याने `Promise<string | undefined>` मिळते:
- **सत्यापन पास झाले**: Base64URL एन्कोडेड (पॅडिंग नाही) सत्यापन कोड टोकन स्ट्रिंग परत करते.
- **बंद करा किंवा रद्द करा**: `undefined` वर परत या.

## पडताळणी प्रक्रिया आणि बॅक-एंड राइट-ऑफ

1. **ट्रिगर प्रमाणीकरण**: फ्रंटएंड कॉल `Captcha()`.
2. **चार्ट मिळवा**: `Captcha.js` क्लिक केलेली इमेज आणि आयडी मिळवण्यासाठी `GET /` ते `captcha_srv` सुरू करा.
3. **समन्वय पडताळणी**: वापरकर्त्याने क्लिक पूर्ण केल्यानंतर, निर्देशांक सत्यापित करण्यासाठी `POST /` ते `captcha_srv` सुरू करतो. पडताळणी यशस्वी झाल्यास, Base64URL एन्कोड केलेले टोकन परत केले जाईल.
4. **बॅक-एंड पडताळणी**: फ्रंट-एंड वेबसाइट बॅकएंडवर टोकन सबमिट करतो आणि टोकन एकाच वेळी सत्यापित करण्यासाठी आणि नष्ट करण्यासाठी बॅकएंड `captcha_srv` आणि `GET /verify/{token}` ला कॉल करते.

### बॅक-एंड राइट-ऑफ सूचना

वेबसाइट बॅकएंडला फ्रंट-एंडद्वारे सबमिट केलेले `token` प्राप्त झाल्यानंतर, त्याला `captcha_srv` सेवेसाठी विनंती सुरू करणे आवश्यक आहे:

- **विनंती इंटरफेस**:`GET /verify/{token}`
- **पथ पॅरामीटर**: `token` (बेस64URL स्ट्रिंग समोरच्या टोकाने परत आली)
- **परतावा परिणाम**: `1` म्हणजे पडताळणी पास झाली आहे आणि वैध आहे (आपोआप नष्ट होईल); `0` म्हणजे अवैध किंवा राइट ऑफ केले गेले आहे.
