# توثیقی کوڈ پاپ اپ پرت

گرافک کلک پر مبنی توثیقی کوڈ پاپ اپ ونڈو۔

- پاپ اپ ونڈو تعامل اور ESC/قریبی تعاون کو نافذ کرنے کے لیے BoxX کے ساتھ مل کر
- پس منظر کی تصویر کی بنیاد پر ہدف پر کلک کریں۔
- قدم پر کلک کو کالعدم اور خودکار دوبارہ کوشش کرنے کے طریقہ کار کی حمایت کرتا ہے۔
- استعمال کریں
  * عوامی نیٹ ورک:`https://captcha.webc.pub`
  * نجی تعیناتی: [captcha_srv](https://crates.io/crates/captcha_srv)

## ڈیمو استعمال کریں۔

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // تصدیق کے بعد، ٹوکن کو بیک اینڈ پر جمع کروائیں۔
  console.log("تصدیق منظور شدہ ٹوکن:"، ٹوکن)؛
}
```

## واپسی کی قیمت

فنکشن کو کال کرنے سے `Promise<string | undefined>` واپس آتا ہے:
- **تصدیق پاس**: Base64URL انکوڈ شدہ (کوئی پیڈنگ نہیں) توثیقی کوڈ ٹوکن سٹرنگ لوٹاتا ہے۔
- **بند کریں یا منسوخ کریں**: `undefined` پر واپس جائیں۔

## تصدیقی عمل اور بیک اینڈ رائٹ آف

1. **ٹریگر توثیق**: فرنٹ اینڈ کالز `Captcha()`۔
2. **چارٹ حاصل کریں**: `Captcha.js` کلک کی گئی تصویر اور ID حاصل کرنے کے لیے `GET /` سے `captcha_srv` شروع کریں۔
3. **کوآرڈینیٹ کی توثیق**: صارف کے کلک کو مکمل کرنے کے بعد، کوآرڈینیٹ کی تصدیق کے لیے `POST /` سے `captcha_srv` شروع کرتا ہے۔ اگر تصدیق کامیاب ہو جاتی ہے تو، ایک Base64URL انکوڈ شدہ ٹوکن واپس کر دیا جائے گا۔
4. **بیک اینڈ کی توثیق**: فرنٹ اینڈ ٹوکن کو ویب سائٹ کے بیک اینڈ پر جمع کرتا ہے، اور بیک اینڈ ٹوکن کی تصدیق کرنے اور اسے ایک ساتھ تباہ کرنے کے لیے `captcha_srv` اور `GET /verify/{token}` کو کال کرتا ہے۔

### بیک اینڈ رائٹ آف ہدایات

ویب سائٹ کے بیک اینڈ کو فرنٹ اینڈ کی طرف سے جمع کردہ `token` موصول ہونے کے بعد، اسے `captcha_srv` سروس سے درخواست شروع کرنے کی ضرورت ہے:

- **درخواست انٹرفیس**:`GET /verify/{token}`
- **پاتھ پیرامیٹر**: `token` (بیس 64URL سٹرنگ سامنے والے سرے سے لوٹی گئی)
- **واپسی کا نتیجہ**: `1` کا مطلب ہے کہ تصدیق منظور اور درست ہے (خود بخود تباہ ہو جائے گی)؛ `0` کا مطلب ہے غلط یا لکھ دیا گیا ہے۔
