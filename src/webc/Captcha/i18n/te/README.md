# ధృవీకరణ కోడ్ పాపప్ లేయర్

గ్రాఫిక్ క్లిక్ ఆధారంగా ధృవీకరణ కోడ్ పాప్-అప్ విండో.

- పాప్-అప్ విండో ఇంటరాక్షన్ మరియు ESC/క్లోజ్ సపోర్ట్‌ని అమలు చేయడానికి BoxXతో కలిపి
- నేపథ్య చిత్రం ఆధారంగా లక్ష్యాన్ని క్లిక్ చేయండి
- స్టెప్ క్లిక్ అన్‌డూ మరియు ఆటోమేటిక్ రీట్రీ మెకానిజంకు మద్దతు ఇస్తుంది
- ఉపయోగించండి
  * పబ్లిక్ నెట్‌వర్క్:`https://captcha.webc.pub`
  * ప్రైవేట్ విస్తరణ: [captcha_srv](https://crates.io/crates/captcha_srv)

## డెమో ఉపయోగించండి

```js
import Captcha from "webc.site/Captcha.js";

const token = await Captcha();
if (token) {
  // ధృవీకరణ తర్వాత, టోకెన్‌ను బ్యాకెండ్‌కు సమర్పించండి
  console.log("ధృవీకరణ ఆమోదించబడిన టోకెన్:", టోకెన్);
}
```

## తిరిగి విలువ

ఫంక్షన్‌కి కాల్ చేయడం `Promise<string | undefined>`ని అందిస్తుంది:
- **ధృవీకరణ ఆమోదించబడింది**: Base64URL ఎన్‌కోడ్ చేయబడిన (పాడింగ్ లేదు) ధృవీకరణ కోడ్ టోకెన్ స్ట్రింగ్‌ను అందిస్తుంది.
- **మూసివేయండి లేదా రద్దు చేయండి**: `undefined`కి తిరిగి వెళ్లండి.

## ధృవీకరణ ప్రక్రియ మరియు బ్యాక్-ఎండ్ రైట్-ఆఫ్

1. **ట్రిగ్గర్ ధ్రువీకరణ**: ఫ్రంటెండ్ కాల్‌లు `Captcha()`.
2. **చార్ట్ పొందండి**: `Captcha.js` క్లిక్ చేసిన చిత్రం మరియు IDని పొందడానికి `GET /` నుండి `captcha_srv`ని ప్రారంభించండి.
3. **కోఆర్డినేట్ ధృవీకరణ**: వినియోగదారు క్లిక్‌ని పూర్తి చేసిన తర్వాత, కోఆర్డినేట్‌లను ధృవీకరించడానికి `Captcha.js` `POST /` నుండి `captcha_srv`ని ప్రారంభిస్తుంది. ధృవీకరణ విజయవంతమైతే, Base64URL ఎన్‌కోడ్ చేసిన టోకెన్ తిరిగి ఇవ్వబడుతుంది.
4. **బ్యాక్-ఎండ్ వెరిఫికేషన్**: ఫ్రంట్-ఎండ్ వెబ్‌సైట్ బ్యాకెండ్‌కు టోకెన్‌ను సమర్పిస్తుంది మరియు టోకెన్‌ను ఒకేసారి ధృవీకరించడానికి మరియు నాశనం చేయడానికి బ్యాకెండ్ `captcha_srv` మరియు `GET /verify/{token}`కి కాల్ చేస్తుంది.

### బ్యాక్-ఎండ్ రైట్-ఆఫ్ సూచనలు

వెబ్‌సైట్ బ్యాకెండ్ ఫ్రంట్-ఎండ్ ద్వారా సమర్పించబడిన `token`ని స్వీకరించిన తర్వాత, అది `captcha_srv` సేవకు అభ్యర్థనను ప్రారంభించాలి:

- **అభ్యర్థన ఇంటర్‌ఫేస్**:`GET /verify/{token}`
- **మార్గం పరామితి**: `token` (Base64URL స్ట్రింగ్ ఫ్రంట్ ఎండ్ ద్వారా తిరిగి ఇవ్వబడింది)
- **రిటర్న్ ఫలితం**: `1` అంటే ధృవీకరణ ఆమోదించబడింది మరియు చెల్లుబాటు అవుతుంది (స్వయంచాలకంగా నాశనం చేయబడుతుంది); `0` అంటే చెల్లనిది లేదా వ్రాయబడిందని అర్థం.
